# 지역별 예측 반복 검증 계획

목표: 기존 6개월 모델을 보존하고, 반복 실험의 평가 기준·시간 순서·채택 기준을 고정해 실제 개선 여부를 확인한다.

기존 연구: ../regional_forecast_20261027/results_v3. 유효 실거래·가격 목표·3개월 가격 공개 지연을 고정한다. 현재 입력은 같은 수정 빈티지이므로 모든 결과는 과거 재구성 검증이다. 이미 본 2024~2026 평가 기간을 새로운 블라인드 평가라고 부르지 않는다.

평가 지표:
- 오차: MAE, RMSE, 중앙 절대오차, 90분위 절대오차, 평균 편향, 최악 원점·지역 오차.
- 기준 대비: 가격 유지/기존 HGB/감쇠 모멘텀 대비 MAE skill. 같은 원점·같은 지역만 비교한다.
- 방향·지역: ±1% 중립 구간을 둔 방향 정확도·balanced accuracy, 지역 순위 Spearman, 지역별 오차·시기별 오차. 원점·지역 수준·시도에 같은 가중치를 주는 지표를 별도로 산출한다.
- 불확실성: 과거에 공개된 예측 잔차만으로 만든 80%·95% 범위의 실제 포함 비율, 평균 폭, interval score.
- 자료: 예측 가능 수, 채점 수, 미래 거래 부족으로 채점 불가한 수, 최신 입력 결측률.

반복 방식:
1. 2015년부터 반기별 후보 예측을 저장하고, 2017~2026을 평가한다. 고정 후보군: 기존 기준, 최근 6/10년 학습, 축소된 가격·금리·수요 특징량, 시간 감쇠, 전환 국면을 위한 가격 지속성 계열. 새 변수는 발표일을 확인하고 별도 사본으로 결합한다.
2. 각 예측 원점마다 당시 이미 공개된 과거 OOS 오차로만 모델을 고르거나 결합한다. 6개월 정답+3개월 공개 지연이 끝나지 않은 예측 오차는 모델 선택·편향 보정·예측 범위에 사용하지 않는다. 후보 선택 경로를 모두 저장한다.
3. 시도·시군구 선택을 분리하고 지역별 손실은 작은 표본에서 전체 손실 쪽으로 축소한다. 고정 50:50 결합과 단순 기준도 함께 평가한다.
4. 사전에 정한 라운드를 모두 기록한다. 평균 오차가 내려가도 큰 오차·특정 지역·급변 국면이 악화되면 그대로 보고한다. 최종 채택 규칙은 원점 균형 MAE 평균 5% 개선, 두 지리 수준 MAE 비악화, 90분위 오차 10% 초과 악화 금지로 고정한다. 미달이면 운영 기준은 유지하고 연구 후보만 남긴다.
5. 과거 결과를 보고 새 후보를 추가하면 탐색임을 기록하며 동일 평가 구간을 새 독립 평가로 계산하지 않는다. 최종 예측과 입력 해시를 저장해 향후 공개된 실제 결과로 전향 평가한다. 새 관측 없이 무한 반복해 정확도를 보장하지 않는다.

구현 파일: evaluation.py(공통 지표·가용 오차·결합), test_evaluation.py(누설·중립·결측·구간 테스트), experiment.py(후보·검증·모델 저장·반복 기록), render_report.py(정적 결과 도표). 기존 코드/원본/모델 변경 없음. 새 유료 서비스·원천 거래 외부 전송 없음.
