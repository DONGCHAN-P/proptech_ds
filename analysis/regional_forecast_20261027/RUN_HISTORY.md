# 실험 결과 사용 이력

- `results/`: 최초 탐색 실행. 개발 2023년 7월 정답이 첫 평가 시점 이후 공개되는 선택 시점 문제가 있어 최종 성능·예측으로 사용하지 않는다.
- `results_v1/`: 시도 정책 노출을 지역별 과거 거래량으로 보정한 실행. 위 선택 시점 문제가 남아 최종 보고에서 제외한다.
- `results_v2/`: 개발 종료를 2023년 1월로 앞당기고 정답 공개일 점검, 증감률의 양쪽 피연산자 공개일, 미래 정답 미관측 지역의 예측·평가 커버리지를 수정했다. 독립 수정 검수와 13개 테스트를 통과했다. 2026 정책 추가 검증 전의 고정 기준 실험이다.
- `results_v3/`: 최종 납품 실행. v2 시간·평가 수정에 더해 검증한 2026년 발표 4개를 별도 불변 입력으로 추가하고, 같은 정책 패키지의 하위 조치를 중복 집계하지 않도록 했다. 14개 테스트와 별도 정책 수정 검수를 적용한다. 신규 조치는 자료·개념 정확성 수정이며 평가 성능을 보고 선택한 조정이 아니다. 기존 2026년 법적 지역 분할이 월 패널 통합 경계와 맞지 않는 동탄은 전체 화성으로 확대하지 않았다.

초기 평가 결과를 본 뒤 성능이 더 좋아지는 날짜나 변수를 고르는 방식으로 수정하지 않았다. v2 수정은 독립 검수에서 찾은 시간 처리·평가 표본 오류에 따른 것이다. 전체 연구는 최신 수정 자료를 이용한 재구성이며, 실제 과거에 보관한 공개 빈티지로 한 검증과 구분한다. 동일 평가 기간을 반복 확인한 탐색·수정 이력도 보존한다. 향후 실제 예측을 저장하고 2027년 정답이 충분히 공개된 뒤 수행하는 전향 검증이 필요하다.
