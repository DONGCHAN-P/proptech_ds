# 지역별 6개월 가격 예측 연구 구현 계획

목표: 2006년 이후 보유 아파트 실거래를 이용해 지역별 6개월 가격 변화율을 예측하고, 변수가 실제 미래 예측을 개선하는지 검증한다. 기존 운영 모델과 원본은 변경하지 않는다.

구성: 월별 동일 단지·면적 매칭 가격 변화 → 시군구/시도 패널 → 발표 지연을 적용한 외생 변수 → 6개월 직접 예측 → 시간 순서 검증. 단순 가격 유지와 모멘텀을 비교 기준으로 사용한다. 지역별 거래 표본과 행정구역 변경, 관측 빈티지 한계를 함께 기록한다.

기술: Python, pandas, DuckDB, scikit-learn, matplotlib. 새 유료 서비스와 대규모 라이브러리 설치 없이 현재 환경을 사용한다.

검토할 위험: 행정구역 개편 중복, 취소·신고 지연의 소급 수정, 드문 거래의 구성 변화, 6개월 정답의 시간 누설, 사후 발표된 통계·정책 사용.

1. `inspect_inputs.py`, `prepare_panel.py`: 원본/확장 수집 범위와 중복·완료 월을 확인하고 불변 입력 명세 및 월 패널 생성. 거래가 적은 지역은 예측에서 제외. 품질 점검 결과 저장.
2. `forecast.py`, `test_forecast.py`: 외생 변수 발표 시점, 정책의 공표 시점, 중간 결측월을 넘지 않는 정답 생성, 학습 정답 종료일·신고 지연을 지키는 분할을 먼저 테스트하고 구현.
3. `run_experiment.py`: 선형/트리 후보와 가격만 이용한 기준 모델을 개발 구간에서 비교. 마지막 시계열 구간은 모델 선정에 사용하지 않고 독립 평가. 상관관계는 수준 대신 미래 변화율과의 관계를 지역 내부에서 비교하고 표본 기간을 표시.
4. 공식 자료·논문 조사 메모와 기계 판독 가능 입력을 결합. 사용 가능한 변수와 미확보 변수를 분리하고 그룹별 추가 예측력을 비교.
5. 전체 실험 실행, 시계열 누설 테스트, 기준 대비 오차·방향·지역별 오차·과거 잔차 범위·미래 6개월 산출물과 보고서 생성. 실제 확보 범위와 성능을 최종 보고.

검증 명령: `tools/python311/python.exe -B -X utf8 -m pytest analysis/regional_forecast_20261027/test_forecast.py -q` 및 각 재현 스크립트. 복잡한 새 모델이 기준을 이기지 못하면 해당 결과를 그대로 보고하고 검증된 기준 모델을 선택한다.
