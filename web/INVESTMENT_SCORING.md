# 실거주·장기보유 비교 v1

2026-10-20 사용자 선택: 실거주 겸 5년 이상 보유. 기존 예산 여유 가산점 때문에 절대가격이 낮은 단지가 과도하게 상위에 오르던 문제를 수정했습니다. API 기본 목적은 `long_term`입니다. 이전 저장 결과는 재계산하지 않습니다.

기본 가중치: 업무지 접근 35%, 유사 조건 비교가격 20%, 거래 활발도 20%, 주거 여건 15%, 사용자 선택 10%. 근무지를 입력하면 업무지 접근·주거 여건에서 각각 5%p를 가져와 개인 통근에 10%를 반영합니다. 가중치는 학습된 수익률 예측 모델이 아닌 서비스의 초기 설계값입니다.

- 예산은 엄격한 상한. 예산 소진율이나 남는 금액은 가산점으로 쓰지 않습니다. 저렴한 단지의 제외 하한도 만들지 않습니다.
- 업무지 접근: 로컬 역 좌표의 광화문·여의도·강남·DMC·마곡나루·판교·가산디지털단지·인천대입구·수원 기준역 중 가장 가까운 두 곳의 직선거리(70:30), 단지의 역 도보 접근. 실제 통근시간이나 고용 인구 순위가 아닙니다. 직선거리 기준 3~35km 구간을 점수화합니다.
- 비교가격: 예산 필터 전 전체 자료에서 같은 시군구·평형·10년 연식 구간·역 도보 구간(10분 이내/20분 이내/초과)의 평당가 중간값. 최근 1년 거래 3건 이상인 단지·평형만 기준 표본으로 사용하며 5개 미만이면 중립 50점. 할인 가산점은 75점으로 제한합니다. 동·층·향·정비사업 상태를 완전히 통제하지 못합니다.
- 거래 활발도: 같은 평형의 최근 1년 거래 건수를 로그 변환해 30건에서 만점. 세대수로 보정한 회전율이나 공식 거래량 통계가 아닙니다.
- 주거 여건: 준공 연식 60%, 기존 생활시설 점수 40%. 오래됐다는 사실만으로 재건축 가치를 가산하지 않습니다.
- 최근 거래가 적으면 기존 신뢰도 감점 적용. 미래 철도·재건축 사업성·향후 공급·전세수익률은 미반영.

결과는 단지·평형별 과거 실거래 기반 비교이며 현재 매도 호가나 매매 가능한 개별 매물 목록이 아닙니다. 공급·정비사업·임대 지표를 연결하고 과거 시점별 검증을 하기 전까지 미래 수익률이나 투자 성공 확률로 해석하지 않습니다.
