## 구현 범위

- 비회원 예산 계산: 월 실수령액·지출, 비상금, 금리·기간·상환 방법, LTV·DSR 가정, 부대비용을 반영합니다.
- 회원 가입·로그인 후 기존 6단계 추천, 개인 저장함, 사용 한도 확인을 제공합니다. 예산을 임의로 넓히지 않습니다.
- 아파트 지도·기본 정보는 공개합니다. 외부 지도 연결이 차단되면 실제 수도권 행정경계도를 표시합니다. 상세 도로 타일을 대체하는 데이터는 아닙니다.
- 허용된 행동 이벤트와 요청 경로·상태·처리시간을 기록합니다. 입력 원문과 금융값을 요청 로그에 남기지 않습니다. 사용자가 직접 저장한 결과는 개인 저장함에 보관합니다.
- 향후 유료 서비스용 권한·한도 구조만 준비했습니다. 결제와 정기 리포트 발송은 비활성 상태입니다.

## 검증 결과

API·계산·저장소·추천 테스트 40개 통과. 실제 로컬 데이터로 PC(1440×1000)·모바일(390×844)의 계산→가입→6단계 추천→저장→지도 흐름을 통과했습니다. 화면 자료와 자동 검증 결과는 `output/jipgorithm-review-v1/`에 있습니다. 지도는 Canvas 렌더러이므로 SVG 경로만 찾던 검증 조건을 수정했습니다. 외부 타일은 검증 환경에서 네트워크 차단되어 행정경계도 대체 화면을 확인했습니다.

독립 코드 리뷰에서 발견한 저장함 목록 100개 제한을 저장 한도 200개와 일치시켰습니다. 인증 모드 전환 후 개발용 세션을 관리형 인증에서 인정하지 않도록 수정했습니다. FastAPI 기존 시작 이벤트 방식의 폐기 예정 경고는 남아 있습니다.

## 공개 운영 전 남은 연결

Supabase 실제 프로젝트·Postgres 연결은 아직 없으며 실서비스 인증 검증을 완료하지 않았습니다. 로컬 계정은 개발 확인용입니다. Supabase 설정 절차와 환경변수는 `SERVICE_SETUP.md`, `service.env.example`을 참고합니다. 운영용 DB는 마이그레이션 실행 권한이 필요합니다. 비밀번호 재설정·회원 탈퇴·관리형 세션 자동 갱신·보존 정책의 운영 절차도 공개 전에 보완해야 합니다.

예산 계산은 사용자 가정 시뮬레이션입니다. 최신 지역 규제·실제 은행 심사·세금 및 감면을 자동 판정하지 않습니다. 실제 결제·앱 출시·공개 배포는 이번 결과에 포함되지 않습니다.
