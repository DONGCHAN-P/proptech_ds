# 지역 상세 지도와 의미 단위 자막 제작 가이드

지역을 자세히 설명할 때 역 표시만 있는 빈 지도 대신, 주변 아파트·상업시설·공원의 실제 배치를 함께 보여준다. 남양주 지도 조각 v2의 40.3~61초 다산역 장면을 사용자가 선호한 기준으로 삼는다. 하단 자막은 글자 수나 화면 폭보다 문장의 의미를 먼저 기준으로 나눈다.

## 채널 인트로·아웃트로의 자막 예외

내레이션이 없는 채널 브랜드 인트로·아웃트로에는 흰 자막 박스를 표시하지 않는다. 배경 영상과 채널 그래픽을 온전히 보여준다. 본문과 내레이션이 있는 도입 훅에는 의미 단위 자막과 고정 흰 박스를 유지한다. 브랜드 구간 경계는 실제 타임록으로 지정하고, 빈 박스가 남거나 첫 본문 자막이 사라지지 않는지 실제 출력으로 확인한다.

## 최종 조립본의 단발 화면 검사

구간을 자르거나 새 영상과 원본을 연결한 최종 MP4에서 모든 컷 경계를 검사한다. 앞뒤 대표 화면만 보는 것으로 대체하지 않는다. 특히 잘라낸 원본 끝에 다음 장면이 몇 프레임 포함되거나, 새 오버레이가 시작하기 직전에 예전 지도가 노출되는지 확인한다. 한두 프레임 또는 수초만 끼어들었다 되돌아가는 불필요한 위치 지도·중간판은 제거한다. 자막·대상 강조의 변화와 실제 지도판 교체를 구별해 검사하며, 의도한 컷 목록과 실제 출력의 컷 후보를 대조한다.

## 지역 상세 지도의 구성

1. 실제 역 좌표를 중심으로 주변 주거 블록, 건물, 도로, 상업지역, 공원·녹지를 확보한다. 확인된 공간 자료에만 색을 넣는다.
2. 주거는 옅은 노랑, 상업·쇼핑은 옅은 분홍, 공원·녹지는 옅은 초록으로 구분한다. 범례와 역 이름은 고정한다. 색상은 법정 용도지역이나 입주·영업 완료를 의미하지 않는다.
3. 아파트·시설·공원 이름은 공식 주소와 지도 좌표를 대조한다. 한 화면에는 대표 장소 약 4~6곳을 표시하고, 인출선으로 실제 위치와 연결한다.
4. 처음부터 주변 배치가 보이게 한다. 설명에 맞춰 역 → 주거 → 상업 → 공원을 색 농도와 윤곽선으로 차례로 강조한다. 음성에서 다루지 않는 시설을 억지로 추가하지 않는다.
5. 세부 지도를 쓸 만큼 구체적인 공간 설명인지 먼저 판단한다. 도시 전체 위치 설명에는 광역 지도, 개발지구 경계 설명에는 공식 계획도를 사용한다. 다른 지역의 배치도를 분위기 자료로 대체하지 않는다.

역이 있다는 사실을 모든 단지의 도보 접근성과 동일시하지 않는다. 이동 동선을 설명할 때는 단지 대표 지점·실제 정류장·역 출구 인근을 구분하고, 도보 → 대기 → 버스 → 하차 후 도보를 분리한다. 사람은 지도에서 과하게 크지 않은 작은 표식으로 표현한다. 걷는 동안만 걸음 동작을 재생하고 대기·도착 시 멈춘다. 연출 속도를 실제 소요시간처럼 표시하지 않는다.

## 신도시 분석의 설명 순서

왕숙 편의 전체 구성은 전체 토지이용계획도에서 시작한다. 일자리 → 교통 → 분양가 → 생활시설 → 주변 공급을 같은 지도에 연결해 설명하고, 대체 지역 대비 메리트와 주목할 블록 판단으로 끝낸다. 기존 도시 소개가 본론을 대신하게 하지 않는다.

각 항목은 **지도상 위치 → 입주자의 편의 → 실제 이용 가능 시점 → 입주 시점에 남는 공백 → 어떤 수요자에게 맞는지**로 연결한다. 공장 투자액, 철도 이름, 학교 심사 결과를 열거하는 것만으로 분석을 마치지 않는다. 예정·목표·승인과 실제 개장·운영을 구분하고, 시간은 지구 전체의 하나의 날짜가 아니라 블록별 입주 달력과 비교한다.

분양가는 같은 전용면적·층 조건·거래 기간의 대체 단지와 비교한다. 가격 차이와 동시에 준공연도, 역 접근, 현재 생활시설, 기다리는 기간과 추가 비용을 보여준다. 비교 가격이 더 낮은 대안도 숨기지 않는다. 이 차이는 곧바로 안전마진이나 미래 수익을 의미하지 않는다.

주목할 단지는 왕숙1·왕숙2 지구명을 붙인 블록 단위로 검토한다. 역·학교·상업·공원 배치, 소음·큰 도로, 공급 규모, 입주 시점, 확인된 분양 조건을 연결해 후보의 장점과 유보 사유를 함께 설명한다. 가격이 미확인인 후보의 수익률 순위를 만들지 않는다. 대장 후보는 조건부 가설로 표시한다.

지도만으로 설명이 부족한 장면은 장면표에 빈 이미지 칸과 필요한 설명 목적을 남긴다. 생성 이미지의 장면·구도·사실 오인 방지 표기를 사용자와 조율한 뒤 만든다. 이 검토용 공백을 설명 없는 검은 화면으로 최종 영상에 납품하지 않는다.

## 자료와 표기

공식 토지이용계획도를 사용할 때는 지구, 기준일, 변경 이력, 이용 조건과 편집 허용 범위를 확인한다. 변경 금지 자료를 자르거나 덧그리지 않는다. 공개 공간 데이터로 직접 만든 지도는 **주변 배치 현황 · 공개 지도 기준**으로 표시한다. 실제 법정 계획도나 정밀 측량 결과로 소개하지 않는다. 현재 시설과 계획 시설은 시각적으로 구분한다.

OSM을 사용하면 OpenStreetMap contributors 출처와 라이선스 링크를 기록한다. 시설명·주소의 공식 근거, 확인일, 좌표 및 미확인 조건은 소스 목록에 남긴다. 제목·범례·출처·자막은 지도 카메라와 분리해 확대해도 흔들리지 않게 한다.

## 의미 단위 자막

자막 흰 박스는 영상의 공통 고정 요소로 계속 유지한다. 큐 사이의 짧은 공백이나 장면 전환 때 박스를 숨기거나 다시 나타내지 않는다. 글자만 실제 의미 단위 타이밍에 맞춰 바꾸며, 박스의 위치·높이·밝기는 고정한다. 실제 렌더의 큐 종료 직전·공백·다음 큐 시작 프레임에서 박스가 연속되는지 확인한다.

자막의 시간상 분할과 화면 안 줄바꿈을 따로 결정한다. 먼저 문장·절·짧은 완결 구절을 정하고, 그 구절 안에서 필요할 때만 줄바꿈한다. 글자 수에 맞춰 기계적으로 잘라 놓고 의미를 사후에 맞추지 않는다.

- **수량 묶음:** `8만 114세대`, `6만 4159세대`, `1만 5955세대`, `8천500억 원`, `6억 9천363만 원`은 수와 단위를 함께 보존한다. 숫자의 자릿수 구성 요소도 서로 떨어뜨리지 않는다.
- **고유명사와 명칭:** `별내별가람역`, `왕숙2 A1`, `59A`, `4호선 진접선` 등을 중간에서 자르지 않는다.
- **날짜와 조건:** `2029년 3월`, `5층 이상 기준층`처럼 하나의 정보를 이루는 표현을 묶는다.
- **문장 구조:** 조사만 다음 자막에 남기거나, 관형어와 명사를 무관한 자막에 분리하거나, 서술어 일부만 다음 자막에 넘기지 않는다. 접속절·문장부호·말의 호흡을 우선한다.
- **표시 길이:** 보통 1~2줄로 구성하되, 보호해야 할 표현이 길면 앞뒤 자막의 길이를 조정한다. 전체 문구를 억지로 축소하거나 화면 밖으로 넘기지 않는다.

예를 들어 `지금 8만` / `114세대가 입주했다는 뜻은 아닙니다`로 나누지 않고, `지금 8만 114세대가` / `입주했다는 뜻은 아닙니다`처럼 의미가 보존되는 지점을 선택한다. 실제 대본의 문구·숫자·조건을 바꾸어 더 짧게 만들지 않는다.

## 확인과 납품

내레이션 중심 영상은 **대본 확정 → 음성 생성·실제 길이 확인 → 장면·자막 타이밍 확정 → 최종 편집** 순서로 제작한다. 지도 자료와 모션 템플릿은 음성 작업과 병행해 준비한다. 인트로 훅과 아웃트로 문구도 음성 입력에 포함하고, BGM은 첫 진입·마무리 구간에서 시작/종료 페이드와 말소리 구간의 음량 낮춤을 적용한다.

음성 서비스가 원문 문자별 시각을 제공하면 그 자료를 저장하고, 승인 원문과 일치하는 문자 위치에 의미 자막을 연결한다. 정규화된 발음문을 원문과 같다고 추측하거나, 문자 비중 추정값을 실제 정렬값으로 표시하지 않는다. 기술상 정렬과 실제 청취 검수는 구분한다.

자막을 공백 정규화 후 이어 붙여 승인 대본과 대조한다. 누락·중복·순서 변경이 없어야 한다. 숫자·단위·고유명사 보호 검사를 하고, 실제 MP4에서 긴 자막과 숫자가 나오는 구간을 확인한다. 줄바꿈은 렌더러에 명시적으로 전달해 브라우저 임의 줄바꿈을 피한다.

의미 분할이 올바르다는 것과 음성 싱크가 정확하다는 것은 별개다. 글자 비중으로 시간을 배분했다면 추정 타이밍으로 기록한다. 실제 청취나 정렬 검증 없이 단어 단위 싱크까지 검수했다고 하지 않는다. 대본·승인 음성·기존 MP4는 보존하고 새 버전으로 납품한다.

현재 참조는 왕숙 최종 `episodes/namyangju-wangsuk-20261014/outputs/readability-cta-v15/namyangju_readability_cta_full_v15.mp4`, 조사 원본 `episodes/namyangju-wangsuk-20261014/research/dasan-context-v2/context.json`, 재사용 구현 `../../video/src/namyangju-v15/`이다. 예전 rail-route-proof 조각 등 중간 MP4는 2026-10-15 용량 정리에서 삭제됐다. 과거 보행 시안을 다음 편의 승인된 기본 표현으로 되살리지 않는다. 파일별 삭제 기록은 `../../output/cleanup-20261015/정리_결과.md`에서 확인한다.

## 토지이용계획도를 한 판으로 읽는 지도 연출

2026-10-15 사용자 검토 의견을 우선 기준으로 적용한다. 거시 설명은 왕숙1·왕숙2의 권역과 주변 도시·철도·일터의 관계를 보여준다. A1·A3·B17 등 세부 블록 점을 모든 장면에 상시 노출하지 않는다. 지도를 처음 보는 사람이 어디인지 알 수 있도록 지구 면적과 이름, 인접 생활권과 기준 철도 등 위치 단서를 함께 둔다.

단지를 설명할 때는 같은 토지이용 지도판 안에서 해당 단지와 주변을 충분히 크게 잡는다. 실제 계획상의 주거·학교·공원·상업·도로가 공간적으로 붙어 보여야 한다. 출처로 확인한 영역을 강조하고, 단지 이름만 떠 있는 점이나 동서남북 관계 상자로 이를 대체하지 않는다. 두 단지를 설명하면 두 영역과 주변을 읽을 수 있는 화면 구도를 정하고 겹치는 점을 그대로 두지 않는다.

세부 권역의 위치는 화면 왼쪽의 작은 전체 계획도로 안내한다. 현재 설명하는 지구의 계획도 한 개만 유지하고, 큰 상세도가 전체 계획도의 어디에 해당하는지 영역 테두리로 표시한다. 왕숙1 상세도에 왕숙2 계획도를 함께 띄우지 않는다. 2026-10-15 후속 피드백에 따라 왕숙 편에서는 동적 줌인·줌아웃과 잠깐 나타났다 사라지는 전체지도 전환을 사용하지 않는다. 지리 좌표 지도와 원도면 내부 좌표를 연결할 때에는 지구 위치 표시와 같은 이름·색을 남긴다. 정합되지 않은 두 지도를 정확히 겹쳤다고 표현하지 않는다.

상세도에 나오는 주요 블록은 사전에 공식 자료로 뜻을 조사한다. 블록 코드와 함께 공공분양·신혼희망타운 등 확인된 주택 유형, 학교·공원·상업·업무 등 계획 용도를 필요한 만큼 표시한다. 단지명·사업자·평형·입주 일정은 확인된 경우에만 추가한다. 색칠된 면과 코드만으로 시청자가 용도를 추측하게 두지 않는다.

같은 지도판을 계승하되 내용에 맞춰 정보를 바꾼다. 일자리는 검증한 기업·업무 부지와 CI 및 계획 상태, 교통은 운영 노선과 계획 노선, 생활은 학교·상권·공원 영역, 가격은 설명 중인 블록의 가격을 보여준다. 매 쇼트마다 동일한 전체 지도와 줌인·줌아웃을 반복하지 않는다. 한 구도를 유지하며 강조 레이어를 바꾸거나 인접 구역으로 이동하는 방식도 사용한다.

첨부·참고 이미지의 구도를 계승하는 것과 과거 철도 개통 표기를 복사하는 것을 구분한다. 공개 계획도의 이용 조건을 확인하고, 편집 가능한 원본이나 공개 공간 데이터에서 필요한 지도를 확보한다. 정합이 확인되지 않은 계획도와 실제 지도를 억지로 겹치지 않는다. 좌표 정합이 부족하면 계획도 자체 좌표에서 일관된 확대와 위치 안내를 제공한다.

## 날짜 설명과 권역별 결론

교통·학교·입주·분양·일자리 등 시간을 설명하는 동안 지도 아래에 가로 연도 축을 둔다. 같은 축에서 입주예정과 시설 개교·개통 목표를 비교해 시차를 읽을 수 있게 한다. 목표·예정·실제 운영을 구분하고, 상업시설 개점처럼 확인하지 못한 날짜는 미정으로 남긴다. 다른 지구나 노선의 목표 연도를 가져다 쓰지 않는다. 축과 라벨은 자막 흰 박스와 겹치지 않는다.

기존 생활권 비교는 설명하는 각 지역의 지도를 함께 보여주고, 실제 단지 영역과 역 위치에 가격을 연결한다. 전용면적·층·계약기간·취소 제외 기준·표본수와 중위값 여부를 같은 화면에 남긴다. 역이 지도에 있다는 이유로 모든 단지를 도보 역세권으로 묶지 않는다.

대장 후보는 권역별로 선정 이유와 우선순위가 바뀌는 조건을 설명한다. 왕숙 편의 일반 매매시장 후보에서 신혼희망타운은 제외한다. 일반 공공분양도 현재 자유롭게 거래할 수 있다는 뜻은 아니므로 공고별 전매제한·거주의무를 확인한다. 의무기간을 예정 입주월에 단순 더해 자유매매 연도를 계산하지 않는다. 미래 시세 선두를 보장하는 순위로 표현하지 않는다.

## 글자 잘림·인출선과 설명 대상 검수

SVG 시간축의 글자 baseline만으로 여백을 판정하지 않는다. 실제 렌더 폰트 로딩 뒤 `getBBox()`에 외곽선 두께의 절반을 더해 상하좌우 표시 영역 안에 들어가는지 모든 날짜 조합을 검사한다. 상단 글자에는 윗획 여백을, 하단에는 받침·내림획 여백을 남긴다. 긴 날짜 라벨과 오른쪽 미정 표시도 확인하고, 실제 MP4의 대표 시점에서 글자 전체를 다시 본다. `overflow: visible`만 주어 인접 지도·범례를 침범하는 방식으로 끝내지 않는다.

계획역을 설명하는 작은 지도는 현재 발화의 지구와 일치해야 한다. 왕숙역 설명에는 왕숙1 남측, 일패역 설명부터 왕숙2를 사용한다. 대본의 지역명만 바꾸고 작은 지도는 고정하는 오류를 막기 위해 실제 자막·문자 정렬 경계 전후 프레임을 확인한다. 일자리 설명처럼 이미 확대된 지도가 처음 등장하는 구간에도 해당 지구 전체판과 현재 상세 범위를 함께 둔다.

학교·공원·단지 인출선은 단어가 읽힌다는 이유만으로 통과시키지 않는다. 라벨에서 실제 대상 면까지 시선을 따라가 교차·엉뚱한 면 관통 여부를 확인한다. 가까운 대상은 라벨을 바깥으로 분산하고 수평·직각 선을 순서대로 배치한다. 문맥용 라벨을 줄여도 대상의 위치와 용도를 임의로 바꾸지 않는다.

## 추가 마무리 멘트와 아웃트로 간격

사용자 지정 CTA는 기존 음성을 보존하고 추가 멘트만 생성한다. 구독·좋아요 아이콘은 텍스트와 함께 짧게 진입한 뒤 안정적으로 유지한다. 대사 끝과 브랜드 시작 사이의 간격은 실제 음성·문자 정렬로 고정한다. 왕숙 v15는 마지막 발화 문자 종료부터 3초를 유지하며, 원본 PCM의 짧은 꼬리도 그 3초 안에 포함하고 음성은 자르지 않는다. 발화 종료가 음향 청취가 아닌 제공자 문자 정렬 기준이라면 검수 기록에 명시한다. 발화가 끝난 무음 유지 구간에는 빈 자막 흰 박스를 숨기고 CTA 화면을 유지한다. 기존 브랜드 아웃트로에는 흰 박스를 표시하지 않는다.

## 낭독문과 화면 자막의 표기 분리 — 2026-10-16 추가

음성 합성을 위한 읽기 표기를 화면에 그대로 노출하지 않는다. 자막은 `S1·S2·S5`, `DMC`, `GTX-A`, `LH`, `LX`, `300곳`, `2028년 1월`, `84㎡`, `3호선`, `7억 6,998만 원`처럼 읽기 쉬운 영문·숫자 표기를 사용한다. 숫자의 값·단위·공고 조건은 그대로 보존한다. 삼송 등 지명, 첫째 등 문장 구조를 이루는 서수, ‘첫 두 달’ 같은 자연스러운 표현은 무조건 숫자로 바꾸지 않는다. 타입명과 학교 코드도 공식 표기를 대조한다.

원문 `spoken_text`와 화면 `display_text`를 따로 저장하고 문자 정렬은 원문 기준으로 유지한다. 모든 치환의 전후·큐·원문 범위·사유를 기록한다. 자막을 연결해 낭독문과 글자 그대로 같아야 한다는 검사는 이 명시적 변환표를 적용한 뒤 수행한다. 최종 SRT뿐 아니라 번인 자막에도 같은 변환을 적용한다.

단지 설명은 실제 위치를 알아볼 수 있어야 한다. 이용 조건 때문에 특정 전체도를 확대하지 못하면 재가공 허용 원자료·공고 배치도·공개 공간 데이터로 대체 자료를 찾는다. 이름만 적힌 사각형과 동서남북 문장 패널을 상세지도 완성본으로 납품하지 않는다. 지구 경계와 역 예정 위치는 서로 다른 범례·형태로 표시하고, 미확정 역은 정밀 출입구처럼 표시하지 않는다.
