## 매번 읽는 핵심 체크리스트

### 2026-10-26 공통 화면 문구와 발화 대상 강조

- 시청자 화면의 ‘AI 개념 이미지’ 배지·푸터 등 제작 설명은 표시하지 않는다. 생성 여부·원본·프롬프트·출처·권리 기록은 제작 자산 기록에 유지한다.
- ‘공식 지수 아님’, ‘인과분석 아님’, ‘실제 장소 아님’ 등 불필요한 부정형 주석과 반복 면책 문구를 화면에 붙이지 않는다. 필요한 비교 기준·기간·단위·출처는 직접적인 사실 표기로 전달한다. 이 지침은 과거 화면용 배지·부정형 주석 지시보다 우선한다.
- 차트에서 회복 분기를 말하면 해당 관측점에 점·세로 가이드·분기 라벨을 표시한다. 비교 고점 기준선과 현재 발화 대상을 연결하고, 설명 순서에 따라 강조를 옮긴다. 예: 2024Q3의 회복을 말할 때 2024Q3 점과 비교 고점 수준을 함께 보여준다. 실제 데이터의 분기·값을 사용한다.
- 글자 잘림은 차트·도식 공통 결함으로 검사한다. 글꼴 로드 후 모든 SVG 텍스트의 실제 글자 경계와 상위 SVG 표시 영역을 대조하고 외곽선·여백을 포함한다. 글자의 기준점이 영역 안에 있다는 이유만으로 통과시키지 않는다. 최초 프레임·주요 값·가장 긴 라벨과 실제 MP4의 해당 구간도 확인한다.

### 2026-10-20 시청자용 대본의 쉬운 표현

- 데이터 집계·비교 조건을 설명하는 데 필요한 용어를 제외하면 기술·행정·제작 용어를 일상적인 말로 바꾼다. 합니다체는 유지한다.
- 예: ‘공개 기하 자료 재구성’→‘LH가 공개한 토지이용계획 자료를 바탕으로 다시 그렸습니다’, ‘사업시행기간의 종기’→‘사업 기간은 ○년 ○월까지’, ‘생활권 접점’→‘기존 시가지와 맞닿은 곳’.
- 중위값·전용면적·전매제한·거주의무처럼 비교와 권리 조건에 필요한 용어는 삭제하지 않고 처음 등장할 때 뜻을 풀어 준다. 숫자·날짜·대상·기간을 세기 시작하는 기준은 단순화 과정에서도 보존한다.
- 화면 지시·원문 출처·내부 파일의 정확한 기술 명칭과 낭독 문장을 구분한다. 대본만 고친 상태를 음성·영상까지 반영한 것으로 안내하지 않는다.
- ‘~는 아니고’, ‘~라는 뜻은 아닙니다’, ‘오해를 줄일 수 있습니다’처럼 시청자의 오해를 먼저 가정하는 화법을 기본 설명 방식으로 쓰지 않는다. 비교 기준과 판단 근거를 직접 전달하되 ‘제가·저는’으로 시작하는 개인 구입자의 시점은 피한다. ‘입지를 평가하는 기준은 ~입니다’, ‘가격·면적·접근성을 함께 비교하겠습니다’처럼 채널의 중립적인 분석 시점으로 설명한다. 필요한 가격 포함 범위·예정/운영·권리 조건은 긍정형 설명과 명확한 표기로 보존하며, 불확실한 사실을 확정 표현으로 바꾸지 않는다.
- 소제목은 ‘1. 일자리’, ‘2. 교통’, ‘3. 가격’처럼 번호와 주제만 표시한다. 제목 뒤 질문·평가·부연 설명은 붙이지 않는다. 설명은 낭독과 자료화면에서 전달한다.

- [ ] 분양지구 바깥의 대안도 비교한다. 비슷한 교통·인프라 조건과 실제 가격이 있는 대상을 고르고 불리한 대안도 숨기지 않는다.
- [ ] 거시 화면은 지구·주변 도시·철도 관계만 남긴다. A1 같은 블록 점을 항상 띄우지 않는다.
- [ ] 단지 화면은 공식 계획도에서 주거·상업·학교·공원·도로가 함께 보이도록 만든다. 점과 단지명만 떠 있는 지도는 사용하지 않는다.

- [ ] 상세도 왼쪽에 **지금 설명하는 지구의 전체 계획도 한 개**와 현재 영역 테두리를 둔다. 왕숙1과 왕숙2를 동시에 작은 지도에 넣지 않는다.
- [ ] **기본값은 고정 지도 구도다.** 왕숙에서 동적 줌인·줌아웃은 최종 철회됐다. 잠깐 전체판을 끼운 뒤 상세판으로 바꾸는 전환도 금지한다.
- [ ] 설명 내용이 바뀌면 해당 레이어·대상·범례도 바꾼다. 동일 지도판을 무관한 내용 내내 반복하지 않는다. 지도 안 대상 가까이에 짧게 요약한다.
- [ ] 철도는 실제 지리와 공식 계획 근거에 맞춰 노선·역을 함께 표시한다. 계획역과 운영역, 확정 위치와 개략 구역을 다르게 표시한다.

- [ ] 시점을 말하면 가로 연도축에 입주와 개교·개통·공급·일자리 시점을 비교한다. 미정은 미정으로 남긴다.

- [ ] 수량·단위·역명·블록명·날짜를 보호해 의미 단위로 자막을 나눈다. `8만 / 114세대`처럼 자릿수를 쪼개지 않는다.

## 재작업과 토큰을 줄이는 작업 계약

1. **시작 계약 한 장:** 기준 본편/브랜드/대본/데이터와 이번 편의 차이, 변경 금지 영역, 현재 승인 범위를 episode preflight에 기록한다. 이 파일과 해당 장면의 입력만 읽는다.
2. **구조 먼저:** 다섯 분석 질문과 결론을 짧은 장면표로 확정한다. 소스/화면 목적이 없는 문장은 추가 조사하거나 삭제한다. 음성까지 만든 뒤 전체 플롯을 바꾸는 비용을 피한다.
3. **대표 장면 먼저:** 전체지도→상세도 locator, 철도/역, 긴 날짜축, 가격 비교, 후보 결론, CTA를 저해상도 대표 시안으로 먼저 검사한다. 사용자에게 전체 본편 적용이 승인됐다고 간주하지 않는다.
4. **공통 결함 먼저:** 자막 박스·SVG 잘림·레이어 정렬 같은 공통 컴포넌트는 가장 긴 문구/최악 조건으로 검사하고 전체 렌더에 확장한다. 같은 결함을 타임코드마다 수동 패치하지 않는다.
   편집 도구도 전체 렌더 전에 작은 실증으로 확인한다. 실제 사용할 FFmpeg의 PCM 출력·AAC 컨테이너·프레임레이트 변환·디코드 검사를 짧은 WAV/2프레임 MP4로 끝까지 시험한다. Remotion 내장 바이너리에 일반 FFmpeg의 모든 muxer·filter·기본 encoder가 있다고 가정하지 않는다. 지원하지 않는 기본 null encoder를 실행한 실패를 디코드 성공으로 기록하지 않으며, 대체 검증은 전체 프레임 디코드 수와 오류 출력을 남긴다.
5. **변경 목록 한 개:** issue_id, 장면ID, 사용자 요구, 최종 지침, 담당, 영향 파일, 재검수 증거를 기록한다. 최신 결정이 과거 지침을 대체했는지 표시한다.
6. **부분 생산:** 변경 장면만 렌더하고 변경 문장만 생성한다. 승인 원문 문자 정렬·원본 음성·캐시 지도·검증 데이터는 재사용한다. 전체 재생성은 의존관계 때문에 필요한 경우로 한정한다.
7. **읽기·위임 최소화:** 역할은 필요한 담당만 실행하고 소유 파일을 나눈다. 새 담당에게는 가능하면 대화 전체 상속 없이(`fork_turns='none'`) 역할 지침·절대 입력 경로·짧은 확정 요약·소유 범위만 전달한다. 원문 피드백 감사처럼 전체 대화가 꼭 필요한 작업은 예외다. 관련 후속 작업은 기존 담당을 재사용한다. 이미 확인한 자료는 요약+근거 경로를 넘긴다. 중복 전체 탐색, 매번 모든 역할 소집, 거대 로그·이미지 base64 출력은 피한다.
8. **통합 한 번:** 부분 검수 뒤 타임록과 음성 믹스를 고정해 통합한다. 컷 앞뒤를 프레임으로 확인하고 최종 해시로 검수와 납품을 묶는다. 파일을 패키징한 뒤 메타데이터를 추가 변경하지 않는다.
9. **예외 재개:** 승인 대기/도구 실패를 조용히 방치하지 않는다. 무엇이 완료됐고 무엇이 막혔는지 알린다. 상시 무인 실행이 보장되지 않으면 보장한다고 쓰지 않는다.
10. **용량 정책:** 최종 납품, 재현 소스·의존 자산, 원본 조사 데이터, 승인·검수·권리 근거는 남긴다. 중간 MP4·중복 패키지·캐시는 의존성 검사와 삭제 목록 확정 뒤 제거한다. 이미지 증거가 삭제되면 검수 기록에 보존 위치를 연결한다.

## 상세 제작·검수 규칙

### 지도 정확성과 가독성

역 위치는 공식 계획·공고·운영사 자료를 먼저 대조하고 기사/나무위키는 탐색과 보조 교차검증에 쓴다. 지도판 좌표와 지리 좌표를 구분한다. 개략도에서 정확한 역 출입구 위치를 읽어내지 않는다. 왕숙역 설명에 일패역/왕숙2 계획도를 띄우는 것처럼 발화와 inset이 다른 오류를 막기 위해 원문 정렬 경계 전후를 검사한다.

원도면의 주거·학교·상업·업무·공원 블록 코드를 미리 조사한다. 정확히 정합되지 않은 두 지도를 강제로 겹치지 않고, 한 계획도 안의 전체판과 상세판을 연결한다. 인출선은 대상 면을 옮기지 않고 라벨을 밖으로 분산해 수평/직각으로 정리한다. 텍스트가 읽혀도 선이 교차하거나 다른 면을 관통하면 실패다.

SVG 날짜축은 폰트 로드 뒤 실제 글자 `getBBox()`와 외곽선 절반을 합쳐 화면 범위와 대조한다. baseline 또는 `overflow:visible`만으로 통과시키지 않는다. 가장 긴 날짜·우측 미정·상하 획을 포함해 모든 조합과 실제 MP4를 확인한다.

세부 예시와 색/자료 규칙: [지역 상세 지도와 의미 단위 자막](지역_상세지도와_의미단위_자막.md).

### 음성·자막·끝 처리

브랜드를 음성 문단 사이에 넣을 때 브랜드 종료 프레임부터 다음 본문 장면을 선택한다. 다음 발화의 정렬 시작이 한 프레임 뒤여도 이전 훅 화면을 fallback으로 되살리지 않는다. 삽입 경계 직전·종료·직후를 실제 인코딩 프레임 번호로 추출해 검사하고, 인접 프레임 PNG 추출은 프레임 드롭을 막는 passthrough 설정을 사용한다. 합성 클립의 색 형식 변경 등으로 필터가 재초기화되면 `select(n)`의 카운터가 다시 시작할 수 있다. 글로벌 PTS 또는 연속 디코드 출력 순번으로 경계를 독립 대조하고, 이미지 파일명만으로 원본 프레임 번호를 확정하지 않는다.

낭독용 한글 읽기 표기와 화면 표기를 분리한다. 자막은 S1·DMC·2028년·300곳·84㎡처럼 숫자·영문을 읽기 쉽게 쓰고, 승인 원문 span과 표시문 변환표를 보존한다. 이 명시적 변환을 적용한 뒤 자막을 연결 대조하고 숫자·단위·고유명사 누락/중복을 검사한다. 삼송 같은 지명은 숫자로 치환하지 않는다. 문자별 원문 정렬이 있으면 저장해 의미 자막을 연결한다. 발음 정규화 텍스트를 원문으로 추정하지 않는다. 정렬 없는 배분은 추정이라고 표시한다.

CTA 3초는 마지막 **발화** 종료를 기준으로 한다. 왕숙 v15는 제공자 문자 정렬의 마지막 발화 문자를 사용했고 실제 청취 기준은 아니었다. 원본 PCM 꼬리를 자르지 않고 그 3초에 포함했다. 다음 편에서도 선택한 종료 기준과 실제 샘플/프레임 수를 기록한다. 중간 무음에 흰 박스가 깜빡이는 것과 의도된 무발화 브랜드 예외를 구분한다.

### 사실과 비교

자료의 관측일·게시일·계획 기준일을 구분한다. 미래 목표는 현재 운영이 아니다. 학교 계획·심사 통과가 개교를 뜻하지 않는다. 투자액과 실제 고용, 기업 소재와 통근 편의, 개통과 가격 상승의 인과를 분리한다. 전매제한/거주의무는 해당 공고로 확인하고 예정 입주월에 기간을 더해 자유매매 연도를 만들지 않는다.

차트는 원거래를 같은 조건으로 묶어 직접 집계한다. 월별 중위값 평균을 분기 중위값으로 쓰지 않는다. 빈 분기와 소수 표본 표시, 지역/단지/가격 단위의 구분은 [광교·동탄 분기차트 검토](../../docs/영상_v10_맥락_차트_CI_검토_2026-10-13.md)를 따른다. 역사적 문서의 당시 미해결 항목을 현재 확정 사실로 승격시키지 않는다.

### 브랜딩·쇼츠·공개

전편 브랜딩의 구체 사례는 [브랜드와 BGM](../../docs/영상_v12_BGM_브랜딩_2026-10-14.md), 검색/첫5초 효익 문구는 [도달 전략](../../docs/영상_v13_도달전략_적용.md)을 참고한다. 제목은 지역명+핵심 선택 문제+검증 범위를 분명히 하고 본문이 뒷받침하지 않는 상승 보장·과장된 대장 단정을 피한다.

쇼츠는 한 문제·한 근거·한 결론이 끝나는 구간을 고른다. 세로 화면에서 지도/숫자/자막을 새로 읽히게 배치하며 롱폼을 중앙 크롭만 하지 않는다. 본편의 중요한 조건·예정 표시를 자르지 않는다. 단독 가치와 본편으로 이어지는 설명을 함께 둔다. 개수·길이·업로드 간격을 영구 고정하지 않으며 추천 노출을 보장하지 않는다.

최종 공개는 영상ID, 공개 상태, 처리 결과, 실제 적용 메타데이터를 조회해 기록한다. HD 처리 성공, Content ID, Studio 검수, 자막 업로드, 쇼츠 관련영상 설정은 서로 다른 확인 항목이다. OAuth 범위가 없으면 미적용으로 남긴다. [이전 업로드 기록](../../docs/영상_v14_업로드_완료_2026-10-14.md)은 당시 비공개 상태를 설명하는 역사 자료이며 현재 상태 증거가 아니다.

## 대본 단계에서 자료화면 확정

[자료화면 설계 원칙](자료화면_설계_원칙.md)을 모든 영상에 적용한다. 낭독 문장별 자료화면·강조 동작·근거·확보 상태·대안을 장면표에 적는다. 텍스트 PPT를 기본 화면으로 두거나 장마다 같은 화면 지시를 복사하지 않는다. 기업·상업시설은 구체적인 사업·참여기관·추진 단계·사업기간을 조사해 추가한다. 사용자 유지 대상은 따로 고정한다. 교산 대장 후보는 기존 토지이용계획도 구성을 유지한다.

## 추적과 적용

전체 요청/최종 우선순위: [사용자 피드백 이력](사용자_피드백_이력.md). 기계 점검 입력: [episode preflight](../templates/episode_preflight.json). 필수 규칙은 모든 새 편에 적용하되 왕숙의 특정 블록·날짜·가격·역 좌표는 다음 도시로 복사하지 않는다. 현재 문서는 제작 운영의 기본값이며 새 유료 호출·외부 전송·공개 권한을 부여하지 않는다.
