## 설명은 질문→증거→생활의 의미→판단으로 묶는다

한 장에 한 가지 선택 질문을 둔다. 위치를 보여준 다음 그 질문에 답하는 근거를 읽고, 입주자에게 생기는 변화와 공백을 설명한 뒤 조건부 판단으로 닫는다. 조사 목록·주의사항을 길게 읽는 것으로 끝내지 않는다. 같은 항목으로 대안을 비교하고 마지막에 처음 질문을 회수한다.

예를 들어 ‘교통계획에 버스 지원이 있다’에서 멈추지 않는다. 현재 이용할 수 있는 교통과 새 철도의 목표를 구분하고, 입주 달력과 나란히 놓아 초기 출근에 어떤 공백이 있는지 보여준다. 아직 모르는 노선은 선을 임의로 그리지 않고 ‘노선·운행일 미확인’으로 짧게 표시한다. 주의사항은 해당 근거 옆에 붙인다.

## 자료 종류는 설명의 기능에 따라 고른다

| 설명 목적 | 주자료 | 보조자료·배치 |
|---|---|---|
| 어디인가 | 검증된 광역 지도·전체 계획도 | 위치 맥락을 먼저 제시. 거시 지도에 모든 블록 핀을 넣지 않는다. |
| 단지 주변에 무엇이 있는가 | 권리가 허용하는 상세 계획도 또는 독립 사실 관계도 | 좌측에 현재 지구 위치 기준, 본문에 대상과 가까운 짧은 라벨. 도면 변경금지 권리가 있으면 오버레이·크롭하지 않는다. |
| 무엇이 근거인가 | 공고·공식 자료의 읽을 수 있는 발췌/직접 작성 사실표 | 발화에 해당하는 행만 강조. 전체 PDF 축소 화면을 읽으라고 하지 않는다. |
| 언제 쓸 수 있는가 | 가로 시간축 | 입주·학교·교통을 별도 lane에 표시. 목표/예정/미정과 날짜 정밀도 보존. |
| 얼마나 드는가 | 동일 조건 비교표·검증 거래 차트 | 기본가·확장비·세금 제외, 기간·면적·n·중위값을 분리. 지도와 표가 겹치지 않게 한다. |
| 생활에서 어떤 모습인가 | 해당 장소·이용조건이 확인된 사진/직접 촬영 | 실제 장소 확인 전에는 일반 자료화면으로 표기. 멋진 오피스가 기업 유치 확정의 증거가 되지 않게 한다. |
| 자료로 설명하기 어려운 개념 | 독립 비교 도식·필요시 AI 개념 이미지 | 사실 지도·계획도·완공 모습을 AI로 대체하지 않는다. 미합의 생성 이미지는 제작표에 공백으로 남긴다. |

항상 같은 지도판을 틀어놓는 것도, 재미를 위해 자료를 무관하게 교체하는 것도 피한다. 설명 질문이 바뀔 때 자료의 기능을 바꾼다. 고정 지도 옆 자료 교체는 원문 근거가 필요할 때만 쓴다. 지역 상세 설명의 요약은 기존 기준대로 지도 안 대상 가까이에 둔다. 우측에 긴 글 목록을 상시 띄우지 않는다.

## 모션은 정보를 가리키는 용도로 제한한다

레퍼런스 정지 프레임은 강조 상태의 증거이지 실제 애니메이션의 증거가 아니다. 아래는 우리 제작 제안이다.

- 지도 카메라는 고정한다. 반복 줌·급격한 팬·순간 전체판 삽입을 부활시키지 않는다.
- 새 근거가 나올 때 대상 윤곽·노선·표의 해당 행·달력의 해당 시점 중 하나만 강조한다. 읽는 동안 강조와 위치를 유지한다.
- 제목·자막·출처는 지도 변환과 분리한다. 긴 문장 등장마다 화면을 갈아치우지 않는다.
- 자료 교체의 유지 시간은 실제 발화와 읽을 분량으로 정한다. 효과를 위한 1프레임~1초짜리 설명판은 금지한다.
- 동일 대상의 근거가 이어지면 베이스는 유지하고 필요한 레이어만 바꾼다. 다른 권역은 일관된 locator와 이름으로 알린다.

## 효과음·BGM: 관찰과 제작 제안을 구분한다

**세 레퍼런스의 효과음은 실제 청취 미검증이다.** 특정 시점에 클릭·우시·종소리가 있다고 주장하지 않으며 원영상 음원을 추출해 쓰지 않는다. 아래는 창릉에 적용할 편집 제안이며 최종 사용 여부는 실제 음성과 함께 청취해 정한다.

| 용도 | 제안 | 피할 것 |
|---|---|---|
| 큰 장의 시작 | 짧고 부드러운 단일 전환음, 필요할 때만 | 모든 컷·모든 자막마다 반복 소리 |
| 핵심 가격·달력 대비 등장 | 가벼운 클릭/탭 후보 1회. 숫자를 읽는 음성을 가리지 않게 배치 | 현금·상승 효과음으로 투자 수익 확정 인상 |
| 계획과 현재의 차이 | 우선 시각적 상태 구분. 소리는 없어도 됨 | 경고음 남발·불필요한 긴장감 |
| CTA | 기존 브랜드와 어울리는 짧은 확인음 후보 | 음성 감사 멘트·아웃트로 첫 음 충돌 |
| 본문 BGM | 기존 이용허락 자산을 낮게 깔고 발화 구간 덕킹 | 레퍼런스 음원 복제·본문 음악 과다 |

각 큐에 scene_id, 원문 트리거, 목적, 음원 경로·사용조건, 시작/끝, gain/ducking, 청취 결과를 남긴다. 타임록 전에는 초 단위를 확정하지 않는다. 실제 청취 때 휴대폰 스피커·이어폰 기준으로 자음/숫자 가림, 누적 피로, 갑작스러운 음량 차이, 브랜드 접합을 확인한다. 새 유료 음악·효과음·생성 호출은 현재 권한에 포함되지 않는다.

## 제작 전 확인

- 대표 시안 3종: 교통 지도+달력, 가격 근거표, 단지 생활 관계도. 한 번에 전편을 렌더하지 않는다.
- 각 장마다 질문·주자료·강조 대상·판단 한 문장이 있는지 확인한다.
- 지도/사진/원문/차트의 역할이 중복되거나 내용과 어긋나는지 확인한다.
- 효과음은 ‘없음’도 정식 선택이다. 실제 청취 전 audio_qa를 통과로 기록하지 않는다.
- 대본·예산 승인 파일은 변경하지 않는다. 낭독을 바꾸면 새 대본 버전과 해당 승인이 필요하다.
