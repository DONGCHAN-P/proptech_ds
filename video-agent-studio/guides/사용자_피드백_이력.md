## 2026-10-25 집 공간 중심 방식 수락·다음 장면 진행

- `household-space-v1`의 거실·원룸·생활 소품·완만한 화면 전환 방식에 “맘에들어 다음”이라고 답했다. 해당 가구 분리 장면과 시각 방향을 수락한 기록으로 남기고 다음 장면에 계승한다. 대본 변경·유료 음성·업로드 또는 전체 본편 완료 승인으로 확대하지 않는다.

## 2026-10-25 가구 분리 시안의 집 구도 유지·보행 대체

- 사용자는 인물 교체 시안 v3도 마음에 들지 않는다고 했으며, 집을 보여주는 구도는 좋지만 걷기가 이상하다고 지적했다. 집 단면 구도는 계승한다. 해당 설명 장면에서는 같은 보행 리그의 미세 보완을 반복하기보다 공간·생활 소품·차분한 카메라 전환으로 가구 분리를 표현한다.
- 기존 집과 자녀가 별도로 마련한 집을 구분해 한 집을 물리적으로 쪼갰다는 오해를 피한다. 실제 통계가 아닌 가상 예시임을 유지한다. 새 공간 중심 시안을 사용자의 확정 스타일 또는 본편 전체 반영으로 기록하지 않는다.

## 2026-10-23 논문 영상의 인물·모션 품질 수정

- 원형 머리와 선으로 된 동일한 막대 인물을 반복하고, 고정된 자세의 그림 전체를 미끄러뜨리는 연출을 저품질로 지적했다. 인물이 필요하면 역할·방향·복장·자세가 있는 원화를 사용하고, 이동은 걷기·정지·접지를 설계한다. 인물이 설명에 기여하지 않는 곳은 실제 지도·사진·데이터의 관계를 중심으로 구성한다.
- 사실·자막·디코드 검수 통과를 미감 합격으로 취급하지 않는다. 전체 렌더 전에 대표 장면에서 형태·시선 유도·의미 있는 움직임을 확인한다. 단순한 효과 추가나 유료 도구 설치를 품질 개선의 근거로 내세우지 않는다.
- 기존 대본과 본편은 보존하며 교체 방향은 별도 짧은 시안으로 비교한다. 이번 음성 생성 보류와 로컬 확인 범위는 유지한다.

## 충돌을 해결한 최종 우선순위

1. **확대 요청 → nozoom:** 공간 관계를 이해시키려는 목적은 유지하고, 수단은 W39·W40·W44의 고정 상세도+한 개 locator로 대체한다. 이전 zoom 장면 요구를 자동 재현하지 않는다.
2. **모션 요청 → 급전환 제거 → CTA 모션:** 반복 지도 카메라는 제거하지만 노선 설명/대상 강조와 사용자 지정 CTA 진입까지 금지한 것으로 일반화하지 않는다.
3. **흰 박스 지속 → 브랜드/무음 예외:** 본문 큐 사이에는 유지하고 무발화 브랜드/마지막 CTA hold에서는 숨긴다.
4. **블록 대장 → 일반시장 권역 후보:** 블록 지명만 고르는 방식에서 거래 조건·주택 유형·권역별 장점을 설명하는 조건부 후보로 발전했다. 왕숙에서 정한 B1/B2/B17/A3/A1을 다른 편에 그대로 복사하지 않는다.
5. **전면 재설계 허용 → 지정 baseline 부분 수정:** 최초 기획 자유와 후반 특정 수정 범위는 다르다. 후반 요청은 해당 baseline과 요구 부분만 수정한다.
6. **AI 활용 가능 → 장면별 필요/비용/합의:** GPT 이미지 도구를 적극 활용할 수 있으나 정확한 계획도·실제 사진 대체와 무제한 유료생성으로 확대하지 않는다.
