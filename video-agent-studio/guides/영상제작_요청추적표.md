# 영상 제작 요청 추적표

정리일: 2026-10-27 · 함께 쓰는 문서: [영상 제작 마스터 가이드](영상제작_마스터가이드.md)

## 검토 범위와 표 읽는 법

**검토한 ‘전체’는 이 작업에서 접근 가능한 현재 대화와 지정 로컬 제작 기록이다.** 다른 채팅방·원문이 없는 과거 대화·사용자가 보지 못한 내부 작업까지 전부 열람했다고 주장하지 않는다. 직접 대화의 요약과 로컬 문서가 전하는 요구를 구분한다. 날짜가 없는 직접 요청은 순서로만 추적하고 날짜를 추정하지 않는다.

| 근거 기호 | 실제로 확인한 것 | 해석 범위 |
|---|---|---|
| C | 현재 제공된 사용자 대화와 승인 답변 | 아래 C01~C45는 이를 요약했다. 문구가 따옴표 안에 있을 때만 짧은 직접 표현이다. 개별 발화일은 불명인 항목이 많다. |
| L-W / L-G | [사용자 피드백 이력](사용자_피드백_이력.md)의 W01~W62 / G01~G28 | 이번 작업은 그 정리본을 읽었다. W도 이번 현재 대화에 원문이 없는 경우 로컬 이력 근거로 분류한다. G는 광교·동탄 로컬 제작 문서가 전하는 내용이다. 원문 채팅 직접 확인으로 승격하지 않는다. |
| L-A | 같은 피드백 이력의 날짜 있는 후속 항목 | 표기된 날짜는 해당 문서가 기록한 날짜다. 현재 플랫폼 상태·완료 여부를 재확인한 날짜가 아니다. |
| B | 기본·상세 가이드와 WORKFLOW | 운영 방법과 검증 기준을 보완한 근거다. 가이드에 적힌 모든 구현 숫자를 사용자 직접 발언으로 취급하지 않는다. |
| V | [직접 녹음 영상 가이드 v1](../../영상/매매가격계산/영상가이드_직접녹음_v1.md) | 새 DOCX를 기준으로 한 현지 설계 문서다. 원고·음성·시안·영상·최신 정책 전체의 최종 합격 증거는 아니다. |

상태는 **공통**(다음 편에도 적용), **편별**(해당 편·버전·자료에 한정), **대체**(후속 결정이 해당 수단/대상을 변경), **보류**(명시적으로 미실행), **기록**(작업 요청·확인 질문의 이력)으로 표시한다. 공통 기준과 편별 선택이 함께 성립할 수 있다. 이 표는 영상별 실제 승인·예산·게시 기록을 대체하지 않는다. ‘확인 기준’은 앞으로 충족 여부를 판단할 항목이며, 이번에 모두 실행했다는 뜻이 아니다.
