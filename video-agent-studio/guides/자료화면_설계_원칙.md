# 대본과 함께 설계하는 자료화면

2026-10-20 사용자 요청. 모든 영상의 신규·수정 대본에 적용한다. 채널의 기존 서체·색·자막·브랜드는 계승한다.

대본 단계에서 **어떤 문장에 무엇을 보여줄지** 결정한다. 제목과 글머리표를 읽는 PPT형 화면을 본문 기본값으로 사용하지 않는다. 텍스트는 지도·사진·원자료·그래프에서 볼 대상을 짧게 안내하는 역할로 쓴다.

## 장면표 필수 항목

| 항목 | 기록할 내용 |
|---|---|
| 낭독 연결 | 장면 ID와 문장·의미 단위 |
| 화면 목적 | 위치·규모·가격·시간·인과 중 전달할 것 |
| 자료화면 | 지도, 공고 원문, 기사 근거, 현장 사진·영상, 그래프, 모션그래픽, 생성 개념 이미지 |
| 동작 | 발화에 맞춰 나타나거나 강조되는 대상 |
| 근거 | 원문 URL·날짜·파일·쪽수·집계 조건과 이용조건 |
| 준비 상태 | 확보 / 제작 예정 / 위치 검증 필요 / 사용허락 필요 / 비용 승인 필요 |
| 대안 | 자산을 못 구했을 때 같은 정보를 전달할 방법 |

장마다 공통 지시 한 줄을 복사한 것은 설계 완료로 인정하지 않는다. 화면 지시는 낭독과 분리한다. 음성 확정 전에는 문장으로 연결하고, 초 단위 타이밍은 실제 정렬 후 고정한다.

## 내용별 기본 화면

- 입지·단지·상권·직장: 실제 경계·위치가 있는 지도. 전체 위치지도와 상세도를 연결하고 말하는 필지·시설·경로를 강조한다. 임의 점·사각형을 정확한 배치처럼 쓰지 않는다.
- 기업·상업시설: 구체적인 사업명·위치·참여 예정 기관·추진 단계·기간을 조사한다. 발표 요약을 지도에 연결한다. 참여 계획·계약·착공·실제 입주·채용·개점을 구별한다. 고용유발 기대효과를 실고용으로 쓰지 않는다.
- 분양가: 공고의 해당 행과 기본가→확장비→합계 그래픽. 실거래는 지도에 가격·거래건수·면적·집계기간을 함께 표시한다.
- 교통: 운영/계획 상태·노선색을 구분한 경로. 시간 추정은 출발·목적지·대기·환승 등의 조건을 붙인다.
- 일정·공급: 가로 달력과 단계별 그래픽. 공개된 날짜·물량만 배치한다.
- 생활시설: 주거와 공원·상가·학교 배치, 도로 횡단과 이동 경로를 보여준다. 학교는 가격·수요의 보조 요소다.
- 원리 설명: 비용 누적·환승 단계·공급 시차 등 관계를 모션그래픽으로 보여준다. 움직임은 발화 대상을 찾게 하는 데 쓴다.
- 미래 생활·추상 개념: 필요한 경우 이미지·조각 영상을 생성한다. 최신 공통 지시에 따라 시청자 화면에 ‘AI 개념 이미지’ 배지를 붙이지 않는다. 생성 여부·프롬프트·권리·파일은 내부 자산 기록에 남기고 실제 현장·공식 조감도·확정 평면을 증명하는 자료처럼 쓰지 않는다. 기존 예산 밖 유료 생성은 예산 게이트를 따른다.

## 유지와 검수

반복 줌인·줌아웃, 한 프레임 위치 안내, 반짝임, 빠른 전체지도 삽입을 피한다. 고정 지도에서도 윤곽·경로 진행·가격 막대 변화로 시선을 이끈다. 읽을 시간을 확보하고 다양성만을 위해 전환하지 않는다.

사용자가 선호한 구간은 유지 대상으로 장면표에 적는다. **교산 대장 후보는 현재 토지이용계획도 구성을 유지한다.** 다른 장의 다양화 요청을 근거로 이 구간까지 추상 도표로 교체하지 않는다.

전체 렌더 전 지도·가격·모션·원자료 유형별 대표 장면을 실제 확인한다. 잘림·가림·선 교차·글자 크기·발화 대상과 강조 대상 일치를 검사한다. 모션은 연속 프레임으로 확인하며, 실제 청취·연속 시청 여부는 별도로 기록한다.
