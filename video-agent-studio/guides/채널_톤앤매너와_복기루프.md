# 채널 톤앤매너와 복기 루프

2026-10-16. 창릉 visual-review-v2가 전편과 이질적이라는 사용자 피드백을 반영한다. 최신 사용자 구도·색·텍스트 요구가 있으면 그 요구가 우선한다. 기준은 실제 게시 왕숙 v15와 직전 광교·동탄 v14이며, 외부 세 레퍼런스는 설명 기법 보완용이다.

## 기준을 한 번 고정한다

`config/current_video.json`의 왕숙 v15 MP4와 `config/video_style.json`의 광교·동탄 v14 MP4, 해당 소스와 토큰을 최초 한 번 확인한다. 창릉 `visual/channel-style-v1/style_tokens.json`과 `outputs/channel-style-v1/comparison_contactsheet.png`를 재사용한다. 매 작업마다 전체 영상을 다시 읽거나 다운로드하지 않는다. 소스 숫자는 구현 근거, 인코딩 프레임은 실제 보이는 결과의 근거로 구분한다.

왕숙의 크림 바탕·Pretendard 일반/굵게·작은 브랜드 행·굵은 제목·실제 지리/계획도 중심·얇은 연도축·고정 흰 자막 박스를 계승한다. 광교·동탄의 사진/차트 다양성은 계승하되 과거 검정 외곽 셸을 왕숙 최신 기본값에 다시 덧씌우지 않는다. 지도는 고정 구도이며 내용에 맞춰 대상과 레이어가 바뀐다. 상세도는 해당 지구 전체도 locator와 현재 범위를 연결한다.

## 반드시 실행하는 최소 루프

1. **실제 기준 프레임 복기:** 철도 W15_175/235, 가격 W15_650, 생활 상세 W15_365를 해당 새 장면 옆에 놓는다. 메시지와 자료 기능을 맞추며 타 도시 수치·노선·배치는 복사하지 않는다.
2. **같은 메시지 새 판 비교:** 최신 승인 대본과 검증 데이터 그대로 새 판을 렌더한다. 비교표에 폰트/굵기, 색, 제목·지도·출처·자막 좌표, 정보량, 강조 대상을 기록한다.
3. **필수 차이 수정:** 얇고 큰 제목, 큰 설명 부제, 상시 우측 장문, 중앙 대형 미확인·면책 글을 제거/축약한다. 주의는 필요한 데이터 옆 작은 조건으로 남긴다. 실제 자료·숫자·생활 의미가 화면의 주인공이어야 한다. 정보가 부족한 곳에 경고 문장으로 면적을 채우지 않는다.
4. **대표 3종 내부 QA 후 확장:** 지리 교통+달력, 가격 근거, 생활 상세를 실제 크기와 축소 화면에서 확인한다. 잘림·겹침·선 교차·발화 대상·지도 범위·출처·숫자·자막을 통과한 공통 컴포넌트만 전체로 확장한다. 사용자에게 매번 디자인 승인을 요청하지 않는다.
5. **모든 컷 검사:** 장별로 해당 기준 프레임과 입력만 읽는다. 각 컷 대표와 경계 전후를 실제 MP4에서 확인한다. 최종 통합 후 변경된 장면과 연결부를 다시 확인하고 검수 해시를 남긴다. 공통 컴포넌트 변경 시 영향 컷 전체가 재검수 대상이다.

각 단계는 검수표에 증거 경로·판정·수정·재검수 경로를 남긴다. 샘플 프레임 확인, 연속 재생, 실제 청취는 별도 상태로 기록한다. 대표 세 장의 통과는 본편 전체 통과가 아니다.

## 외부 레퍼런스의 한계

기존 `레퍼런스_설명과_자료연출.md`와 세 분석 보고서만 재사용한다. 질문→근거→생활의 의미→조건부 판단, 현재 대상만 강조, 원문/지도/사진/차트의 기능 교체를 보완한다. 외부 영상의 색·자막·브랜드를 그대로 가져와 채널을 갈아엎지 않는다. 효과음은 실제 청취 전 미검증이다. 원영상 프레임·음원 재사용 권한은 별개다.
