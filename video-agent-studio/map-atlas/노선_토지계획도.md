# 노선·토지계획도 추가 · 2026-10-18

## 사용

기본 단지 지도에서 지하철 레이어를 켜면 경로와 역이 함께 나온다. 상세 설정의 ‘노선 색상·경로’로 선만 끌 수 있고, 기존 노선 선택으로 특정 노선을 강조한다. 색상은 OSM route 관계의 colour 태그를 사용하며 잘못된 값·미기재는 회색으로 처리한다.

상단 ‘토지계획도’ 버튼 → 창릉·왕숙1·왕숙2·교산·대장·계양 중 선택. 용지를 클릭하면 용도명을 확인한다. 범례와 ‘지구 전체 보기’를 제공한다. 모바일은 ‘토지계획도’ 선택 뒤 ‘지구·범례’를 누르면 지구 선택 패널을 연다. 단지 지도로 돌아가면 이전 지도 위치를 복원한다.

## 원자료

- 노선: OpenStreetMap route 관계 235개에서 member way 좌표를 추출·중복 제거했다. 22개 노선군의 경로를 수록했다. 단순한 역 좌표 순서 연결이 아니다. 지역 밖 부분과 플랫폼 way를 제외했다. 원본 `layers/raw/rail_routes_geometry_osm.json`, 가공 `layers/processed/overlays.json`.
- 경로와 역은 자료가 다르다. 역은 KRIC 기존 자료로, 선로는 OSM 커뮤니티 경로로 표시한다. 누락 노선/구간, 시점 차이, 역 중심과 선로의 오차가 있을 수 있다. GTX·김포 등 모든 노선을 수록한 것으로 주장하지 않는다. 신설 계획역이나 공식 측량 선형도 아니다.
- 경로 출처·라이선스: https://www.openstreetmap.org/copyright (ODbL 1.0). 데이터 수집은 공개 Overpass 정상 GET으로 수행했다. 타일 수집과 별개이며 원자료를 보존했다.
- 계획: https://wherehome.lh.or.kr/lhmap.do?mainTabNo=12 공개 WFS의 실제 공간 도형. 2026-10-18 조회, 계획 승인 기준일 필드 미표기. 원본 3,290개 feature를 Polygon 파트 3,451개로 렌더링한다. 왕숙2 원본 115개 MultiPolygon feature가 276개 파트로 나뉘므로 이 숫자를 단지 수로 해석하지 않는다.
- 계획은 용도·블록과 지리 관계를 표시하며 현재 준공·입점·개교 상태를 나타내지 않는다. 별도 사이트에 원자료를 재배포할 때의 포괄 라이선스 확인 완료를 주장하지 않는다. 현재 로컬 검토용이다.

원본·SHA·데이터 타임스탬프·지구별 건수: `layers/overlay_validation.json`. 좌표는 EPSG:4326에서 EPSG:5179로 변환했다. 기존 보드 이미지를 임의로 지리 정합하거나 도로·역 위치를 추정하지 않았다.

## 검증

`qa_overlays.py`: 데이터 로드, 노선 선 표시, 선택 노선 필터, 색상 형식, 창릉 계획 화면, 용지 클릭, 왕숙 전환, 이전 단지 화면 복귀를 실제 Chromium에서 확인. 생성한 두 화면을 직접 확인했다. 데스크톱·모바일 기존 UI 회귀는 `qa_ui_v3.py`에서 확인했다. 실제 현장·모든 노선의 측량 정합성 검증은 아니다.

재현: `prepare_overlays.py` → `build.py` → QA. 이전 화면은 `versions/v4-before-rail-plans/`에 보존했다.
