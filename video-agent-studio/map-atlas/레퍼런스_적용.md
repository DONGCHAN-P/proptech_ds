# 지도 탐색 화면 적용 기록

2026-10-18 사용자 제공 호갱노노 지도 전체 및 단지 클릭 화면을 참고했다. 사이트 직접 요청은 403, 연결된 브라우저는 없음. 따라서 실제 클릭·드래그·줌 동작이나 내부 API·소스는 확인하지 않았다. 아래 구현은 화면에서 보이는 정보 구조를 우리 공공데이터로 재구성한 것이다.

- 지도 전체를 탐색 영역으로 유지하고 검색·필터를 왼쪽에 모은다.
- 단지 이름·세대수 말풍선은 확대 시 표시하고 서로 겹치는 라벨을 줄인다.
- 현재 지도 영역에서 단지 목록을 새로 조회한다.
- 단지 선택 시 같은 왼쪽 패널에서 기본정보·주변 학교·역·상권을 세로로 읽는다. 목록 복귀 버튼 제공.
- 주변 학교·역 버튼으로 해당 시설 상세 및 위치를 확인한다. 직선거리와 학교 배정을 혼동하지 않도록 명시한다.
- 확대·축소 버튼 제공. 기존 드래그·휠·촬영 모드 유지.

가격 추이·거래 내역·면적별 가격은 아직 구현하지 않았다. 기존 실거래 원자료의 단지 ID 매칭, 면적·취소거래·기간 기준을 정해 연결해야 한다. 임의 가격이나 예시 그래프를 실제 데이터처럼 넣지 않는다.

기존 단지·학교·역 원본 및 이전 화면은 `versions/v2-before-explorer`에 보존했다. 최종 파일은 `index.html`, 웹 배포용은 `web/`이다. 공개 배포하지 않았다.
