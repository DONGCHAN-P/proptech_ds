# 웹사이트 확장을 위한 구조

현재는 프레임워크·backend 없는 정적 사이트다. 공개 배포나 상시 서버는 만들지 않았다. localhost HTTP 서버는 기능검증 때만 생성하고 즉시 종료했다.

## 공통 소스와 두 빌드

- `src/app.js`: Canvas 지도·필터·상세·로딩·모바일 패널 동작.
- `src/styles.css`: 채널 톤과 반응형 스타일.
- `src/index.template.html`: 접근성 레이블과 UI 마크업.
- `index.html`: 같은 소스와 gzip 데이터를 내장한 오프라인 단일파일. 더블클릭용.
- `web/index.html`, `web/assets/app.js`, `web/assets/styles.css`, `web/assets/data/atlas.json.gz`: 향후 정적 호스팅용. 상대경로만 사용하며 서브폴더에 놓아도 동작한다. 웹버전은 file:// 더블클릭보다 HTTP 호스팅을 전제로 한다.
- `data/schema.json`, `data/source_manifest.json`, `web/source_manifest.json`: 데이터 계약과 출처·파일SHA·revision.

빌드 예:

```powershell
tools/python311/python.exe -X utf8 video-agent-studio/map-atlas/build.py --downloads-dir C:/Users/e2ken/Downloads --source-dir video-agent-studio/episodes/capital-10eok-map-20261017/research/coordinate-link-v2 --output-dir video-agent-studio/map-atlas
```

세 옵션을 생략하면 기존 위치를 사용한다. 기본 Downloads는 현재 사용자 홈에서 계산한다. 웹 배포용 데이터와 manifest에는 사용자 이름·절대 로컬 경로·API키가 들어가지 않는다. 재현 입력의 실제 위치는 빌드 CLI에서만 결정한다.

## 데이터 계약

- `schema_version=1.0.0`. 호환되지 않는 schema는 UI가 오류를 표시하며 중단한다.
- 단지 기본키는 문자열 `HSMP_INNB`다. RTMS aptSeq와 동일하다고 가정하지 않는다. 보조CSV는 같은 문자열ID로만 조인한다.
- 좌표계는 **EPSG:5179**, 단위m, xy는 easting/northing. `rings`는 같은 원투영 좌표이고 위도·경도가 아니다. 렌더링 때만 y축을 반전한다.
- 도형 표시 좌표는1m 반올림. 원본 SHP는 episode source에 유지한다.
- 자료일자는 `dataset_date`, 보조 레이어 일자는 `auxiliary_dates`에 분리한다. ‘현재/최신/실시간’으로 표현하지 않는다.
- `approved`는 원자료 사용승인일 문자열로, 앞으로의 예측 준공일이 아니다. 원문 기준일과 혼용하지 않는다.
- 값 없음과0을 구분한다. 학원 규모별3열과 업종별9열을 더해 이중계산하지 않는다. 화면은 업종9열합계를 명시하고 실제 고유사업장수라고 단정하지 않는다.
- 출처표시 `attribution`, 원문 URL·버전·SHA를 manifest로 전달한다. 기본 source는 REB 공식 다운로드 자료이고 경계는 SGIS 기반 statgarten/maps MIT다.

## gzip·캐시 설정

`atlas.json.gz`는 파일 자체가 gzip인 blob이다. 권장 HTTP 응답은 `Content-Type: application/gzip`, **Content-Encoding은 생략**한다. JS가 gzip magic bytes(1f8b)를 확인한 뒤 `DecompressionStream('gzip')`으로 한 번 해제한다. 서버가 `Content-Encoding: gzip`으로 자동해제해 JSON바이트를 넘기는 경우에도 magic bytes가 없으면 JSON으로 읽어 이중해제를 피한다. 이미 gzip 파일을 서버가 한 번 더 압축하지 않는 것이 좋다.

gzip은 mtime0으로 재현 가능하게 만든다. payload와 JS/CSS/HTML 소스 전체의 SHA에서 revision을 만들고 데이터와 JS/CSS URL에 `?v=revision`을 붙인다. 배포 시 index.html과 source_manifest.json은 재검증되도록 하고, URL query를 무시하는 CDN 캐시 설정은 사용하지 않는다. 단일 산출물 묶음을 함께 배포해야 한다. source_manifest의 asset SHA로 묶음 무결성을 확인할 수 있다.

## 확인 범위와 다음 확장

오프라인7검사와 일시 HTTP 모바일검사에서 검색/키보드선택/정보패널/지도조작/촬영모드·압축데이터 로딩을 확인했다. `ui_validation.json`, `web_ui_validation.json`, `mobile_preview.png` 참조. 검색 결과는 키보드 Enter/Space로 선택 가능하고 로딩/오류는 status/alert를 제공한다. 모바일은 기본 패널·검색·드래그 대응이며 두 손가락 pinch 확대는 미구현이다. Canvas 지도 전체를 스크린리더로 공간 탐색하는 기능은 제공하지 않는다.

후속으로 원본좌표 bbox 공간색인, 줌별단순화, 벡터타일, 연도별 실거래 packet을 연결할 수 있다. 현재20k폴리곤/약9MB 오프라인 first pass에 타일링엔진·새 API·로그인·DB를 추가하지 않았다. 실거래 연결 시에는 가격 집계조건과 aptSeq↔공식ID의 검증된 조인 계약을 별도로 유지해야 한다.
