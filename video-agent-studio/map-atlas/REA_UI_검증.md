# REA 조사와 UI 반영 · 2026-10-18

REA 6.5.0 MCP 실제 호출로 임시 Chromium 157에서 https://hogangnono.com/ 접속에 성공했다. 기존 HTTP 도구의 403과 구분한다.

- 홈 DOM 증거: `ev_7e12fb9fd3118c148cbaf0945be089a4aa8fa35f330f83bb10f2bf16adbe94f5`.
- 검색 입력 시나리오: `ev_8a28ba1574ee008b52ce848074a13f3deb1d207ca8842f2cd6f41dd35c4e37c2`.
- 실제 관측: 검색창의 아파트·지역·학교 검색 안내, 단지/매물 전환, 매매·유형·평형·가격·세대수 등 필터, 주제별 지도 레이어.
- 검색어 입력 액션은 성공했지만 수집 DOM에서 결과 항목·상세 이동을 확인하지 못했다. 단지 상세 배치는 사용자가 제공한 스크린샷을 근거로 했다. 상세 API나 가격 데이터를 추출하지 않았다.

## 구현

기존 Canvas 및 공공 SHP 가공 데이터를 유지했다. React 전환은 하지 않았다. 별도 REA 분석 호출에 근거하여 검색·필터·레이어·결과를 왼쪽에 정리하고 단지 선택 시 같은 패널을 상세로 교체한다. 세대·동·승인일 요약, 가까운 학교·역 카드, 해당 시설 이동, 자료 상세 접기를 구현했다. 검색어와 단지명이 정확 일치하면 우선 표시한다. 도형 색을 옅게 줄이고 기존 중복 선택 라벨을 제거했다.

## 도로 배경지도

웹 화면에서 사용자가 ‘도로 배경지도’를 켜면 OpenStreetMap의 현재 화면 타일만 요청한다. `file:`로 연 단독 HTML에서는 비활성화한다. EPSG:5179와 경위도는 동봉한 proj4 2.20.9로 변환한다. 지도 타일은 두 삼각형으로 투영하며 확대 수준별 화면 범위만 메모리에 유지한다. 실제 타일은 별도 서버 제공 데이터이며 SHP나 오프라인 파일에 포함하지 않는다.

정책: https://operations.osmfoundation.org/policies/tiles/ . 현재 화면 외 선다운로드·대량 수집·오프라인 타일 묶음을 제공하지 않는다. 출처를 항상 화면에 표시하고 브라우저 기본 캐시·Referer를 유지한다. 촬영 자동화는 이 타일 서버로 실행하지 않는다. 향후 공개 서비스의 사용량·SLA에 맞는 별도 제공자 검토가 필요하다.

## 검증 범위

`qa_ui_v3.py` 데스크톱 1440×1000·모바일 390×844에서 각각 요약·시설 6개·패널 표시·가로 넘침·섹션·좌표 원점·타일 범위·레이어 상태 8항목 통과. 배경 투영 검사는 외부 OSM 요청 대신 시험 이미지를 사용했다. 실제 도로 타일의 제공 상태·현장 정합성을 검증했다고 주장하지 않는다. 생성된 두 스크린샷을 직접 확인했다.

기존 `qa.py`, `qa_explorer.py`, `qa_web.py` 통과. 휴대폰 실기기 검증은 안 했다. 가격 그래프·거래표·매물·실제 철도 선로는 구현 범위에 포함하지 않았다. 가공되지 않은 가격을 임의로 표시하지 않는다.

재현: `build.py` → QA 스크립트. 최종 파일 `index.html`, 웹용 `web/`. `serve.py`는 web 폴더만 127.0.0.1:8765에서 제공한다. 이전 화면은 `versions/v3-before-rea-ui/`에 보존했다.
