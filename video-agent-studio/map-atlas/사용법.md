# 수도권 단지 지도

웹사이트 확장 버전: 공통 원본은 `src/index.template.html`, `src/app.js`, `src/styles.css`이며, `build.py`가 오프라인 `index.html`과 정적 호스팅용 `web/`을 함께 생성합니다. 자세한 경로·빌드 옵션·gzip/캐시 계약은 `웹사이트_구조.md`를 참고하세요. 기존 `template.html`, `migrate_src.py`, `fix_hit.py`, `refine.py`는 이전 단계 기록이며 새 UI 수정에는 사용하지 않습니다.

`index.html`을 최신 Chrome 또는 Edge에서 더블클릭으로 엽니다. 인터넷·웹서버·외부 CDN·API키가 필요하지 않습니다. 단일 HTML 약9.3MB 안에 도형과 정보가 압축 내장되어 있습니다.

- 드래그로 이동하고 휠로 확대·축소합니다.
- 단지명·주소·공식 단지번호로 검색하고 지역/시군구를 고릅니다.
- 검색 결과 또는 도형을 클릭하면 단지 상세를 표시합니다.
- `전체 보기`는 필터와 선택을 초기화합니다.
- `화면 촬영 모드` 또는 F는 좌우 패널을 숨깁니다. 같은 버튼/F로 복원합니다.
- `화면 좌표 저장`은 EPSG:5179 중심좌표·배율·선택 공식단지번호·필터를 JSON으로 저장합니다. 영상 제작의 후속 지도 장면에 활용할 수 있습니다.

단지 도형은 한국부동산원 2025 공동주택 단지 연계정보에서 수도권20,058개를 사용합니다. 원본 Polygon의 EPSG:5179 좌표를 직접 그리며, 표시용 좌표만1m 반올림했습니다. 원본 ZIP과 SHP는 episode의 coordinate-link-v2에 그대로 보존되어 있습니다. 개별 단지 출입구나 세대 위치를 의미하지 않습니다.

보조자료는 공식 단지번호 HSMP_INNB 정확 일치로만 연결합니다. 경사도/표고2025는 각20,055개, 상권2026Q1과 학원2026.08은 각20,058개가 연결됩니다. 학원 업종 합계는 소·중·대 규모 열을 제외한9개 업종 열의 합계이며 고유 사업장 수로 단정하지 않습니다. 개별 학원/상권 위치를 임의로 찍지 않았습니다. 단위와 공간범위를 원문 설명서로 확정하기 전에는 임의 도보시간·반경·학군점수로 해석하지 않습니다. 값 없음은0이 아닙니다.

실거래 가격·과거연도별 도형·철도/도로 상세는 아직 연결하지 않았습니다. 단지 자료의2025범위와 경계파일의 행정구역 시점이 다를 수 있습니다. 현장 정확성·모든 수도권 단지 포괄성을 보장하는 지도는 아닙니다.

재생성: workspace 루트에서 `tools/python311/python.exe -X utf8 video-agent-studio/map-atlas/build.py` 실행. `template.html`이 UI 원본입니다. 추가 CSV 입력 경로와 SHA는 `validation.json`에 기록되어 있습니다. `fix_hit.py`, `refine.py`는 이미 반영된 일회성 편집 기록이므로 재실행하지 않습니다.

검증: `qa.py`로 기존 headless Chrome에서 로컬 로딩·반포자이 검색/상세·인천필터·휠·드래그·촬영모드를 실제 JS 실행해 통과했습니다. `ui_validation.json` 참조. 실제 사람의 전체 탐색 검수와 모바일 사용성 검사는 미실시입니다.
