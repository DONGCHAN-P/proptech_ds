# 20초 무음 교체 방향 시안 검토

**판정: 방향 채택 가능, 수정본 재확인 필요.** 기존 막대 인물보다 형태·공간·설명 흐름이 뚜렷하게 개선됐다. 전체 본편 합격이나 캐릭터 동작의 최종 품질 승인은 아니다. 검토 대상은 `character-quality-v1`의 인구·가구 분리 예시 한 장면이며, 기존 재건축 이주 장면까지 통과시킨 것이 아니다.

## 실제 확인 범위

episode_root 아래 `outputs/character-quality-v1/` 기준으로 다음을 직접 열었다.

- `checks/encoded/contact.jpg`: 0–19.9초의 표본 13개가 담긴 축소 이미지.
- `checks/encoded/06-8s.png`, `checks/encoded/10-12s.png`: 8초·12초 이미지 원본을 `view_image`로 열람.
- `project/index.html`: 장면 배치, Lottie 호출, 카메라·두 번째 방·가구 수·자막의 타이밍 코드 읽기.
- `project/assets/provenance.json`, `checks/verification.json`: 로컬 기록 읽기. 요청에 적힌 `assets/provenance.json`의 실제 위치는 `project/assets/provenance.json`이다. 출처 URL은 접속하지 않았다.

비교 기준은 앞선 감사에서 직접 열었던 `literature-visual-v1`의 `frame-026.png`, `frame-060.png`다. 이번에는 동일 파일을 다시 열지 않았다. 검증 기록은 1920×1080, 30fps, 20초·600프레임, 음성 없음으로 기재되어 있다. 해당 기술 검사를 이번에 재실행한 것은 아니다. 기록상 MP4 SHA256은 `51e3db1b895840213772ec8abb16110c4922c9b4547a6f47e8db80c83a8f73db`다.

**coverage:** 콘택트시트 1장·원본 표본 2장·소스 및 로컬 기록 읽기. 실제 MP4 연속 재생=`unchecked`, 실제 청취=`unchecked`(무음 시안), 새 MP4 스트림/디코드 검사=`unchecked`. 콘택트시트의 작은 패널 확인과 실제 소형 화면 연속 재생은 구분한다.

## 개선과 잔여 결점 — 3항목

### SR-01 — 인물·실내 형태는 개선, 선행 그림자는 재렌더 대기

- **scene_id / timecode / severity / status:** `household-scene` / 00:00–00:04.9 표본 / `required` / **`fixed pending rerender`**
- **개선:** 몸통·의복·머리·신발이 있는 측면 인물과 바닥·가구가 있는 실내로 바뀌었다. 8초의 파란 옷 자녀와 남은 두 사람이 구분되고, 12초에는 새집과 이사 상자가 독립 거주를 보조한다. 기존 CQ-01의 막대 기호 문제와 CQ-02의 문 선 관통은 지정 표본에서 뚜렷이 완화됐다.
- **evidence / 문제:** 현재 콘택트시트 초반에는 자녀가 도착하기 전 오른쪽 빈 공간에 타원 그림자가 먼저 보인다. 별도 대상이 있는 듯한 불필요한 시각 신호다.
- **수정안 / 확인 조건:** 주 에이전트가 수정 중이라는 최신 지시에 따라 위 상태를 기록한다. 수정 완료를 독립 확인했다는 뜻은 아니다. 재렌더의 0·2·4.9초 및 자녀 등장 직전/직후에서 그림자가 인물과 함께 나타나는지 확인한 뒤 닫는다.

### SR-02 — 보행 포즈 변화는 보이나, 도착 후 제스처는 어색함

- **scene_id / timecode / severity / status:** `household-scene` / 00:08, 00:10.5–00:19.9 표본 / `recommended` / `open`
- **개선:** 콘택트시트의 6·7·8·9·10초에서 다리 자세가 달라진다. 고정된 막대 인물을 통째로 옮기던 이전 방식보다 보행을 표현하려는 변화가 확인된다. 두 방의 바닥과 신발도 접지 판단의 기준을 제공한다.
- **evidence / 문제:** 12초 원본에서 자녀는 양팔을 앞으로 뻗은 자세이며, 10.5·15.5·19.9초 축소 표본에서도 유사한 자세가 유지된다. 손이 향하는 대상이나 행동 목적이 약해 정착보다 동작 도중 멈춘 인상이다. 다만 표본 사이에도 완전히 정지했다고 단정하지 않는다.
- **수정안 / 확인 조건:** 도착 반응 후 팔을 내려 안정된 거주 포즈로 정리하거나 제스처의 대상을 명확히 한다. 출발·이동·도착의 연속 재생에서 발 미끄러짐·급정지·접지를 별도로 확인한다. CQ-03은 **정지 표본상 개선, 연속 동작은 unchecked**로 남긴다.

### SR-03 — 설명 상태 변화는 명확해짐, 마지막 정보의 우선순위는 정리 필요

- **scene_id / timecode / severity / status:** `household-scene` / 00:08–00:19.9 표본 / `recommended` / `open`
- **개선:** ‘인구 3명’을 유지한 채 ‘1가구→2가구’를 바꾸고, 자녀가 별도 방에 도착한 결과를 남긴다. 8초와 12초 비교에서 사건 전후가 읽힌다. 소스도 방 등장 6.3초, 목적지 라벨 9.5초, 상자 9.7초, 가구 수 전환 10.3초로 구분되어 있어 기존 일률적 등장 효과보다 설명의 단계가 구체적이다.
- **evidence / 문제:** 큰 두 줄 제목은 계속 강하게 남는 반면, 마지막 ‘주거 수요는 달라질 수 있습니다’는 오른쪽 아래 작은 글로 추가된다. 15.5·19.9초 콘택트시트에서는 제목·두 방·왼쪽 가구 수·하단 자막에 비해 이 결론이 부차 정보로 밀린다. 원본 소스의 결론 글자는 25px, 제목은 66px다.
- **수정안 / 확인 조건:** 결론을 반드시 읽혀야 하는 정보로 쓸 경우 가구 수 변화와 가까이 묶거나 최종 hold의 강조를 옮긴다. 보조 문구라면 중복 설명을 줄여도 된다. CQ-04·05는 **설명 구조 개선 확인, 실제 재생 박자와 소형 화면 가독성 판정 보류**다. 효과 수나 기술 검사만으로 통과시키지 않는다.

## 전달

담당은 교체 시안 제작 중인 주 에이전트다. 재확인은 그림자 수정본과 도착 포즈·최종 정보 배치의 변경 구간에 한정한다. 이전 CQ-01–05를 일괄 종료하지 않으며, 이 보고서는 기존 감사·공통 상태를 수정하지 않는다. 구현·추가 에이전트·외부 요청 없이 `qa/character-quality-v1/sample_review.md`만 작성했다.
