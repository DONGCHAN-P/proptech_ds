## 검토 결과

### 1. 공간 표현·별도 집이라는 의미는 개선 확인

거실은 소파·테이블·조명, 자녀 공간은 침대·책상·노트북·여행가방으로 구분된다. 이전처럼 같은 방을 복제한 인상이 줄었고, 걷는 인물의 관절·접지에 주의가 빼앗기지 않는다. 8.7초 원본에서 기존 집의 두 잔과 별도 집의 같은 파란 계열 잔 하나를 확인했다.

두 공간은 독립된 벽·바닥 외곽과 사이 여백을 가지며, 기존 집의 내부 구조는 유지된다. 라벨도 ‘부모 · 기존 집에서 계속 거주’, ‘성인 자녀 · 다른 집으로 독립’, ‘자녀가 따로 마련한 집’으로 구별한다. **확인한 표본에는 한 집에 칸막이를 넣거나 내부를 물리적으로 쪼갠 표현이 없다. 물리 분할로 오해할 위험은 낮다.** 실제 시청자 이해를 실험한 결과는 아니다.

남은 권장 사항은 잔의 전달력이다. 원본에서 구별되는 잔도 축소 패널에서는 매우 작아, 세 사람을 나타내는 핵심 단서로 먼저 읽히기 어렵다. 현재 의미는 인구 수와 라벨이 주로 전달한다.

- **issue_id / scene_id / timecode / severity / owner / status:** `HS-01` / 가구 분리 공간 예시 / 00:02, 00:08.7 / `recommended` / 주 에이전트 / `open`
- **evidence:** 콘택트시트의 초기 세 잔과 8.7초 원본의 두 잔+한 잔. 작은 패널에서는 가구·창문보다 잔의 변화가 덜 두드러진다.
- **수정안:** 잔 변화가 독립적인 설명 장치여야 한다면 잔의 크기·대비를 높이거나 해당 순간에만 짧게 시선을 모은다. 라벨·숫자의 보조 소품이면 현 상태도 방향 시안 범위에서 수용 가능하다.

### 2. 전환 중 반투명·화면 밖 진입은 잔여 검토점

6.5초 원본에서는 오른쪽 원룸이 낮은 불투명도로 진입하고 우측 일부가 화면 밖에 있으며, 양쪽 역할 라벨도 흐리다. 7.0–7.8초 축소 표본을 거쳐 8.7초 원본에서는 두 공간과 라벨이 완전한 상태로 보인다. 따라서 **6.5초의 잘림을 최종 배치의 상시 잘림으로 판정하지 않는다.** 다만 중간 상태만 보면 공간이 안개처럼 겹쳐 나타나므로, ‘자연스러운 집 제시’의 완성도는 정지 화면만으로 확정할 수 없다.

- **issue_id / scene_id / timecode / severity / owner / status:** `HS-02` / 가구 분리 공간 예시 / 00:06.5–00:08.7 / `recommended` / 주 에이전트 / `open`
- **evidence:** 6.5초 원본의 반투명 원룸·라벨·일부 화면 밖 배치, 8.7초 원본의 안정된 전체 배치. 하단 자막은 이 두 원본에서 경계 안에 읽히며 공간과 겹치지 않는다.
- **수정안:** 실제 재생에서도 흐린 중간 상태가 길게 느껴지면 공간 제시와 라벨 등장의 시점을 나눠, 라벨은 읽을 수 있는 대비로 안정된 위치에서 나타나게 한다. 현재 표본만으로 전환 재제작을 필수 요구하지 않는다. 카메라 속도·가감속·멈춤의 자연스러움은 연속 재생 후 판정한다.

### 3. 1→2가구 전환은 표본상 의도와 부합

콘택트시트의 8.1초에는 **1가구**, 8.3초에는 **2가구**, 8.7초 원본에는 **2가구**가 보인다. 인구는 계속 **3명**이다. 이는 스토리보드의 8.2초 전환 계획과 부합하며, 두 번째 공간이 충분히 드러난 뒤 숫자를 바꾸는 순서도 타당하다. **확인 가능한 전환 시점은 8.1–8.3초 사이이며, 정확히 8.2초의 단일 프레임을 확인한 것은 아니다.**

8.7초에는 기존 집의 두 잔+자녀 집의 한 잔과 두 거주 라벨이 숫자를 뒷받침한다. 10.3초의 ‘한 곳에서 두 곳으로’ 자막은 결과를 뒤이어 설명하며 충돌하지 않는다. 15.2·19.9초 표본에서도 두 공간·2가구 상태가 유지된다. 이 항목은 `verified_in_samples`이며 추가 수정안은 없다. 무음 시안이므로 내레이션과의 동기 통과를 뜻하지 않는다.
