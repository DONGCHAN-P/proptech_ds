# 통합 보고서 작성자에게 전달할 표현 한계

RPR-LIT-QA-20261023 · 문헌 검수 v1 · 대상: writer Russell(01a167e3-ae71-7db1-883d-a3d83f6f72f7). 보고서 작성용이며 새 대본·음성·렌더의 승인이나 작업 지시가 아니다.

우선 반영: **현재 서울·경기 격차의 원인·기여율은 입증되지 않았다. S4 효과계수와 인과 headline은 제외한다. ST-F08의 학술지판 기간·방법을 WP와 분리한다.**

## 3. 서지 중복 제거와 독서 라벨

주요 목록은 **20 연구 그룹(수요 7 / 공급 6 / 공간 7)**이다. 서로 다른 목록의 최상위 DOI 중복은 없다. 이 숫자는 독립 인과증거 20개를 뜻하지 않는다.

- spatial:S1의 2016 보고서/2017 학술지판, spatial:S6의 WP/관련 학술지판은 각각 같은 연구 그룹으로 유지한다. 판본별 기간·방법은 분리한다.
- demand:P7의 2013 작업본/2015 최종판, spatial:S2의 2018 저자본/2020 최종판을 독립 근거로 더하지 않는다. 읽은 판본을 명시한다.
- **9본문 독서**는 연구 담당의 명시된 범위 합계다: demand:P1·P2·P6 / supply:P1·P2·P5 / spatial:S2·S4·S6. QA의 독서 수가 아니며 모두 최종판 전문·원표 시각 검수인 것도 아니다. 공급 P2·P5는 표 이미지 셀 미검수이고 spatial:S2는 저자본이다.
- 나머지 11그룹은 선택 본문·공개 일부 6, 초록·공식 요약 5로 표시한다. S1 검색 노출은 전문 열람으로 격상하지 않는다. 상세 라벨은 audit_manifest.json을 사용한다.
- 보고서에서는 저자·연도·제목·직접 출처를 사용한다. 내부 ID는 demand:P1 / supply:P1 / spatial:S1처럼 구분한다. D01 등은 주장 ID다.

## 4. 설명의 연결과 다음 검수

문헌 인사이트는 ‘접근 가능한 일자리와 구매력의 선택 → 이용 가능한 주택의 대체 범위 → 공급·이주의 시간차 → 지역별로 다른 반응 가능성’처럼 조건을 연결해 설명할 수 있다. 이는 여러 연구를 연결한 해석이라고 표시하고, 어느 연구도 모든 연결고리를 함께 식별하지 않았음을 밝힌다. 수요·공급·교통의 중첩 경로를 독립 효과처럼 더하거나 문헌 수로 원인 순위를 매기지 않는다.

새 데이터 수집·원자료 재계산·대본 작성은 이번 검수의 요구가 아니다. writer는 문헌의 결과·종합 해석·아직 검증하지 않은 후보를 분리하면 된다. 총괄이 초안 완료를 알리면 실제 보고서의 원인 단정·판본 혼용·S4 제외·독서 라벨과 위 필수 수정의 반영 부분만 재검수한다. 현재는 report_draft_issues를 만들거나 보고서 내용을 수정하지 않는다.
