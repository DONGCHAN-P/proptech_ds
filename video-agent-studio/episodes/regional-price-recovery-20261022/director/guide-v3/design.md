2026-10-25 사용자가 지적한 네 기준을 기존 MP4와 제작 소스에 대조했다. v2의 저자·날짜 보호와 일부 서술 정리는 반영됐지만, 문장·절 우선 자막, 별도 이미지 챕터, 필요한 이미지 생성, 주제를 넘나드는 같은 집·건물 재사용 방지는 충족하지 못했다. 기술 검수를 제작 가이드 전체 통과로 확장해 해석한 점을 바로잡는다.

## 이번 제작 결정

- 낭독 사실·논문·실제 평면과 기존 승인 브랜드를 보존한다. 기존 Jun 생성 보류는 유지한다.
- 원문 30문단을 작성자가 직접 162개 의미 단위로 나눴다. 문장·접속절·완결구절을 먼저 정하고, 글자 수는 화면 안 줄바꿈 점검에만 쓴다. 음성 없는 시간표는 잠정 추정이다.
- 8장마다 3.5초의 독립 이미지 챕터를 둔다. 제목은 번호와 주제만 쓴다. 8개 이미지는 중복하지 않는다. 기존 공통 이미지 4개와 새 생성 4개를 사용한다.
- 본문에 청년 원룸, 가계 재무, 이사, 공급 공사, 환승의 새 이미지 5개를 사용한다. 각 사진은 해당 장에서만 짧게 쓰고, 다른 주제로 돌려 쓰지 않는다.
- 승인한 집 단면과 컵 3→2+1은 L002 가구 분리 설명에만 사용한다. 실제 왕숙 59A 평면은 L003 공간 설명에 사용한다. 이외 본문은 데이터·선택 행렬·시간축·순증 계산·추정 경로·통근 단계 등 서로 다른 관계를 보여준다.
- 같은 대상의 연속 설명에서는 그래픽을 유지하며 의미 단위별 강조를 바꾼다. 관련 없는 장에 같은 배경을 깔거나 새 이미지 대신 제목만 바꾸는 것은 통과시키지 않는다.
- AI 생성 이미지는 실제 현장·논문 분석 단지·가격 결과의 증거로 사용하지 않는다. 제목·숫자·출처는 생성 이미지 밖 편집 레이어에 둔다.
- 하단 흰 자막 박스는 본문·큐 사이·챕터 전환에 유지하고 글자만 교체한다. 브랜드 구간과 마지막 3초 CTA 유지에서는 숨긴다. 원문과 표시 표기의 4개 명시 변환을 기록한다.
