# guide-v3 의미 단위 대본 설계

기준: readable-v2의 8개 장면·30개 문단. 문단 원문과 순서는 보존했다. 문장·절·완결 구절을 사람이 직접 선택했으며 글자 수로 분할하지 않았다. 화면 설계·에셋 제작은 main 담당이다.

타이밍: 미확정. 실제 음성 생성·청취·정렬·프레임 검수는 수행하지 않았다. 의미 단위 경계는 컷 전환 명령이 아니다. 실제 1~2줄 배치와 표시 시간은 main/editor가 렌더 및 음성 정렬 후 확인한다.

자료 유형: data=기존 집계자료, real_plan=실제 평면, concept_image=가상 생활 개념 이미지, diagram=관계·시점 설명, study=기존 연구 근거, synthesis=연구를 연결한 질문·종합. 설명 화면과 분위기 화면을 구분하고 생성 개념 이미지는 사실 증거로 사용하지 않는다.
