# 교산 v4 무료 검토본 배치 가이드

배포 파일은 `outputs/production-v4/gyosan_review_v4r1_free_tts.mp4`입니다. 사용자 승인 대본 v4를 유지하고 새 Microsoft Heami 무료 음성으로 제작합니다. 원본 v1·v2 영상, 대본, 승인 자료와 첫 v4 조립본도 보존합니다. 외부 업로드와 유료 생성은 수행하지 않습니다.

화면은 창릉 기준 색·서체를 계승합니다. 본문 흰 자막은 y=875~1000, 출처는 y=1018~1068로 고정하며 지도·도표 모션과 분리합니다. 각 구절의 실제 새 WAV 길이로 타이밍을 정하고, 숫자·단위·날짜를 보호해 명시적 줄바꿈을 전달합니다. 원문과 발음용 정규화 문장은 별도로 보관합니다.

M008 후보 장면은 v2의 실제 토지이용계획도·좌측 locator·C2/B2 정확한 필지 매칭을 유지합니다. 자족5/7은 개별 코드와 기하를 매칭하지 못했으므로, 계획 자족용지 전체와 발표 기능 도표를 보여주며 개별 필지 정밀 위치로 소개하지 않습니다. 스타필드 하남과 캠프콜번은 공식 주소와 VWorld 주소 대표점을 사용하고, 실제 OSM 도로선을 배경에 넣습니다. 사업경계·출입구·계산된 보행경로로 해석하지 않도록 표기합니다.

자료 유형은 실제 계획 필지, 운영 철도·도로 기하, 공식 공고 발췌, 검증된 가격·일정의 자체 도표, 이전 영상 실제 프레임입니다. 신규 AI 이미지는 생성하지 않았습니다. 기존 여섯 개 AI 챕터 배경은 개념 이미지 표기와 함께 재사용합니다. 브랜드 인트로·아웃트로는 흰 자막 없이 보존하고, 마지막 음성 파일 종료 뒤 90프레임을 유지합니다.

재현 순서는 `prepare_audio.py` → `generate.ps1` → `timeline.py` → `prepare_visual.py` → `render.cjs --render` → `assemble.py` → `finish.py`입니다. SAPI 엔진은 샌드박스 레지스트리 접근 제한 때문에 일반 Windows 실행이 필요했습니다. 완료된 음성은 파일 존재와 길이 검증 후 재사용합니다. OSM은 `fetch_roads.py`의 1회 캐시를 사용하며 재렌더 때 네트워크 호출하지 않습니다.

실제 구간·대표 시점은 아래 표 및 `representative_timestamps_v4r1.json`을 따릅니다. 입력 SHA는 `input_manifest.json`, 기술 사양은 `technical_v4r1.json`, 구조적 컷 경계 전후 검사는 `boundary_verification.json`, 실제 모션 연속 프레임 검사는 `motion_verification.json`에 기록합니다. 실제 청취·연속 재생과 독립 QA 판정은 해당 검수 기록의 범위만 주장합니다.

v4r1은 독립 QA V4Q02를 반영해 M009의 기존 단지 실거래 중위값 발화에 실거래 차트를 재호출합니다. 수정 구간은 32057~32192프레임이며 원문·음성·자막·전체 길이를 바꾸지 않았습니다. 첫 조립본에서 키프레임까지의 본문을 재사용하고 이후 약49.4초만 재인코딩했습니다. `patch_assemble.py`와 `patch_plan.json`에 이 과정을 기록합니다.
