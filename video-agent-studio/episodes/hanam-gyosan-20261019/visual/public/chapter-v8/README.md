# 재사용 챕터 배경 v1

GPT 내장 이미지 생성으로 만든 공통 자산 6종이다. 특정 지역 사진·공식 조감도·계획 위치의 증거가 아닌 **AI 개념 이미지**다. 도시 분석 시리즈의 독립 챕터 배경으로 재사용한다.

|파일|역할|
|---|---|
|jobs.png|일자리·업무지|
|transport.png|철도·버스·교통|
|price.png|분양가·진입가격|
|comparison.png|주변 기존 단지 비교|
|supply.png|주택 공급·도시 완성|
|school_life.png|학군·공원·생활시설|

글자는 이미지에 굽지 않았다. 왼쪽의 어두운 여백 위에 편집에서 번호·제목을 얹고, 화면의 실제 색 대비와 안전 여백을 확인한다. 개념 배경임을 짧게 표시하며 지역명·역명·단지명이 이미지의 실제 촬영 장소를 뜻하는 것처럼 쓰지 않는다. 본문의 위치·가격·교통 근거는 검증된 지도와 원자료를 별도로 사용한다.

생성 방식·역할·크기·파일 해시는 manifest.json에 보존한다. 원본 이미지는 임의 덮어쓰기보다 후속 버전을 만든다.
