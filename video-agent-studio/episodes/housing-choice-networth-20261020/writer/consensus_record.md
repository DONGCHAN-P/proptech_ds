# 실제 Claude 논의와 조정 기록

기준 2026-10-20. 구독 Claude CLI를 실제 두 번 실행했습니다. 원본 시트·개인 금융금액·Google 링크·저장소 루트·자격증명은 전송하지 않았습니다. 익명 가정 대본과 조사 요약만 별도 packet.json으로 전달했습니다. CLI는 Read를 해당 packet에만 허용하고 MCP·hooks·설정 자동로딩·세션 보존을 비활성화했습니다. API키 환경변수는 제거했습니다. 네트워크는 사용자가 요청한 논의 범위의 scoped 권한 확장으로 실행했으며 API나 유료 크레딧으로 전환하지 않았습니다.

## 1. 1차 응답

입력은 script-v1 초안·익명 모형 note·공식자료 요약입니다. 요청은 가정·회계·편향·대본에 대한 비평이었으나 Claude는 대체로 내용을 요약했습니다. exit_status0·is_error false로 실제 응답은 받았지만 비평 요구를 충족한 합의로 기록하지 않습니다. 응답은 model note의 과거 ‘독립 QA 미수행’ 설명을 반복했습니다. 이후 독립검수가 완료된 상태와 충돌하므로 이 문장은 기각했습니다. 10~12분이라는 Claude 추정도 음성 측정 근거가 없어 채택하지 않았습니다.

증거: director/claude-story-v1/round1.{packet.json,input.txt,stdout.json,stderr.log,review.md,receipt.json}. 1차 입력에는 모델 작성자의 당시 미완료 검수 문구도 함께 있어, 2차에서는 최신 QA 결과로 명시적으로 교정했습니다.

## 2. 2차 응답

수정 대본에는 낭독 숫자 반올림, 월세120만원 민감도, 매매/임차 비용30만원·5만원 차이25만원, 환율+10%/+10%→+21% 예시를 반영했습니다. 질문은 가정 내부 회계의 일관성, 과거성과·세후·예측 오해, 남은 핵심 오류, 제한적 합의 여부로 좁혔습니다.

Claude는 원금상환의 부채 감소 연결, 보증금 자산 처리, 초기 투자금 차이에 나타나는 기회비용, 배당·환율 중복 방지를 수용하고, 수학적·개념적 오류를 발견하지 못했다고 답했습니다. 실제 과거 재현·세후 결론·예측이 아니라는 설명에도 동의했습니다. 다만 시장 임대료 적합성·세금·대출가능성이 확인되지 않은 조건에 한정된 합의라고 밝혔습니다. 이 유보는 채택했습니다. **이는 제공 패킷에 대한 의견 일치이며 Claude가 원자료나 코드를 독립 검증했다는 뜻은 아닙니다.** 독립 숫자 검증 근거는 별도 QA입니다.

## 3. 채택과 기각

| 의견 | 결정 | 근거·반영 |
|---|---|---|
| 가정 내부 원금·보증금 회계가 일관됨 | 채택 | 별도 독립 QA 결과와 일치. 대본5장·S011~013 |
| 시장 임대료가 결과 순서를 좌우하며 등가 주거조건 확인 필요 | 채택 | 검증된 실제 계약이 아닌 가정임을2장·8장에 명시. 월세120만원 민감도 추가 |
| 상품 세금·대출 실행 가능성이 미검증 | 채택 | 2장·6장·9장 및 보고서 범위에 표시. 세후·대출승인 결과로 표현하지 않음 |
| 6억 집의 시장 월세는150~165만원 이상이라는 단정 | 기각 | Claude는 외부 검색 금지 패킷만 읽었으며 단지·시점·전환율 원자료가 없음. 가정5~6%에 보증금차3억원을 적용한 단순 환산도 월125~150만원으로 제시값과 다름. 해당 비율 자체도 실제 시장 근거가 아님 |
| 세금 미반영은 매매에 구조적으로 불리함 | 기각 | 상품·계좌·주택요건별 세금을 계산하지 않아 순영향을 확정할 수 없음. 응답은 소유자의 미계산 세금까지 열거하면서 생략의 방향을 매매불리로 단정해 논리가 일치하지 않음 |
| ‘2025년 이후 현행 금융투자소득세’ 문구 | 기각 | 패킷에 없는 법률 주장을 출처 없이 생성. 이번 작업은 해당 제도를 전제로 계산하지 않음. 실제 세금 적용은 연도별 공식 원문 검증 후 수행 |
| DSR40%로 최소 월소득430만원이라는 개인 적용 | 미채택 | 소득 정의·대출종류·타부채·시점 규제 미확정. 다음 예산편에서 공식 규칙과 가구 조건을 분리해 계산 |

## 4. 합의 범위

최종 상태는 **부분 합의·근거에 따른 조정 완료**입니다. ‘같은 집·초기 순자산·월예산에서 원금·보증금·투자를 연결하고 조건별 결과를 보여준다’는 대본 방향에 제한적으로 의견을 모았습니다. 시장 등가 임대료·실제 세금·대출승인·변동 경로·반환 지연은 남은 연구 과제입니다. 두 차례 논의 뒤 추가 반복 호출은 하지 않았습니다. Claude의 기각된 주장까지 일괄 합의한 것으로 기록하지 않습니다. 사용자 대본 승인은 아직 받지 않았으며 TTS·유료 미디어·렌더·업로드도 시작하지 않았습니다.

2차 증거는 director/claude-story-v1의 packet.json,input.txt,stdout.json,stderr.log,review.md,receipt.json 및 round2.* 보존본입니다. receipt의 cli_cost_estimate는 CLI가 출력한 사용량 환산치로 별도 API 청구의 증거가 아닙니다.
