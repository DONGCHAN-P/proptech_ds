# 무료 TTS 샘플과 후속 준비

현재 온라인 합성 명령은 사용자가 지정한 두 문장만 생성한다. 전체 대본 생성 명령은 제공하지 않는다. 최종 대본은 양측 검수를 마친 뒤 별도 지시를 받아야 한다. 새 파일과 폴더만 생성하며 기존 음성·대본은 덮어쓰지 않는다.

`samples/injoon-20261026-v1/sample.mp3`가 InJoon 남성 샘플이다. 속도는 -5%, 피치는 +0Hz다. 서비스 음성 목록에서 한국어 남성임을 확인했다. PCM 실측은 7.896초이며 포맷·전체 디코딩·클리핑·문장 경계 원문을 검사했다. 자연스러움·숫자 발음은 직접 청취 미확인이다. SAPI 대체 합성은 Edge 서비스가 작동하므로 실행하지 않았다.

원시 `boundaries.json`의 문장 경계에는 50ms 겹침이 있다. 원시 값과 `sample.mp3`·`sample.wav`는 유지하고 `cue_boundaries.json` 및 `sample.srt`에만 앞 문장 끝을 다음 문장 시작으로 정리했다. 마지막 서비스 경계 7.8921052초와 PCM의 -60dBFS 이상 마지막 신호 6.813125초는 다른 기준이다. 무음·문장 끝 품질은 청취 후 판단해야 한다. `timemap.json`은 서비스 메타데이터이며 단어 강제 정렬이나 청취 검증이 아니다.

모든 명령은 프로젝트 루트에서 실행한다. 내장 Python의 `_pth` 구성은 `PYTHONPATH`를 자동으로 읽는 일반 환경과 다르므로, `tts_pipeline.py`가 자기 폴더의 `deps`를 명시적으로 import한다. 전역 패키지나 `.env`는 사용하지 않는다.

```powershell
# 오프라인 계약 검사: 샘플 외 텍스트 차단·원문/소수점 보존·PCM 시간·경계 처리
tools/python311/python.exe -B -X utf8 video-agent-studio/episodes/housing-choice-networth-20261020/narration/free-tts-v1/test_tts_pipeline.py
```

설치는 이미 완료됐다. 재현이 필요할 때만 지정 target과 잠금 파일로 설치하며 전역 설치를 하지 않는다.

```powershell
tools/python311/python.exe -B -X utf8 -m pip --isolated --disable-pip-version-check install --no-input --no-cache-dir --only-binary=:all: --index-url https://pypi.org/simple --target video-agent-studio/episodes/housing-choice-networth-20261020/narration/free-tts-v1/deps -r video-agent-studio/episodes/housing-choice-networth-20261020/narration/free-tts-v1/requirements.lock.txt
```

최종 대본을 받으면 낭독할 본문만 담은 UTF-8 TXT와 확정 발음 사전 JSON을 입력한다. Markdown 제목·화면 지시·출처를 낭독 본문과 혼합하지 않는다. 아래 준비 명령은 온라인 전송이나 TTS를 하지 않는다. `script_revision`에는 실제 확정 버전을 넣고 `out`은 담당 폴더 안의 새 버전을 사용한다.

```powershell
tools/python311/python.exe -B -X utf8 video-agent-studio/episodes/housing-choice-networth-20261020/narration/free-tts-v1/tts_pipeline.py prepare --text <낭독본문.txt> --pronunciations <발음사전.json> --script-revision <확정버전> --out <담당폴더/prepare-v2>
```

출력 `source.txt`와 `units.json`은 문단/문장 ID, 원문 위치, `original_text`, `spoken_text`, `meaningcue`를 보존한다. 현재 meaningcue의 기본 단위는 문장 1개이며 타임코드는 null이다. 추가 분할이 필요하면 문장 안의 실제 경계를 확보해야 한다. 글자 수에 시간을 균등 배분하지 않는다. `scene_id`는 총괄 장면표와 연결하기 전까지 null이다. 자동으로 주제나 의미를 바꾸는 요약은 하지 않는다.

이후 별도 승인으로 생성한 문장별 PCM16 mono WAV가 있을 때만 실측한다. `audio-map.json`은 `{ "P001_S001": "문장WAV절대경로", ... }` 형식이다. 문장 파일의 샘플 수/샘플레이트로 계산하고 합산하며, 삽입 화면·인트로·아웃트로의 시간은 총괄과 편집 담당이 확정한다.

```powershell
tools/python311/python.exe -B -X utf8 video-agent-studio/episodes/housing-choice-networth-20261020/narration/free-tts-v1/tts_pipeline.py measure --units <prepare-v2/units.json> --audio-map <audio-map.json> --audio-revision <음성버전> --out <담당폴더/measure-v2>
```

샘플의 최초 엄격 비겹침 검사 실패는 `failure.json`에 보존했다. 같은 오디오를 로컬로 재검증해 복구했으며 재합성하지 않았다. 이미 validation/SRT가 있는 폴더에서 검사 명령을 반복하면 덮어쓰기 대신 중단한다. 재검수 결과도 새 버전 폴더나 새 기록으로 보존한다.
