# 두 편 제작과 비공개 업로드

2026-10-26 사용자 직접 지시. 총괄: Codex. 기존 대본·MP4·원천 자료 보존.

## 1. 매매·전세·월세

기존 17분 무음 검토본의 주거·자금·원금·보증금 그래픽과 승인 인트로를 계승한다. 최신 집값 설명과 조건부 결론을 연결하고, 비용은 항목과 모형의 가정액을 함께 설명한다. 계산을 유리하게 바꿔 결론을 만들지 않는다.

의존 순서: 최신 대본 → 수치·표현 QA와 Claude 검수 → 수정·양측 재검수 → 무료 TTS 및 실제 길이·발음·의미 자막 → 타임록·화면 보완 → 실제 출력 검수 → Claude/Codex 최종 승인 → 비공개 업로드·상태 확인.

Claude에게는 대본·익명 집계·공개 출처와 필요한 검수 이미지/기록만 제공한다. 구독 CLI를 우선하고 키 환경변수·MCP·외부 도구 없이 검토한다. 개인정보와 자격증명은 검수 패킷에 넣지 않는다.

TTS는 추가 결제가 없는 한국어 음성을 쓴다. 무료 음성 생성은 이번 사용자 지시로 승인됐다. 기존 Jun 생성 보류를 유료 서비스 재개로 해석하지 않는다. 음성과 자막을 붙인 뒤 숫자 발음·실측 길이·정렬·음량·자막 범위에 대해 후속 검수를 수행한다.

## 2. 다음 편

첫 편의 비공개 업로드 확인 뒤 별도 episode에서 감당 가능한 매매 가격 편을 제작한다. 보유자금 → LTV → DSR → 세금과 부대비용 → 가격별·가구별 사례 → 정책 구입자금 상품 → 감당 가능한 가격이라는 순서다. 6억·9억·12억원과 공식 정책의 추가 경계값을 구분한다.

모든 규정은 공식 원문에서 확인한 적용일과 지역·주택 수·생애최초·출산/소득/부채·면적·만기 조건을 계산에 연결한다. 한도는 담보·상환능력·상품 상한·주택가격 조건을 함께 적용한다. 규정상 상한과 실제 취급 심사는 구분해 조건을 직접 설명한다. 신생아 특례·디딤돌·보금자리론 등은 확인된 현행 대상과 금리를 각각 표시한다. 취득세 감면과 중개보수 상한/부가세·등기 등 비용을 사례별로 나눈다.

## 3. 공통 검수

- 의미가 다른 장면에 동일 이미지·차트를 계속 띄우지 않는다. 각 장면의 목적·자료 유형·변화 동작을 기록한다.
- 같은 계산의 연속 설명은 강조 대상을 이동시키고, 다른 메시지로 넘어가면 자료도 바꾼다.
- 분기·숫자·계약·가구를 말할 때 화면의 해당 대상을 표시한다.
- 글꼴 로드 후 글자 실제 경계·여백·패널 잘림·출처·자막 영역을 검사한다. 긴 문구와 실제 인코딩 프레임을 함께 점검한다.
- 회피형 부정 문구를 반복하지 않는다. 비교 조건·관측 기간·자료 범위·확정 상태를 직접 설명한다.
- 새 이미지가 설명에 도움이 되면 사용자가 허용한 범위에서 생성한다. 그래픽·표·자산을 임의의 사진으로 대체하지 않는다. 생성/권리 기록은 자산 기록에 남긴다.
- 의미 단위 자막을 실제 음성에 맞추고 숫자·단위·날짜를 보호한다. 본문 흰 자막 박스는 큐 사이에도 유지한다.
- 클린 브랜드 인트로·아웃트로와 기존 음악을 재사용한다. 마지막 발화 뒤 3초 무음 유지 후 아웃트로로 넘어간다.
- 재생·청취·표본 프레임·자동 기술 검사를 구분해 실제 수행 범위만 기록한다.
- 양측 검수의 필수 이슈 0건, 최종본 해시·승인 기록, 비공개 상태 확인을 완료 조건으로 삼는다.

이번 지시는 위 조건을 충족한 비공개 업로드까지의 사전 승인이다. 일반 디자인과 편집 선택마다 승인을 다시 요구하지 않는다. YouTube 공개·유료 음성·충전은 이번 범위에 없다.
