# Claude 초기 모형 감사 조정 기록

실제 구독 CLI 실행에 성공했다(exit 0, is_error false). 첫 sandbox 실행은 ConnectionRefused로 실패했으며 attempt1 로그를 보존했다. 권한 확장으로 동일 익명 패킷을 재실행했다. receipt의 cli_cost_estimate는 CLI 출력의 사용량 환산치이며 실제 별도 API 청구를 입증하는 값이 아니다. API 키는 제거했다.

채택: 전세 자기자본 가산은 이미 전세 대출을 순액 처리한다는 점, 매매 잔존채무 고정 방식의 조건부 타당성, 원금상환/운영비 미확정 구분, 보증금 기회비용·배당 중복 차단, 동일 주거 서비스·청산 비용·갱신·유동성·민감도 검토.

수정·기각할 Claude 표현:

- 연환산 수식이 보이지 않는다는 이유만으로 '연율 표시 확정 오류'라고 할 수 없다. 확인된 것은 월 적용과 라벨 부족이다. 연율 오표시 여부는 미확정이다.
- 상수 하드코딩은 확인되지만 현재 값의 계산 오류를 뜻하지 않는다. 입력 변경 시 불일치 위험으로 분류한다.
- '관리비는 매수자에만 발생'은 일반화하면 틀린다. 공통 거주비는 공통 예산에, 소유자 부담 세금·수선 등 차등 항목만 시나리오 비용에 넣는다.
- 달러 수익률에 FX를 단순 더하면 교차항을 누락하는 근사 오류이다. 그 자체를 FX 이중반영이라고 부르면 부정확하다. 이미 원화로 환산된 수익에 FX를 다시 적용하는 경우가 이중반영이다.
- 동일 월 기여금 '시점 규칙'은 적용돼 있으나 시나리오별 기여금 액수는 다르다. t=0과 첫 달 처리의 정합성은 여전히 검토해야 한다.

Claude는 원본을 열지 않았고 packet.json의 익명 구조만 검토했다. 독립 원자료 검증이나 전체 대본 합의로 간주하지 않는다.
