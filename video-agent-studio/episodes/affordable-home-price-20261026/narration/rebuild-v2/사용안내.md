# 무료 음성·자막 재제작 준비

현재는 코드와 계약만 준비했다. writer의 한글 복원·마지막 수정·부모 잠금이 진행 중이므로 실제 원고를 읽거나 TTS를 호출하지 않았다. 기존 대본·MP4·음성·공통 상태는 수정하지 않는다.

`build_contract.json`이 편집 연결 계약이다. `scenes` 배열이 재생 순서이며 ID·chapter 숫자로 정렬하지 않는다. 장면 문단 전체를 InJoon `+0%`로 한 번 합성한다. 자연스러운 내부 쉼과 원본 PCM을 보존하고, 장면 사이에 추가할 무음은 0.25초다. 마지막 장면 WAV에는 마지막 발화 기준 3초 여백을 포함하므로 편집에서 중복 추가하지 않는다.

`audio_path`는 24kHz mono PCM16, `audio_48k_path`는 편집용 48kHz mono PCM16이다. 모든 경로는 작업공간 루트 `C:/projects/realestate_reco` 기준이다. cue·word·beat 시간은 각 장면 WAV의 0초 기준이며, `scene_start_s`는 브랜드·챕터 카드가 없는 본문 가조립 시각이다. 공통 EDL은 총괄이 확정한다.

원문에 유일하게 나타나는 anchor의 문자 범위를 찾아 실제 WordBoundary 중 그 범위를 덮는 단어의 시작·끝으로 연결한다. 단어 내부 시간은 추정하지 않는다. 실제 큐·anchor 시각은 TTS 결과가 있을 때만 생성한다. 렌더 글리프 경계·실제 청취·자연스러움은 후속 검수 범위다.

부모가 사용할 명령은 다음과 같다. 아래 경로는 계약 예시이며 실제 승인 파일은 부모가 `director` 안에 작성한다. 출력 디렉터리가 이미 있으면 새 버전 이름을 쓴다.

```powershell
tools/python311/python.exe -X utf8 video-agent-studio/episodes/affordable-home-price-20261026/narration/rebuild-v2/build_narration.py prepare --script video-agent-studio/episodes/affordable-home-price-20261026/writer/rebuild-v2/scenes_v3.json --out video-agent-studio/episodes/affordable-home-price-20261026/narration/rebuild-v2/prepare-v1
```

`prepare`는 오프라인이다. UTF-8 한글 수·연속 물음표·대체문자, 숫자 발음 리터럴, 원문→발음 치환, 원문을 복원하는 전체 큐, 숫자·단위 보호, anchor 유일성을 검사한다. `prepared.json`의 SHA와 부모 확정 대본 SHA를 승인에 연결한다.

```powershell
tools/python311/python.exe -X utf8 video-agent-studio/episodes/affordable-home-price-20261026/narration/rebuild-v2/build_narration.py check-gate --prepared video-agent-studio/episodes/affordable-home-price-20261026/narration/rebuild-v2/prepare-v1/prepared.json --lock video-agent-studio/episodes/affordable-home-price-20261026/director/rebuild-v2/locked_script.json --authorization video-agent-studio/episodes/affordable-home-price-20261026/director/rebuild-v2/free_edge_authorization.json --out video-agent-studio/episodes/affordable-home-price-20261026/narration/rebuild-v2/audio-v1
```

`check-gate`도 외부 호출을 하지 않는다. 승인 필수 항목과 `command_argv`는 `build_contract.json`에 명시했다. 정확한 절대경로 명령 배열은 Python의 `build_narration.command_argv(prepared, lock, authorization, out)`로 구한다. 모든 승인 조건이 맞고 부모가 실행 범위를 승인한 뒤 같은 인수로 `generate`를 사용한다. 자동 재시도는 0회, 네트워크 시도 상한은 장면 수이며 각 장면에 1회만 할당한다.

실패하면 원본 MP3·WordBoundary·부분 WAV와 영수증을 보존한다. 실패한 실행에는 최종 시간표를 만들지 않는다. 새 유료 서비스·계정 토큰·API 키·Claude·업로드 호출은 없다. 이전 음성 캐시를 자동 재사용하지 않는다.

검증용 `offline-tests` 안의 가상 승인·원고·오디오·시간표는 시험 자료이며 실제 제작 입력으로 사용하지 않는다. 합성을 모의한 검사는 `TEST_FIXTURE_ONLY`로 표시하고 실제 네트워크 호출 수는 0으로 기록한다.
