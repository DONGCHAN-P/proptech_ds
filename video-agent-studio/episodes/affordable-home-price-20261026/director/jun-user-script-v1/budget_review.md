# 이번 편 Jun 음성 예산

- 사용자 선택: 이번 편까지 Jun. 다음 직접 녹음 편과 구분한다.
- 대상 원고: 「현금 1억부터 5억까지」의 원문 48문단·31장면·7개 장.
- 원문: 5,701자. 숫자·약어 읽기 전개 후 본문 5,715자.
- 실제 보낼 7개 장 입력: 구분 공백 포함 **5,797자**.
- 현재 조회 요율: 모델 배수1 × 할인 배수1 × Jun 요율1. 최초 생성 예상 **5,797크레딧**.
- 제안 상한: 포함 크레딧 **7,000**, 수정 여유 **1,203** 포함. 이전 편의 상한을 이월하지 않는다.
- 조회 시각: 2026-10-27 23:12 KST. 포함 잔여 **18,981크레딧**. 잔여는 실행 직전 다시 확인한다.
- 추가 결제·충전: **0원**. 초과 사용·자동 재시도 없음.
- 현재 상태: **이번 편 상한 승인 답변 대기. 유료 생성 0회.**

입력과 읽기 변환은 `narration/jun-user-script-v1/narration_manifest.json`, 계정 조회는 같은 폴더의 `account_readonly.json`, 산출 근거는 `budget_proposal.json`에 있다. 키·계정 식별정보·원본 API 응답은 이 자료에 포함하지 않는다.

예산 확인 근거는 [영상 제작 마스터 가이드 §12](../../../../guides/영상제작_마스터가이드.md)의 **“유료 생성 전 예상 입력·사용량·크레딧 상한·현재 잔액·추가 결제·충전·초과 사용·재시도 조건을 정한다.”**이다. Jun 선택은 이번 사용자 지시로 확정되었고, 확인할 것은 새 편의 포함 크레딧 사용 상한이다. 화면 설계·대표 시안·내용 확인은 병행한다.
