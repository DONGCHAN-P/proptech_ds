# 이번 편의 화면 개선 판단

사용자 요청: 좋은 Jun 음성을 보존하고 화면 밀도·도형 정렬·가독성을 높인다. 본편·썸네일·홍보 쇼츠·계산 요약 쇼츠를 준비하며, 업로드 공개 범위는 모두 비공개다. 일반 제작 판단은 총괄에게 위임되었다. 추가 유료 생성·충전은 진행하지 않는다.

## 유튜브 형식에서 이번에 적용한 것

1. **제목의 약속을 초반 화면과 연결한다.** 제목은 ‘현금 1억부터 5억까지, 얼마짜리 집을 살 수 있을까?’다. 초반은 모은 돈과 매물 가격의 간격을 보여주고, 원고의 질문·순서는 유지한다. YouTube는 첫 30초가 제목·썸네일에 대한 기대와 맞는지 살펴보라고 안내한다. [공식 시청 지속 시간 안내](https://support.google.com/youtube/answer/9314415)
2. **첫 계산의 가치를 전달한 뒤 짧게 구독·좋아요를 요청한다.** S14 상단에 6초간 시각적 안내를 넣고, 마지막 S31에서 다음 편 예고와 함께 유지한다. 좋은 음성을 살리기 위해 추가 TTS 없이 화면 안내로 구현했다. 이 배치는 이번 편의 편집 판단이며 성과가 입증된 공식으로 표현하지 않는다.
3. **마지막은 다음 행동 하나를 남긴다.** 본편은 다음 편 기대와 내 예산 작성으로, 홍보 쇼츠는 본편 예산 계산으로, 요약 쇼츠는 자기 예산 작성으로 연결한다. YouTube의 클릭 가능한 최종 화면은 마지막 5~20초에 넣을 수 있다. 이번 로컬 영상에 넣은 구독 문구와 실제 YouTube 최종 화면 설정은 별도 상태로 관리한다. [공식 최종 화면 안내](https://support.google.com/youtube/answer/6388789)
4. **쇼츠마다 역할을 나눈다.** 홍보용은 ‘돈은 모았는데 어떤 집을 살 수 있을까?’라는 질문, 요약용은 준비금 차감→LTV 역산→대출→월 부담의 한 계산을 완결한다. YouTube 관련 동영상 연결은 본편이 공개 또는 일부 공개여야 가능하므로, 모두 비공개인 이번 상태에서는 연결 완료로 기록하지 않는다. [공식 Shorts 관련 동영상 안내](https://support.google.com/youtube/answer/14075157)

공개 후 비교할 지표는 첫 30초 잔존율, 계산 단계 전환의 이탈, CTA 전후의 유지율, 썸네일 노출 클릭률과 시청 시간이다. 데이터가 없는 현재에는 개선 효과를 단정하지 않는다. 유지율 급상승은 관심과 이해 부족에 따른 재시청을 함께 검토한다.

## 실제 수정 범위

- 모든 장면의 첫 설명 대상은 진입 직후 보여준다. 원래 숫자·단어 비트는 후속 전개에 활용한다. 첫 등장 그룹이 수 초 뒤까지 숨겨져 제목만 남던 원인을 제거했다.
- S04의 선과 문자 화살표를 같은 좌표의 SVG로 교체했다. 연결 그룹에 y 이동을 주지 않아 접점을 고정한다. S09 분수의 분자·분모·선을 같은 폭과 중심에 맞췄다.
- S03은 돈·대출이 집으로 연결되는 도식, S09는 소득과 대출 상환의 분수, S10은 심사/납부 경로, S12는 사례 설정, S23은 차주/주택 조건, S24는 계약 전 순서, S25는 월 소득 배분, S29는 수요 관리/실수요 지원으로 다시 구성했다.
- S13·S15·S16·S18은 설명을 기다리는 공간에 주택을 유지하다 결과 도식으로 바꾼다. S22는 앞서 본 70% 기준 막대를 먼저 보여주고 40% 비교를 전개한다.
- S21은 상세 영수증 뒤 준비금 4000만원의 분할 도식으로 전환한다. 정확값 1306만8000원과 2693만2000원을 보존한다.
- 브랜드·목소리·전체 714.8초 시간표·원고·의미 단위 자막을 계승한다. 기존 MP4와 승인 기록은 보존한다.

## Claude 및 업로드의 실제 상태

Claude Desktop에서 **Opus 5.5 / 최대**를 선택하고 기준본 실제 인코딩 장면 모음 `encoded_scenes_1.jpg`와 개선 판단을 전송했다. 새 대화 제목 ‘영상 화면 품질 개선 검수’와 추론 중 화면을 확인했다. 이후 Windows 컴퓨터 제어가 현재 브라우저 URL을 충분히 확인하지 못해 정책상 종료되었다. 답변을 읽거나 수정본 승인을 받은 것으로 기록하지 않는다. 파일 선택에서 세 장을 지정했으나 실제 첨부는 한 장만 확인되어 전송 범위도 한 장으로 기록한다.

기존 YouTube API 계정의 읽기 전용 확인은 `invalid_grant: Token has been expired or revoked`로 실패했다. 다른 계정·토큰을 찾거나 권한을 확대하지 않는다. 브라우저 제어도 종료되었으므로 실제 비공개 업로드는 미실행 상태다. 일반 제작 판단 위임을 인증·권한 복구나 새 결제 승인으로 확대하지 않는다.

실제 청취·연속 재생과 제공자 정렬/ASR·샘플 프레임 검수는 구분한다. 최종 파일 검수가 끝나도 미확인 항목을 합격으로 바꾸지 않는다.
