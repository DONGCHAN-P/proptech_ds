# 현금 1억부터 5억까지, 내 집 예산 잡는 법 — 영상 가이드 v1

2026-10-27 · 원고·자료 확인 2026-10-26 · **사용자 직접 녹음에 맞출 화면 설계안**

기준 원고는 다운로드 폴더의 `현금_1억부터_5억까지_내집마련_유튜브_대본.docx`입니다. 낭독 본문 48문단을 7개 장·31개 설명 장면으로 연결했습니다. 원고의 순서와 말투를 기준으로 삼고, 아래 문장 수정은 제안으로 구분했습니다. 기존 18분 42초 영상의 계산 사례·합성음성·타임코드는 이 원고에 가져오지 않습니다.

**이번 영상의 중심 질문은 “통장에 모은 돈이 어떻게 내 집 가격으로 바뀌는가?”입니다.** 현금에서 준비금을 떼고, 대출로 주택가격을 만들고, 마지막에 그 대출을 매달 감당할 수 있는지 확인하는 과정이 화면에서도 이어져야 합니다.

## 1. 먼저 전달할 인사이트

| 시청자가 발견할 것 | 이번 원고의 근거 | 가장 적합한 화면 |
|---|---|---|
| 집값 예산이 커진 만큼 내 순자산이 커지는 것은 아니다 | 현금 1억→2억에서 집값 예산은 2.66억→5.66억. 자기자금 증가 0.9억과 대출 증가 2.1억의 합 | 집값 증가분 3억을 두 색으로 분해 |
| 현금이 늘어도 대출이 계속 함께 늘지는 않는다 | 대본의 개인별 대출한도 4억 조건에서 현금 3·4·5억의 사용 대출은 모두 4억 | 4억에 닿아 멈추는 대출 막대와 계속 늘어나는 자기자금 |
| 현금이 같아도 대출 조건이 다르면 집값 예산이 달라진다 | 현금 2억·준비금 3000만원에서 대출 3.96억이면 집값 5.66억, 대출 2억이면 집값 3.7억 | 같은 자기자금에서 대출 부분만 줄어드는 두 사례 |
| 최대 예산과 생활의 여유는 별개로 선택할 수 있다 | 현금 5억에서 8.4억 집은 월 약203만원, 7억 집은 월 약132만원 | 대출 4억→2.6억, 월 부담 약71만원 차이 |

기획의 결론은 “최대한 비싼 집을 사자”가 아니라 **자기 현금·대출 조건·월 여력을 연결해서 탐색 가격대를 정하자**입니다. 표의 다섯 결과를 읽는 것보다, 결과가 달라지는 이유에 화면 시간을 씁니다.

## 2. 영상의 기본 형식

이번 제안은 **사용자 목소리 + 계산 모션그래픽 + 필요한 생활 이미지**입니다. 얼굴 촬영은 필수로 두지 않았습니다. 문서 전체를 화면에 띄우거나 장마다 같은 집 이미지를 놓고 숫자만 바꾸는 형식 대신, 계산 대상이 바뀔 때 시각 자료의 역할도 바꿉니다.

검토한 형식은 세 가지입니다. 얼굴 설명 중심은 표정과 신뢰 전달에 좋지만 별도 촬영·구도가 필요합니다. 표 중심은 다섯 결과를 비교하기 쉽지만 계산 원리가 묻힙니다. **이번에는 목소리와 자금 흐름 모션을 중심에 두는 안을 제안합니다.** 이미 작성한 원고와 직접 녹음 의도를 가장 잘 살립니다. 최종 구현 전의 설계안입니다.

스타일은 공개된 매매·전세·월세 Jun 편의 아이보리 바탕·네이비 글자·Pretendard·흰 자막 박스를 계승합니다. 역할별 색은 이번 편에서 일관되게 사용합니다.

| 정보 | 색·표현 |
|---|---|
| 집값에 넣는 자기자금 | 파랑 `#286cda` |
| 빌리는 대출 | 골드 `#c29a44` |
| 별도 준비금 | 회색·작은 독립 영역 |
| 월 부담이 줄어든 여유·최종 선택 | 초록 `#3f8f7f` |

가격이 다른 집을 건물 크기나 가구의 호화로움으로 표현하지 않습니다. 같은 집 형태 옆에 금액·자금 구성을 보여줍니다. 실제 평면이나 평형이 필요한 경우에는 단지·주택형이 확인되는 공개 도면을 확보한 뒤 연결합니다.

원고의 예상 분량은 10~13분입니다. 현재는 **녹음 전 추정**이며, 실제 길이는 녹음과 편집 후 측정합니다. 원고를 정해진 러닝타임에 억지로 맞추지 않습니다.

## 6. 직접 녹음할 때

7개 장을 각각 `CH01_take01.wav`부터 `CH07_take01.wav`로 녹음하면 수정 관리가 쉽습니다. 전체를 한 파일로 녹음해도 작업할 수 있습니다. 장 제목·‘화면 |’ 지시·제작 참고용 계산표·출처 목록은 읽지 않고 본문만 읽습니다.
