시각자료 전체는 1080×1920 세로에서 새로 구성했다. 가로 본편을 중앙 크롭하거나 축소하지 않는다. Pretendard 제목 64px·자막 54px·조건 26px를 사용한다. 배경 주거 형태만 화면 밖까지 확장하고 제목·수치·자막·조건은 별도 레이어에서 고정한다. 화살표는 쓰지 않는다. 생성 이미지와 새 외부 자료는 사용하지 않았다.

`youtube_portrait_full_frame_v2` 기준으로 x140~840/y260~1360 안에 읽어야 할 글자 경계를 보호한다. 원어·숫자·단위를 보존하면서 자막을 1~2줄로 나누고 두 줄의 길이를 균형 있게 맞춘다. 고정 흰 자막 영역은 큐 사이에도 유지한다. 마지막 3초에는 각 편의 다음 행동 문구를 같은 영역에 표시한다.

원본 음성 파일은 모두 `narration/jun-user-script-v1/paragraphs/<단위>P01/audio.wav`이다. 아래 시각은 원본 장별 WAV에서의 초이며 본편 MP4의 시각이 아니다. 원본 재생속도·피치를 유지하고 접점의 3ms만 램프 처리한다. 화면 프레임 정렬에 필요한 0~27ms 패딩과 마지막 3초를 제외하면 새 음성을 만들지 않는다. 렌더 오디오는 AAC 48kHz mono, 원본 WAV는 44.1kHz mono이다.
