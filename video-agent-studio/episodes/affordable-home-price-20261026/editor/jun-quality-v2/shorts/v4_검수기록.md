최종 검수 대상은 `01_promo_jun_v4.mp4`, `02_summary_jun_v4.mp4`이다. v3의 편집 판단을 유지하고 파란 도형 집을 기존 승인된 목재 주택 컷아웃으로 교체했다. 홍보형 공개 설명에서 내부 음성 제작 문구 한 문장을 제거했다.

두 MP4 전체 영상·오디오 디코딩 통과. 1080×1920·30fps·SAR1:1·회전0·H.264·AAC/48kHz/mono, 38.166667초/51.466667초를 확인했다. 글리프 경계146개와 `youtube_portrait_full_frame_v2` 안전영역·글꼴 최소값 검사 실패0, 자체 UI 모사 겹침0이다.

`v4_regression.json`에서 v3 대비 실제 AAC 스트림 바이트 동일, 발췌 WAV 바이트 동일, SRT 바이트 동일, 모든 캡션 텍스트/줄바꿈/시각·원본 구간·출력 프레임/길이 동일을 확인했다. 대표 원시 합성 프레임36개를 코드로 비교해 집 표식 영역 밖의 픽셀이 동일함을 확인했다. 따라서 막대·자막·출처·다른 도형은 변경하지 않았다.

목재 표식은 승인 PNG의 알파 경계를 사용하며 모든 장면에서 같은 이미지·방향·241×208px 표시 크기로 재사용한다. 원본 PNG는 수정하지 않았다. 집은 가격·면적이나 실제 장소를 입증하는 자료가 아닌 공통 상징이다. 새 이미지 생성은 없다.

v4 MP4에서 홍보19개·요약25개의 표본 프레임을 추출했다. 이 변경분 검수에서는 그중 목재 표식이 보이는 홍보0.800초·35.500초, 요약7.300초·24.500초를 2×2 합성 화면으로 실제 관찰했다. 잘림·막대/자막과 겹침·가격에 따른 표식 크기 변화를 발견하지 못했다. 추출44개와 실제 관찰4개를 구분한다. v3 원래 관찰 기록은 `versions/v3/검수기록.md`에 보존한다.

이 기록은 자체 변경분 검수이며 실제 청취·연속 재생·Sagan 독립 QA를 수행했다고 주장하지 않는다. 두 파일의 실제 AAC가 v3와 동일하다는 것은 기계적 무결성 근거다. Sagan의 최종 검수는 v4 MP4·SRT·현재 SHA를 대상으로 요청한다.
