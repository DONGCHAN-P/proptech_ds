# v12 도달 전략 독립 검토

입력: `config/current_video.json` 기준 `video/out/newtown-v12-brand-bgm.mp4`, v12 시간표·SRT·출처, v11 썸네일. 원본 편집·업로드·유료 생성 없음.

## 확인 범위

- 실제 인코딩 영상에서 추출된 기존 QA 프레임 13.7/14/18.7/18.8초를 직접 확인하고, 90초 프레임을 새로 추출해 확인했다. 새 전 구간 프레임 검수나 연속 재생은 하지 않았다.
- 썸네일 원본과 320×180, 160×90 축소본을 직접 확인했다.
- 기존 기술 결과는 H264 1920×1080, 30fps, AAC, 634.933333초. 기존 검수 기록의 오디오 피크·디코딩 통과를 읽었으며 이번에 다시 측정하지 않았다.
- 실제 음성 청취, 휴대폰 BGM/내레이션 균형, 채널 분석 통계, Studio 저작권 검사는 미확인이다.

## 필수 점검

1. **가격 신뢰도:** 22.25억원 사례는 기사 기반이며 로컬 국평 거래 표본에서 대조되지 않았다. 원인도 미확정이다. 설명 출처를 명확히 하고 원자료 대조 또는 문구 변경을 결정하기 전 숫자를 썸네일 핵심 약속으로 키우지 않는다. 현재 썸네일은 가격을 내세우지 않아 유지 가능하다.
2. **방법 설명 명료화 점검:** 01:20.467 이후 SRT는 앞의 선을 ‘그해 … 중위가격’이라고 설명하지만 현 설정의 주 추세 차트는 분기별 중위가격이다. 새로 확인한 90초 프레임 자체는 ‘2026년 국평 37건’ 연간 설명 카드이므로 그 카드 수치를 분기와 혼동해서 오류로 확정하지 않는다. 담당은 ‘선’이 지칭하는 앞 장면이 분기선인지 대조해 해당 문구만 필요시 수정한다. 연간 카드와 분기 추세의 기준 차이는 설명에 명시하는 편이 좋다.
3. **공개 전 실제 청취:** 기술 오디오 스트림이나 볼륨 측정만으로 숫자 발음·BGM 마스킹·이어폰/휴대폰 재생을 보장하지 않는다. 최소 도입·지도·차트·엔딩과 모든 연결부를 실제 청취한다.
4. **AI 실사풍 공개 설정:** intro/outro는 실제 촬영처럼 보이는 가상 도심 생성물이다. Studio의 변경·합성 콘텐츠 설정을 확인한다. AI 썸네일 제작 자체만으로 표시 의무가 생긴다고 주장하는 것은 아니다. [YouTube 공식 기준](https://support.google.com/youtube/answer/14328491)
5. **소재 권한:** 공개 업로드 전 사진의 출처·저작자·CC/KOGL 조건 및 가공 조건을 재확인한다. 현재 출처 기록이 곧 모든 이용 조건 충족이나 Content ID 통과를 뜻하지 않는다. BGM은 로컬 합성 원본 기록과 제작 파일을 보관한다.

## 포장·유지율 권고

- 썸네일 큰 두 줄은 160×90에서도 판독된다. 보조 문구 ‘신도시 성공 공식’은 작은 화면에서 약하지만 클릭 핵심에는 필요하지 않다. 장식이나 글자를 더 추가하기보다 현재 두 줄을 유지한다.
- ‘광교·동탄 / 왜 달랐을까?’는 두 지역끼리의 차이를 묻는 것으로 오독될 수 있다. 제목에 ‘다른 신도시와’ 또는 비교 단지 맥락을 넣는다. 시청자의 질문은 ‘광교·동탄 중 어디를 살까’보다 ‘어떤 조건을 가진 신도시를 살펴볼까’에 맞춘다.
- 신규 채널에서 상승 수익률 후킹만 강화하면 단기 투자 팁을 기대한 시청자가 데이터 학습 내용을 보고 이탈할 수 있다. 도시 선택 조건이라는 영상 효익을 설명 앞부분과 제목·설명 첫 문장에 맞춘다.
- 시간표상 브랜드가 13.733~18.733초, 단지명 음성은 27.533초, 다음 신도시를 보는 기준이라는 효익은 39.333초에 나온다. 훅을 끊고 효익 공개가 늦다는 **가설**이며 실제 이탈 통계가 아니다. 사용자가 승인한 인트로는 이번에 유지하고 공개 후 해당 구간을 관찰한다. 다음 편에서 효익 선제시·브랜드 2~3초를 시험할 수 있다.
- 조회수·CTR 특정 숫자를 성공선으로 보장하지 않는다. 유입 경로별 노출 CTR과 첫 30초 유지율, 13~20초 이탈, 차트 시작 구간 이탈, 엔드스크린 클릭을 함께 본다. [첫 30초 공식 정의](https://support.google.com/youtube/answer/9314415)
