## 우리 창릉 연출 제안

1. 학교·상업·공원·기존 시가지의 생활 의미를 대상 가까이 한 문장씩 연결한다. 왕숙의 고정 상세도와 왼쪽 전체도 locator 유지.
2. 권역별 후보는 위치→생활 의미→이용 시점→입주 공백→맞는 수요자 틀 안에서 장점과 유보를 같은 순서로 답한다.
3. 제도가 선택을 바꾸는 순간에만 짧은 설명 도식 삽입. 최신 공식 공고로 검증하며 레퍼런스의 제도표는 복사하지 않는다.
4. 현재 대상만 강조하고 지난 블록 표는 접거나 축약한다. 여러 가격표·아이콘을 상시 누적하지 않는다. 가격 단위·면적·기준일·확정/추정 구분 명시.
5. 결말은 후보별 적합 수요자와 미확정 조건을 한 줄씩 정리한다. 단정적 최상 대신 검증 조건을 붙이고 우리 지도나 권리 확보 배경 사용.
6. 카메라 고정, 대상 테두리·학교 아이콘·노선 구간의 절제된 등장 제안. 이는 우리 연출 제안이며 원본 모션 검증이나 철회된 지도 줌 복원이 아니다.
7. 효과음은 실제 청취 미검증으로 특정 채택 0건. 향후 청취 시점·종류·이용조건 확보 후 결정. 장 전환/핵심 대상 등장 때 짧고 낮은 레벨의 권리 확보 소리를 내부 후보로 검토할 수 있다. 기존 승인 BGM·덕킹 기준 유지.

## 기본가이드 추가 문구 제안

레퍼런스는 원본 타임스탬프·관찰 근거·우리 연출 제안을 분리해 기록한다. 지도에서는 발화 대상과 학교·상업·공원·도로의 생활 관계를 하나씩 강조하고 지난 대상 표를 계속 누적하지 않는다. 제도가 판단에 필요한 순간 최신 공식 자료로 짧게 보조 설명한다. 권역별 결론에는 적합 수요자와 미확정 조건을 한 줄씩 남긴다. 효과음 채택은 실제 청취 근거와 이용조건 확보 후 결정한다.

공통 scenes.json을 읽지 않아 장면ID는 임의 배정하지 않았다. 총괄이 생활시설·권역별 후보·제도 보조설명·결론에 매핑한다. 원본의 예상가격·상승률·개통일·역 위치·청약 제도는 독립 사실 검증 범위 밖이며 research 검증 없이 사용하지 않는다.
