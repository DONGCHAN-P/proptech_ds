# 창릉 대표 시안 v2

최신 제작 브리프: 1920×1080, 왕숙 고정 지도·흰 자막 박스·담백한 색상을 계승한다. 교통은 기존 거점과 입주/철도 달력, 가격은 본청약 기본/확장/현재 대안 분리, 생활은 S4 관계도와 전체 위치 기준을 준비한다. 긴 우측 문단 대신 대상 가까운 짧은 라벨을 쓴다. 지도 급zoom·왕숙 도형 전용·정밀 미확인 역핀·새 유료 이미지 생성은 하지 않는다. brainstorming 지침의 명확한 요청 즉시 실행 기준을 적용했고, 직접 작성 도식/표이므로 imagegen 호출은 필요하지 않았다.

`review.html`에서 3개 PNG를 확인할 수 있다. SVG와 `drawing_data.json`은 같은 좌표 원본으로 재현한다. `build.py` → `render.ps1` → `finalize.py` 순서로 실행하며 무료 로컬 Python/Windows System.Drawing만 쓴다. PNG와 SVG는 동일 배치지만 글꼴 엔진별 글자 렌더 차이가 있을 수 있다. 폰트는 Malgun Gothic이며 최종 v15 Pretendard 통합은 편집 단계다.

S4 좌측은 국토교통부 고시2025-813호(2025.12.24), 토지이음의 본단지 가구·획지 총괄도 원본 전체를 비례fit했다. 출처표시+변경금지인 공공누리3유형 조사 인계를 적용한 조건부 채택 후보다. 표제·범례·테두리를 전부 유지하고 크롭·오버레이·트레이싱을 하지 않았다. 도면 안 S4 강조/테두리는 없고 도면 밖에 설명 대상을 썼다. 고해상도 원본을 먼저 직접 열람했다. 개별 S4 공고 도면은 상업 사용조건 미확인이라 삽입하지 않았다. 기업이전단지를 포함한 전체 지구 도면이라고 설명하지 않는다.

원도면 출처: https://www.eum.go.kr/web/gs/gv/gvGosiDet.jsp?seq=628391

PNG 3장을 직접 view 도구로 확인했고 S4 전체도 교체 후 다시 확인했다. 실제 1920×1080, 긴 문자 경계, 숫자/단위, 자막 여백, 원도면 전체fit과 별도 관계도 구분을 점검했다. 이는 대표 시안이며 실제 음성·연속 영상·효과음 믹스 검수가 아니다. `sceneplan.json`은 편집 전달용 후보, `audio_cues.json`은 무음 우선의 미선정 큐다. 초 단위 시간은 확정하지 않았다.

대본 v2와 실제 음성이 오면 해당 문장으로 트리거를 연결한다. 2025.12.24 이후 고시의 완결성, 실제 지도 안 정밀 locator, S4 최신 개교 확정 및 실제 출입구/횡단보도 접근시간은 미해결로 남긴다. 이번 작업은 full video render가 아니다.
