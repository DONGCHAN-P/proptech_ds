# 실제 지리 지도 소스 v1

`outputs/geographic-v1/GEO01_commute.png`, `GEO02_life.png`는 1920×1080의 재사용 대표 소스다. 대본 고정 영상이나 본편 완성본이 아니다. 최신 사용자 지시에 따라 무상 지도 2판과 메타데이터 저장까지만 마무리했다.

Overpass 공개 서비스에 범위를 제한한 벡터 요청 1회로 실제 도로·철도·하천·운영역·시설·아파트 용지 데이터를 받았다. 재시도·타일 요청·유료 호출·AI 생성은 0회다. `raw/query.overpass`, `raw/osm.json`이 입력 증거이며 `render.py`를 로컬 Python/Pillow로 실행해 재현한다. `osm_subset.geojson`은 ODbL의 파생 데이터로 같은 라이선스와 출처를 유지한다. `locations.json`의 OSM ID/원URL에서 각 좌표근거를 추적할 수 있다.

기존 원흥·새절·DMC·행신·대곡·삼송·지축역은 OSM station 노드 대표 위치다. 운영망 이름은 commute-v3의 공식 근거를 계승했다. 좌표 자체의 독립 공식자료 전수 대조나 측량을 했다는 뜻은 아니다. 노선은 실제 OSM way 선형과 이름 태그로 구분했다. 미래 창릉역 정밀 핀, 임의 접근시간, 계획블록 경계를 넣지 않았다.

생활권 지도에는 OSM에 이름과 용지가 있는 삼송2차아이파크, 삼송원흥역센트럴푸르지오, 도래울센트럴더포레, 지축역센트럴푸르지오, 지축역중흥S-클래스북한산파크뷰 5개를 넣었다. 원래 용지 도형과 bbox 중심 마커이며 공식 사업경계·주출입구 표시는 아니다. 창릉호반써밋은 이름붙은 정류장만 검색되어 단지로 오인 표시하지 않았다.

IKEA 공식 고양점 페이지에서 권율대로420 주소와 롯데아울렛 입주를 직접 확인했다. 시설 사진과 CI는 사용하지 않았다. 수색교 이름 지오메트리는 이번 결과에서 확보하지 못했다. 덕양로·도래울로·권율대로·서오릉로는 확보된 실제 way다. 전체 길이나 도로 폭·횡단보도는 검증하지 않았다.

OSM 출처와 ODbL/저작권 URL을 지도에서 읽히게 표시했다. 상업 활용은 ODbL 조건(출처표시·라이선스고지·파생 데이터 공유)을 지켜 가능하다. 공식 공공누리3 전체 계획도는 별도 원본과 기존 전체fit 시안으로 참조하며 이 지도 위에 복사·크롭·트레이싱하지 않았다. 권리조건은 `rights_and_sources.json`을 보존한다.

PNG 2판을 직접 view로 확인했다. 생활권 판의 지축단지 라벨 겹침과 우측 여백을 수정하고 재확인했다. 후속 사용 시 설명 대상만 강조하고 카메라는 고정한다. 지도와 자막·출처를 별도 레이어로 두는 편집을 권한다. SVG는 편집 좌표 참조용으로 PNG와 글꼴/백판 세부 표현 차이가 있을 수 있으므로 본편 채택 전 해당 출력도 검수해야 한다.
