# 실제 화면 대조

왕숙 v15 인코딩 8장(50/175/235/290/365/650/905/916초), 광교·동탄 v14 3장(100/280/440초)을 추출했다. 기준 경로는 current_video와 video_style 및 왕숙 게시기록 previous_current_video가 일치한다. 비교 contact sheet를 직접 보았고 v2 교통·가격과 GEO01은 원본 크기도 직접 확인했다. 연속 재생/청취는 하지 않았다.

- 왕숙은 굵은 43px 제목과 작은 브랜드 행, 지도 큰 영역·얇은 하단 달력·작은 출처·고정 흰 자막의 위계다. 상세에는 좌측 전체도와 현재 영역이 있고 생활 요약이 대상 옆에 붙는다. 가격도 지리 지도와 표가 함께 있다.
- v2는 같은 크림/청색임에도 48px 일반 굵기의 제목, 29px 부제, 넓은 흰 카드·단순 연결선·문장 요약 중심이라 문서 발표처럼 읽힌다. 교통은 실제 위치 없이 역 이름→목적지를 나열하고 달력이 큰 별도 패널을 차지한다. 가격은 데이터는 풍부하지만 양쪽 대형 표/목록뿐이라 지도에서 설명하던 채널 리듬이 사라졌다.
- 주황 굵은 미확보 경고와 하단 면책형 문장이 정보보다 눈에 띈다. 해당 항목 옆 짧은 조건으로 축약하고 자막은 승인 발화를 그대로 사용한다. 경고를 삭제하며 실제 미확정을 확정으로 바꾸면 안 된다.
- geographic-v1은 실지리 선형·운영역·도로·하천을 확보한 유용한 바탕이다. 큰 두 줄 제목/설명과 우측 상시 텍스트 목록·부정 문구가 여전히 넓은 면적을 차지한다. 왕숙 셸로 정리하고 실제 출근 목적지 또는 시설 관계를 해당 발화만 강조한다. 지도 선형을 사실과 무관하게 새로 다듬지 않는다.
- 광교·동탄의 검정 외곽 셸과 큰 사진/거래 차트는 과거 문법이다. 자료 종류가 달라도 자막 위치와 설명 위계가 유지되는 점을 계승한다. 최신 왕숙 셸보다 과거 셸을 우선하지 않는다. GD14 100초는 원영상 자체에 제목 가림이 보이므로 복사 대상으로 삼지 않는다.

외부 3개 분석은 읽었으며 재다운로드하지 않았다. 위치 기준 유지, 대상만 강조, 생활 의미와 조건 회수만 보완한다. 외부 브랜드 복제나 효과음 검증 주장 없음.

`baseline_contactsheet.png`는 최초 실험 합성으로 세로 비율이 압축되어 비교 근거로 채택하지 않는다. 최종 `comparison_contactsheet.png`는 모든 타일의 원래 16:9 비율을 유지한다. 추출 원본 PNG는 모두 보존한다.
