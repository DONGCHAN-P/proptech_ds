본편 공개 이후 게시를 검토할 수 있는 로컬 검토본이다. 업로드·게시 시각·플랫폼 연결은 별도 승인 대상이다.

0.00~11.40초 S4 실제 계획 필지와 원흥 생활권·1,024세대 → 11.40~15.30초 S4 과거 공고가격 → 15.30~22.64초 가격수준 후보와 상승률 구분 → 22.64~33.24초 S5 낮은 공고가·빠른 입주 예정 → 33.24~42.32초 S1 현재 상암 연결 → 42.32~45.33초 화면 CTA. 상세 PCM 경계는 clip_plan.json에 기록했다.

작은 중앙 카드를 제거하고 지도와 가격 영역을 화면 전체 폭으로 재구성했다. 실제 계획 필지·지리 배치는 크게 유지하며 제목, 후보 요약, 자막과 출처는 화면 좌표의 독립 레이어다. 지도 강조는 0.8초간 변화하고 카메라는 고정한다. S1 선은 실제 대중교통 노선이 아닌 대표 좌표 간 위치 비교선이다. AI 자료·음악은 없다.

사용자가 요청한 전체 화면 구성을 위해 `youtube_portrait_full_frame_v2`를 명시 적용했다. 제목 58px, 자막 54px, 후보·요약 52~80px, 가격 104px, 출처 26px. 상단 헤더·오른쪽 액션·하단 메타데이터를 가정한 YouTube 세로 화면 모형과 폰 contain/cover 예시를 검토한다. 넓은 태블릿 cover·전 플랫폼 공통 가림 없음·실기기 재생을 보장하지 않는다.

음성은 v1과 동일한 기존 승인 Jun의 8개 발췌 PCM이다. 말의 속도·원문·22개 자막 시각은 유지했다. 마지막 3초 CTA는 화면에만 표시한다. v1 원본과 이전 검토본은 보존했다.

재현: `tools/python311/python.exe -X utf8 analysis/video_task_runner.py <editor/shorts-leader-v2/render_job.json>` 실행 후 `evidence.py`로 실제 MP4의 경계·긴 자막·지도 라벨·UI 모형 자료를 만든다. 소스 컴포지션·데이터·public 폴더는 render_project.json과 inputs_manifest.json에 연결되어 있다.
