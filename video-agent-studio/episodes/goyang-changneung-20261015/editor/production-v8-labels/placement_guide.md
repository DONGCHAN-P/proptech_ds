# 시설 계획번호 표시 패치 v8.1

납품: outputs/production-v8-labels/changneung_full_v8_labels.mp4

- 780.567~799.033초: S4 생활 필지 지도 및 학교 범례.
- 823.600~866.800초: S5/S4/S1 학교 상세 지도와 설명 카드.
- 본문 143개 PNG만 변경. 나머지 PNG와 도입/브랜드 파일은 기존 입력을 재사용한다. 최종 본문 비디오는 안정적인 프레임 정합을 위해 동일 타임라인으로 재인코딩한다.
- 내부 초·유·중·고 시설 계획번호는 source_data 및 facility_label_mapping.json에 보존. 시청자 표시는 학교 유형별 ‘예정 부지’로 변경한다.
- 표시 자막 3큐만 계획번호를 예정 부지로 정규화. 원래 대본과 음성, 날짜·목표·미정 의미, 213큐 시작/종료시간은 보존한다.
- 학교명·개교·배정 확정을 뜻하지 않는다. 실제 계획 자료와 목표·미정을 구분한 기존 문구를 유지한다.
- 카메라/전환/동작/레이어 및 출처 영역은 기존 v8과 동일하다.
- 실제 전체 청취·연속 재생은 실시하지 않는다. 변경부 추출 프레임·모바일 및 경계와 전체 디코드를 검사한다.
