# 창릉 실제 위치·토지이용 공간자료 v4

확인일 2026-10-16. **새로 확보한 LH 공식 공개 공간데이터의 실제 도형으로 상세 지도 제작이 가능하다.** S1/S4/S5를 빈 사각형이나 방위관계 패널로 대체할 필요가 없다. 원래 도면의 색·글꼴·배치를 복제하지 않고 좌표와 용도 사실을 채널 지도에 독립 표현한다.

## 편집에 바로 쓰는 파일

- `raw/landfeatures.geojson`: LH 내집어디 토지이용 WFS 원응답 733 features. `properties.bzdt_cd=105142`, `bl_type` 용도·필지코드, `geometry` 실제 MultiPolygon. EPSG:4326, 좌표는 [경도,위도].
- `raw/boundaryfeatures.geojson`: 같은 서비스 창릉지구 경계 원응답 1 feature. **창릉역 표시가 아니라 사업지구 경계**다. 기업이전단지 등 분리부분을 포함하는 서비스 응답이므로 본단지만의 면적과 같다고 가정하지 않는다.
- `target_blocks.geojson`: S1/S4/S5 도형만 추출. `S-1_context.geojson`, `S-4_context.geojson`, `S-5_context.geojson`: 같은 좌표의 인근 도형 subset. 전체와 상세 locator를 같은 투영으로 연결한다.
- `block_extents.json`: 원블록 bbox와 편집 후보 extent. 후보 extent는 화면 편의를 위한 범위이며 역세권·통학권이 아니다. 큰 도로 도형이 화면 밖으로 뻗을 수 있으므로 viewport clip한다. S5와 예정역을 같은 상세화면에 넣으려면 동쪽을 경도126.8812 정도까지 더 넓혀야 한다.
- `schools_by_block.json`, `landmarks_index.json`: 실제 학교코드·철도용지·CM1/CM2의 도형 bbox/중심(출입구 아님).
- `planned_station_context.json`: 공고의 창릉역 예정기호가 가리키는 중앙복합권역을 표시할 안내 범위. 정거장 중심·출입구·역사 시설경계는 미확인.
- `raw/lh_land.png`: 동일서비스 WMS 전체 응답 1800×2100. **실제 열람한 공간 대조·검수판**이며 그대로 원도면 가공허가를 확인했다는 뜻은 아니다.
- `source_manifest.json`: 공개조회경로·쿼리·원응답 해시·날짜. 키 포함 없음.

S1 추가 공간정합 표본: 공식 본청약 모집공고 첫 장은 행신동313번지 일원이라고 명시한다. 기존 무료 VWorld 키로 해당 지번을 조회한 좌표는126.84690040025342,37.62927817754951이며 S1 도형 범위 안이다. 지번대표점과 단지출입구는 다르다. 원응답은 `raw/s1_address_vworld.json`에 보존했고 키는 출력·복사하지 않았다.

## 창릉역과 창릉지구 구분

2026 S4 공식첨부 `../map-clearance-v1/raw/s4_landuse_202607.jpg`를 실제 열람하면 ‘GTX-A 창릉역(예정)’의 작은 원형기호는 CM1/CM2 중앙복합권역 접점에 있고, 넓은 붉은 지구계와 별개다. WFS CM1·CM2 참조범위는 [126.87570974,37.62101002,126.87998574,37.62431476]이다.

이 범위는 공고의 위치관계를 시청자에게 보여줄 **편집용 안내권역**이다. 역 확정 부지경계나 통계적 오차구간이 아니다. 전체 지구는 넓은 외곽선, 역은 다른 색 점선타원과 ‘GTX-A 창릉역 예정권역 / 정확 출입구 미정’으로 구분한다. 작은 철도시설 필지가 여러 곳 있어 그중 하나를 근거 없이 역사 또는 출입구로 확정하지 않는다. 직선500m 반경·도보분수는 산출하지 않는다.

## 기준일과 고시 대조

WFS 필드에는 승인 고시번호·계획기준일·갱신일이 없다. **‘LH 내집어디 공개 공간자료 조회2026.10.16, 계획변경가능’**을 표시한다. 2025.12.24 고시 제2025-813호와 같은 버전이라고 가정하지 않는다.

실제 열람한 고시 전체도와 WMS 전체도를 육안 대조한 범위는 세 블록의 주요 주변형상·관계다. S1의 분리권역과 초7유7, S4의 초6유6/북측상업/남측공원, S5의 A4/남측교육군/북측업무·도로는 주요 관계가 일치했다. 733도형 전수 정합이나 법적 최신계획 완결성은 검증하지 않았다. 색·세부 분할이 다른 부분도 있어 공고 이미지를 현재 WFS 스타일과 혼합하지 않는다.

## 이용조건 판단과 대체 해법

[공공누리3유형 공식조건](https://www.kogl.or.kr/info/licenseType3.do)은 변경 및2차적저작 작성을 금지한다. 하지만 문구에 ‘모든 화면 확대’, ‘모든 부분표시’, ‘크기 조절’이 일률금지라고 직접 쓰여 있지는 않다. 기존 전체도 크롭·확대 절대금지 설명은 보수적 편집 권고였으며, 모든 연출에 대한 확정 법률판단으로 사용하면 과도하다. 그렇다고 이번 조사에서 원도면 크롭·라벨덧씌우기 허락을 확보했다고 하지 않는다.

이번 해법은 KOGL3 JPG의 기하학을 트레이스하는 것이 아니라 **별도로 공개조회한 WFS의 좌표·필지용도 사실을 자체 지도에 표현**하는 것이다. LH WFS 데이터의 개별 재사용 라이선스 문구는 확인하지 못했으므로 ‘포괄적 원도면 가공허가 확보’라고 기록하지 않는다. 원래 WMS 이미지·제3자 배경지도·로고·홍보도면 표현의 복제와 구분한다. 표시는 ‘자료: LH 내집어디 공개 공간정보, 조회2026.10.16 / 계획변경가능’과 공식 서비스 링크를 권고한다.

국토부 [토지이용계획정보15123973](https://www.data.go.kr/data/15123973/openapi.do)는 무료·이용허락범위제한없음을 확인했다. 다만 설명상 법정 용도지역 등과 지적정보의 융합자료이며 이번 확보한 LH 신규개발 블록 계획과 동일 데이터라고 검증하지 않았다. 따라서 해당 라이선스를 LH WFS에 대신 붙이지 않는다.

## 화면 권고

1. 전체 토지이용 도형을 자체 팔레트로 그리고 S1/S4/S5 라벨과 지구경계를 명확히 한다. 물·도로·학교·공원 범례를 분리한다.
2. S5 확대는 원 geometry 그대로. 단지 강조 후 초5/유5/중3/고2, 남측 공원, 북측 업무·주차·보행자도로를 순차 설명한다. 상업은 실제 상업용지로 분류된 주변 필지만 표시한다.
3. 같은 전체 지도에 현재 상세 extent 테두리를 표시하여 위치를 연결한다. 원본 공공누리 도면 위에 locator를 덧그리는 방식이 아니다.
4. S1/S4도 동일 구현을 쓰되 학교 코드를 각각 바꾼다. bbox 중심을 출입구 핀으로 쓰지 않는다.
5. 원래 KOGL3 전체판 비례fit만으로1080p에 표시하면 S5·학교 문자가 매우 작아 이번 사용자 상세가독성 요구를 해결하기 어렵다. 전체판은 검증자료/보조 확인판으로 두고 상세는 실제WFS독립지도 구현이 낫다. 최종 편집영상 가독성은 editor·QA가 실제 렌더로 판정한다.
