# 창릉 주변 기존 아파트 가격 비교 v2

확인일 2026-10-16. 작성 범위는 가격 비교 자료이며 대본·공통 상태·기존 master는 수정하지 않았다.

## 최종 입력과 재현

공식 국토교통부 아파트 매매 실거래가 상세 API의 덕양구 41281, 계약월 202607·202608·202609만 무료 GET으로 조회했다. 최초 샌드박스 연결 실패 3건 후 허용된 네트워크 실행으로 성공했다. 성공 응답은 이 폴더 raw에만 저장했다. 월별 응답 전체 건수/실제 item은 473/473, 465/465, 407/407이며 페이지당 1000 한도 안이다. 키·키 포함 요청 URL은 산출물에 넣지 않았다.

재현 명령(추가 네트워크 호출 없음):

`tools/python311/python.exe video-agent-studio/episodes/goyang-changneung-20261015/research/prices-v2/calculate.py`

`refresh.py`는 자료 갱신이 다시 승인된 때에만 사용한다. calculate.py는 보존 XML을 읽어 comparisons.json·facts.json·verified_rows.csv를 다시 만든다. 입력 파일 SHA256와 월별 수집시간은 comparisons.json audit.sources에 있다. verified_rows.csv의 source_file와 source_item_index(1부터 시작)는 XML의 해당 item을 지정한다. 총 유효 표본 68건이다.

공식 서비스 설명: https://www.data.go.kr/data/15126468/openapi.do — 계약연월·법정동 앞5자리별 신고자료, 무료, 이용허락범위 제한 없음. 응답 전용면적 excluUseAr, 금액 dealAmount(만원), 계약일 dealYear/Month/Day, 층 floor를 사용했다. 기존 스키마 변환은 run_step2.py의 COL_RENAME_TRADE와 clean_trade_xml을 추적했다. 기술문서 HWP 본문은 이번 작업에서 읽지 않았으며 필드의 세부 의미가 필요한 추가 검증 범위로 남긴다.

## 동일 조건과 통계

- 계약일 2026-07-01 이상 2026-10-01 미만, 전용면적 83㎡ 이상 85㎡ 미만, 5층 이상.
- 아파트 매매 응답만 사용. 중개거래·직거래를 함께 포함하고 행별 raw_dealing_type으로 공개한다. 신혼희망타운/분양권/전세 자료를 섞지 않는다.
- cdealType 또는 cdealDay가 공백이 아니면 제외. 선택 6단지 조건 일치 원자료에서 삼송2차아이파크 1건·도래울센트럴더포레 1건을 제외했다. 나머지 0건. 원자료 해제 여부를 추정 보완하지 않았다.
- 단지별 계약 거래금액 전체를 정렬한 중위값. 짝수 n은 중앙 두 값의 산술평균. 월 중위값 평균이 아니다. 최고가·평균가·현재 호가가 아니다.
- 원금액은 만원 정밀도로 보존. 화면에서 억원 소수 둘째 자리 표시 시 8.375→8.38, 11.275→11.28로 반올림한다. 표본 n은 이 기간·면적·층·취소 조건을 통과한 행 수이며 전 기간 보유행 수가 아니다.
- n<5는 소수 표본. 원흥역센트럴푸르지오 n3은 보조 참고 카드만 권장하며 안정된 시세·가격 우위의 근거로 쓰지 않는다.
- 같은 면적 범위여도 정확한 타입·향·동·수리상태·준공연도는 다르다. 분양가와 실거래 중위값의 차이를 차익·수익률로 해석하지 않는다.

## master 차이와 중복 처리

기존 master/trade_events.parquet와 직접 대조했다. 선택 master 행의 해제플래그 결측 0, 금액·면적·층·날짜 결측 0, 해제일 존재/해제플래그 false 불일치 0, deal_hash 중복 0이었다. 새 원자료에만 있는 정상행은 5건이다. 이 중 4건은 기존 보존 raw에도 없었던 9월 신고이며, 조회 시점 차이로 설명 가능한 새 행이다. 과거 취소·정정 누락이 전혀 없다고 보장하지 않는다.

나머지 삼송2차아이파크 2026-08-28/84.739㎡/10층/94,500만원은 기존 raw에도 있었지만 master에는 없었다. 동일 일자·면적·층의 다른 금액 행도 존재한다. run_step3.py dedup_trades가 apt_id/계약일/면적/층 기준으로 높은 금액 하나를 남기는 구조여서 실제 별개 신고를 지울 수 있다. 이번 최종 집계는 raw의 별개 응답 item을 그대로 유지했다. 동일 신고 ID가 없어 같은 일자·면적·층을 이유로 임의 삭제하지 않았다. 선택 정상 원자료의 금액까지 포함한 완전 동일 키 중복은 0이다. 기존 master 변경 없이 원자료 기준 6단지 68건을 사용한다.

## 지도와 해석 한계

기존 raw/subway/subway_stations.csv는 삼송 37.653083/126.895558, 원흥 37.650658/126.872642, 지축 37.648033/126.913917(서울교통공사쪽), 37.648017/126.913970(일산선쪽)을 담고 있다. updated_at은 2026-04-30이다. 원공급기관 메타데이터·현행 좌표를 이번에 독립 검증하지 못했으므로 보조 참고이며 새 정확한 역 핀을 확정하는 근거로 사용하지 않는다. 지축의 두 좌표를 두 개 역으로 그리지 않는다. 공식 지도 담당의 검증 좌표를 우선한다. 단지 출입구·보행경로·통근 소요시간은 미확인이다.

가격 해설은 ‘분양가격만’ 대신 총예산(확장·옵션·세금·금융비용은 개별 확인), 현재 완성된 생활시설, 입주대기 시간, 운영 중 철도와 향후 철도 달력의 차이로 연결한다. n이 작거나 조건이 다른 가격을 근거로 어느 쪽이 무조건 싸다고 단정하지 않는다. 도래울을 지하철 도보권으로 표시하지 않는다. 구체 시설의 운영 여부·통근시간은 별도 검증 담당 근거를 붙여야 한다.
