# 대본 v4 독립 검토 기준

이번 검토는 수정안의 내용과 화면 지시 검토다. 사용자 승인, 음성 생성, 본편 제작 또는 영상 검수 통과를 뜻하지 않는다. writer의 쓰기 완료 신호를 받은 동일 버전을 한 번 읽고 필수 항목을 묶어 전달한다.

1. 초반에 현재 신규 청약가를 소개하는 영상인지, 향후 일반 매매 후보를 비교하는 영상인지 취득 전제가 명시되고 결론과 일치하는가.
2. 원흥역 출발 열차 24·28·49분은 현관 출발 총통근시간과 구별되는가. 단지별 집→역 시간이나 통근 순위를 새로 만들지 않는가.
3. S4의 조건부 장점과 더 큰 공고가격 부담을 함께 회수하는가. 특정 타입·층 가격과 평균분양가를 구별하는가.
4. S5 759 / S1 494 / S4 1,024, 합계 2,277세대는 세 후보 단지 공고규모의 부분합이며 지역 전체 공급량·실제 확정입주량·현재 청약물량으로 오인되지 않는가.
5. S6 2027.12 사례 때문에 S5는 ‘비교 세 후보 중 이른 일정’으로만 표현하는가. S5 ‘중앙서측’은 검증된 전체방위로 단정하지 않는가.
6. 전매제한·거주의무의 별도 기산과 S3 상품 구조를 혼동하지 않는가. 단순 3년 경과가 자유매매 보장일이라고 쓰지 않는가.
7. 각 장에 숫자 나열 후 시청자가 얻을 결론과 실제 판단의 한계가 있는가.
8. 지도 화면 지시가 위치 확인·실제 대상 강조·환승 순서·비교·불확실성 중 어떤 기능인지 구체적인가. 근거 없는 최단경로·출입구·거리·미래가격을 화면 지시로 발명하지 않는가.
