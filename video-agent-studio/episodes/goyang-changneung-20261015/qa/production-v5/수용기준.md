# v5 변경 구간 독립 검수 기준

근거: 인증된 텔레그램 이벤트 718066298, 기준본 production-v4r2. 기존 음성·183개 정규화 자막·24,140프레임 유지. 실제 청취·연속 재생은 현재 미실시다.

## 기존 1:38~2:59 진단

- 1:38.233(2947프레임) 일자리 시작에도 전체계획도 화면이 유지된다. 같은 전체계획도 구성은 1:10.133(2104)부터 1:58.633(3559)까지 48.5초 이어진다. 제목·하단 자막이 바뀌어도 메시지 전환이 잘 드러나지 않는다.
- 1:58.633~2:09.833은 광역 업무지 다섯 곳을 말하지만 DMC 중심 지도에 서울 도심·여의도·마곡·강남의 실제 위치가 충분히 표시되지 않는다.
- 2:36.300~2:55.900은 상암·여의도·마곡·강남으로 설명 대상이 바뀌어도 DMC 지도 구도가 유지된다.
- 1:38.233~2:59.367 구간의 주화면 구성 시간은 전체계획도 20.4초, 지도/지도+시간표 약57.1초, 역 사진 약3.7초다. 지도 계열 비중 약70.4%는 설명용 모션 여부를 제외한 구성 분류이며 지루함의 단독 판정 수치가 아니다.
- 근거는 v4r2 전역 순번 표본과 project_v4 타이밍이다. 연속 시청이나 실제 청취 결과로 쓰지 않는다.

## 필수 수용 기준

1. 2947프레임 일자리 첫 문장에 주화면의 자료·구도·설명 상태가 명확히 바뀐다. 창릉 내부 자족용지의 장기 가능성과 당장 외부 직장 접근을 구별한다. 300여 기존 기업 이전을 신규 대기업 300곳 유치로 보이게 하지 않는다.
2. 3559~3749프레임의 서울 도심·상암 DMC·여의도·마곡·강남은 실제 위치 자료로 확인 가능한 범위에 표시한다. 발화군에 맞춰 대상 또는 연결 경로에 시선이 모인다. 지도 밖 장소를 하단 자막으로만 열거하는 상태는 미해결이다.
3. 4689~4865 상암·여의도, 4867~4961 마곡, 4965~5105 강남 설명은 대상·경로·비교 수치 중 해당 메시지를 담는 시각 요소가 구별된다. 제목·하단 자막 변화만으로 전환을 충족하지 않는다.
4. 본편 183개 큐를 message→visual focus 표와 대조한다. 지명/단지/학교/가격 대상 변경에는 해당 객체가 존재하고 강조가 발화 범위 안에 들어온다. 여러 장소를 한 큐에서 말하면 정렬 단어 시점 또는 의미군 단위로 매핑한다. 없는 단어 시점을 정밀 동기화로 주장하지 않는다.
5. 가격·생활 장면도 같은 지도에 고정하지 않고 설명 대상 가격행·실제 시설·학교/공원 면 등으로 초점을 옮긴다. S1/S4/S5 내부점 앵커와 명료한 연결선, 전체 locator를 유지한다.
6. 지속 확대·번쩍임·단발 위치 점프 대신 실제 설명 기능을 갖는 모션을 사용한다. 전환 직전/직후와 모션 중간을 검사한다. 15초 이상 같은 구성은 반복 진단 대상으로 표시하되 이해를 위한 유지 자체를 일률 탈락시키지는 않는다.
7. 원음 AAC, 원문 및 183큐 표시 내용·시간, 24140프레임과 브랜드/홀드/아웃트로를 보존한다. 변경 표본은 실제 최종 MP4에서 전역 순번/PTS로 검수하며 예전 필터 n 리셋 라벨을 재사용하지 않는다.

## 단계별 검수

대표 일자리·생활·가격 PNG 및 짧은 모션 → 지리·발화초점·변화 가독성 피드백 → 본편 확장. 최종은 모든 shot과 의미 변화별 대표 상태, 경계 ±1, 모션 중간/최대 강조를 대조한다. 반복 비중과 가장 긴 동일 구성 유지 시간은 v4r2와 같은 정의로 비교한다. 실제 청취/연속 재생과 프레임 표본·신호 검사를 구별해 기록한다.
