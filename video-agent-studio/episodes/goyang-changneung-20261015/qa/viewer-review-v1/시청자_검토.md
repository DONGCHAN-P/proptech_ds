# 창릉 영상 · 시청자 관점 개선 검토

후속 작업: 사용자 요청에 따라 아래 시각 개선을 본편 UI·모션 r5에 적용했다. 가격·공급·가족 달력 재구성, 후보·학교 실제 도형 강조, 운영 노선 그리기, 일정별 강조, 결론 조건 태그를 포함한다. 최종 산출물 검수 기록은 [r5 검수](C:/projects/realestate_reco/video-agent-studio/episodes/goyang-changneung-20261015/qa/production-v6-ui-r5/final_review.json)에 별도로 남긴다. 아래의 '본편 미적용' 설명은 최초 대표 시안 제작 당시의 기록이다.

검토 대상: 무료 TTS v6 r4, 15분33.933초. 아래 시간은 이 검토본 기준이다. 최종 Jun 음성의 시간으로 승계하지 않는다.

핵심 판단: 자료와 위치 근거는 갖춰졌지만, 화면에 있는 숫자가 생활의 판단으로 연결되는 속도가 느리다. 더 많은 모션보다 **지금 말하는 대상과 의미를 읽게 하는 변화**가 우선이다.

동일 상태 시간은 자막 변경을 제외한 보드·포커스 속성의 연속 구간을 계산했다. 첫 진입 모션 1초가 포함될 수 있다. 정체 가능성을 판단하는 근거이며 시청 이탈률을 측정한 값은 아니다.

## Claude와 대조한 결과

실제 Claude CLI에 최종 MP4에서 추출한 시간 지정 프레임14장과 모바일 축소 비교1장, 실제 자막·타이밍을 전달했다. Claude는 긴 정체 구간, 코드명 인지, 가족 달력 활용 방법, 결론의 조건 태그를 지적했고 해당 방향은 채택했다.

반면 '첫1분이 같은 지도'는 브랜드·전편 화면·계획도 전환과 맞지 않아 기각했다. 공급 설명으로 '2분 이상 절감'이라는 제안도 산술과 맞지 않아 기각했다. 경쟁 채널 대비 상위권이라는 평가는 비교 근거가 없어 사용하지 않는다. 전체 원문과 반론은 `claude_review.md`, `codex_response.md`에 보존한다. Codex의 정정을 Claude가 재승인했다고 표현하지 않는다.

## 대본 검토가 필요한 선택

- 통근 숫자를 덜 읽고 '목적지에 따라 판단이 달라진다'는 해석을 더하는 안. 숫자 낭독도 정보를 듣는 시청자에게 필요하므로 전부 삭제하지 않는다.
- 공급·제한의 중복 설명을 압축하는 안. 실제 문장과 최종 음성 길이를 확인한 뒤 10분 이상 요구를 함께 검토한다.

위 두 안은 현재 승인 대본·음성을 바꾸므로 이번에 자동 적용하지 않는다. 새 유료 음성·이미지·영상 생성은 실행하지 않았다.

## 검토 범위

실제 MP4 표본 이미지, 기존 컷 검수 근거, 실제 자막·편집 타이밍과 512px 축소를 사용했다. **실제 청취·전체 연속 재생·실제 휴대폰 앱 재생은 수행하지 않았다.** 따라서 음색·효과음의 인상, 실제 재생 중 체감 속도, 실측 시청 지속시간을 확인했다고 주장하지 않는다. 무료 Heami TTS를 최종 Jun의 품질·러닝타임으로 평가하지 않는다.
