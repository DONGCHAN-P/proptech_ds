# Data Insight — 30초 화면 문구 확정본 v1.1

무대사. 아래 문구는 생성 모델이 그리지 않고 한글 폰트로 별도 합성합니다.
로즈: ① 필요한 순간 바로 / 보라: ② 평소에도 먼저 / Before: 무채색.

## 00–04초 | S1
제목: 같은 월요일, 달라진 하루
자막: 출근 후 찾던 숫자가, 이제 먼저 도착합니다.
보조 표시: 월요일 Before/After
입력 이미지: A02, A07, A13

## 04–07초 | S2
제목: 질문 하나가 걷던 길
자막: 질문은 길었고, 답은 늦었습니다.
보조 표시: 이슈 인지 → 요청 부서 찾기 → 검토·재질문
입력 이미지: A04

## 07–10초 | S3a
제목: 평소에도 먼저 도착하는 신호
자막: ② 평소에도 먼저, 지표와 신호가 도착합니다.
보조 표시: 시그널룸 알림 · 프로모션 브리핑 예시
입력 이미지: A01, A07

## 10–13초 | S3b
제목: 11:00  쿼리지니
자막: ① 필요한 순간 바로, 검증된 데이터로 확인합니다.
보조 표시: 자연어 질의와 검증된 데이터
입력 이미지: A03, A09

## 13–16초 | S3c
제목: 14:00  또박
자막: 애매한 질문이, 분석을 시작할 요건서가 됩니다.
보조 표시: 요건 구체화
입력 이미지: A05, A12

## 16–19초 | S3d
제목: 16:00  본부 대시보드
자막: 확인에서 판단과 실행까지, 더 가까워집니다.
보조 표시: 대시보드와 짧아진 의사결정 경로
입력 이미지: A10

## 19–23초 | S4
제목: 밤과 주말에도
자막: 출근하지 않은 시간에도, 같은 기준으로 흐릅니다.
보조 표시: 매시 10분 · 야간·주말 이상 알림
입력 이미지: A04, A08, A01

## 23–27초 | S5
제목: 업무의 필요에서, 함께 만든 변화
자막: 30명 · 7개 본부가 함께 만든 일상의 변화입니다.
보조 표시: 30명 · 7개 본부 / Weekly 7회 / 2~3시간 → 5분
입력 이미지: A11, A06, A08, A10

## 27–30초 | S6
제목: 목적은 통제보다 안심입니다.
자막: 2027, 보고서 플랫폼으로 이어집니다.
보조 표시: 보안·정합성을 걱정하지 않는 환경
입력 이미지: A06

## 표기와 근거
인물·사무실 동작은 AI 재현입니다. 실제 UI는 제공 자료를 활용합니다.
30명·7개 본부·Weekly 7회·2~3시간→5분 등은 사용자 제공 구성안의 수치입니다.
모든 원본 13개를 사용합니다. 원본 ZIP과 기존 타 영상은 보존합니다.

v1.1 수정: 원본 A01은 시간대 알림, A07은 프로모션 브리핑이므로 특정 09:50 데일리 화면이라고 오인하지 않도록 제목·보조표기를 수정했습니다. Weekly 7회 수치는 사용자 시놉시스에만 근거하며 A08의 7종과 구분합니다.
