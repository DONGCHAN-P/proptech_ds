A02/A04/A11은 각각 모니터 사무실·폰 팬트리·노트북 라운지 키프레임의 배경 참고 자료다. 원본 사진 3장이 영상에 인서트로 보였다고 주장하지 않는다. UI10개는 모두 물리 디스플레이 내부에서 표시된다. 각 구간·유형은 asset_usage.json에 기록한다.

세 영상의 실제 1280×720/24fps 소스121프레임을 모두 추출해 내부 화면의 네 모서리를 측정했다. 좌표는 1920×1080으로1.5배 변환했다. 화면-베젤 명암 경계를 선형 fitting하고3프레임 median으로 미세 노이즈를 줄였으며 안쪽0.85source-pixel inset을 적용했다. 소스 시간 사이의 좌표는 보간한다. 각 기기의0.5/2.5/4.5초 실제 합성 대표스틸을 검사했다. 리프레임은 인물·영상·UI 전체에 같은 부모 transform을 적용한다.

폰의 둥근 화면과 노치에는 로컬 평면 clip path를 적용해 원본 베젤·노치가 드러나도록 한다. 손은 디스플레이 활성 영역을 가로지르지 않는 소스를 사용했다. 모바일 문구는 A01 원문 확대를 확인하고 mobile_text_inventory.md에 사전 작성한 뒤 로컬 한글 폰트로 재식자했다. 제공 화면 기반 모바일 재구성을 표기한다. 낮 시간 알림 원본 예시를 실제 야간 수신 로그라고 표현하지 않는다. 야간·주말은 사용자 시놉시스의 운영 범위다.

글꼴: 로컬 Pretendard WOFF2 및 모바일 합성용 설치된 맑은 고딕. 음악은 v1 original procedural composition WAV를 재사용했다. 외부 음원·추가 유료 생성은 편집 담당이 호출하지 않았다.
