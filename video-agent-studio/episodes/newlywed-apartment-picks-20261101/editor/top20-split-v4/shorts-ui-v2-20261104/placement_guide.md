## 재현 및 검수 범위

`tools/python311/python.exe -X utf8 <editor-task-root>/build_ui.py` → `proof_ui.py` → `pipeline_ui.py check` → `deliver_ui.py` 순서다. 실제 렌더 argv는 각 프로젝트 render_receipt.json에 보존한다. 대표 QA 통과 증거가 없으면 렌더 스크립트는 중단한다.

실제 MP4 ffprobe·전체 A/V decode·마스터 PCM 상관 대조와 대표/경계 프레임을 확인한다. 전체 글리프 실측은 원본 DOM에 대한 검사이며 독립 QA의 실제 MP4 판단과 구분한다. 실제 청취·연속 재생은 미수행이다.
