## v3 우선 적용 사항

기존 크림·네이비·파랑·Pretendard·흰 하단 자막을 계승합니다. 아래 v2 설명은 상속 이력이며, 다음 v3 규칙이 우선합니다.

- 최신 718066312 요구 및 후속 사용자 지시를 적용합니다. 현재 산출물은 script 승인 검토용 대표 HTML/PNG이며 최종 편집·음성·본편 렌더가 아닙니다.
- 도입 O002에서 국가데이터처 자료명, 2024 한계, 2026년 5~10월 계약/11월3일 조회/10월 신고 진행을 한 번 설명합니다. 지역별 통계 기관 문구는 반복하지 않습니다.
- 지역 제목은 ‘거주 수 N위’로 표시합니다. 가격 순위로 읽히는 순위 배지를 쓰지 않습니다. 옛 서구는 역사적 구역임을 명시합니다.
- hero/comparison/top5의 사진 구도를 계승합니다. 특징 문장은 문장별 카드로 바꾸고 사진은 특징 발화가 끝날 때까지 유지합니다.
- 가격 첫 원발화 단어에서 지도·지역 중위값·단지 자체 중위값으로 하드 컷합니다. 특징 마지막 단어 종료가 가격 시작보다 늦으면 거부합니다. 실제 단어가 없을 때는 시안의 문장 예산으로만 전환하며 provisional을 표시합니다.
- final-api-20261103-v2만 사용합니다. 원팩·정규화·지도·독립 검수 SHA를 연결합니다. 지역과 단지의 가격 및 n은 서로 별도입니다.
- 가격 지도 phase 내내 계약기간·전용면적·취소 제외·지역n·단지n을 표시합니다. 가격은 반올림 없이 ‘X억 Y,YYY만원’ 형식입니다.
- 부모 제공800x600 SVG의 바이트·비율·geometry를 보존합니다. 해당 단지의 검증 좌표/inside 결과가 일치하는 핀만 사용하며 핀을 재추정하지 않습니다.
- 긴 금액은 줄임표 없이 폰트 폭을 맞춥니다. 긴 단지명·숫자+단위를 자르지 않습니다. 본문 y900 이내, 흰 자막 y922~1052를 유지합니다.
- 사진·지도 이용조건과 전체 출처는 credits.md/json 및 price_map_credits.json에서 설명란으로 인계합니다. 예전 사진과 새 랜드마크가 다르면 자동 연결하지 않습니다.
- 기본3유형, 강남 최고가격, 기흥 최장 단지명, 옛 서구를 실값 경계 사례로 검사합니다.

## 상속한 v2 구도 설명

v1의 크림 바탕·네이비 제목·파랑 강조·Pretendard·흰 하단 자막을 계승한다.
주제별로 사진 중심(hero), 현재/옆 순위 비교(comparison), 상위5(top5)의 세 구도로 나눈다.
사진은 실제 원본 파일을 contain 배치하며 실제 장소·촬영연도·짧은 작가/라이선스를 보존한다.
사진 비율이 패널보다 넓으면 패널 높이를 낮춰 사진과 글의 간격에 목적을 부여한다.
지도는 기존 SVG의 실제 구 경계만 정적으로 크게 제시하고, 같은 지도 내 위치 안내를 작게 곁들인다.
지도 줌·가짜 좌표·사진 색보정·생성 보정은 사용하지 않는다.
단일 진행 막대 대신 다섯 행 순위 사다리(같은0~16,000쌍 척도)와 현재 지역 강조를 쓴다.

숫자는 정확한 최종값이다. 실제 발화 단어의 표시문/낭독문 대응을 찾아 강조를 시작한다.
수치 앵커가 없으면 값은 정적 자료로 표시하고 audit에 사유를 남긴다.
N001/N002는 같은53개구·같은2024.11.1의 전체 기준/초혼 기준을 나란히 놓는 행 비교도다.
행마다 지역 전체 이름을 크게 표시한다. 시간에 따른 순위 상승/하락으로 보이는 화살표를 쓰지 않는다.
새 장면은 extra_scenes.py의 함수 등록 또는 --scene-data와 --visual-module로 확장한다.
장면 수 고정·자동 Shorts 빌드는 없다.

제목43px·브랜드23px·고정 흰 자막39px을 계승한다. 24px 미만은 보조 위치도·척도·원자료 크레딧만 사용한다.
출처 y885, 자막 상자 y922~1052를 침범하지 않는다. E001은 C001 최종 화면을 그대로 유지한다.
