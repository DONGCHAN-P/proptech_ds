# TOP20 본편 비주얼·정보 보강 v2

요청: 기존 본편의 시각적 품질을 높이고, 유용한 추가 분석으로 실제 재생시간 8분을 넘긴다.

기준본은 top20-production-v1/main/top20_main_free_v5.mp4(470.966667초)이다. 이전 원고·음성·MP4·비공개 업로드 3개는 보존한다. 이번 요청은 수정본 제작이며 새 게시·삭제를 실행하지 않는다.

## 제작 판단

현재 자료는 서로 다른 실제 사진과 지도를 갖추었지만 지역 장면 20곳이 같은 크기와 배치를 반복한다. 사진·지도·숫자를 한꺼번에 고정 노출하는 방식 대신 실제 발화에 따라 시선 중심을 옮긴다. 채널의 크림색 바탕·네이비 제목·파란 강조색·Pretendard·흰 하단 자막은 계승한다.

1. 지역 장면은 사진 중심, 지역 비교 중심, 상위권 중심의 세 구도로 구성한다. 원본 비율과 실제 장소 표기를 유지한다.
2. 순위·규모는 고정 스케일의 작은 순위 사다리로 연결하고, 현재 지역을 강조한다. 지도는 실제 경계와 작은 위치 안내를 사용하며 같은 수도권 지도만 크게 반복하지 않는다.
3. 분석 장면은 변화선·비교 막대·순위 변화 등 각각의 질문에 맞춰 다시 구성한다. 현재 말하는 값의 앵커에서 모션을 시작하고, 충분히 읽을 최종 상태로 멈춘다.
4. 기존 전체 순위와 다른 기준의 순위를 원자료에서 다시 계산해 새로운 발견을 추가한다. 계산 결과가 유용하고 검증됐을 때만 채택한다. 목표는 정보 약 45~75초 추가, 실제 8분 30초 이상이다. 무음·느린 재생으로 길이를 늘리지 않는다.
