# 쇼츠 구성과 화면 개선 · 2026-11-04

사용자 요청: 갑자기 순위를 읽는 도입을 고치고, 최근 쇼츠 자료를 조사해 인트로·아웃트로와 UI를 보완한다. 기존 본편은 유지한다.

## 방향

기존 Jun의 완결된 질문으로 시작하며 첫 프레임에 신혼부부 **거주 수 순위**와 해당 범위를 표시한다. 로고만 기다리는 오프닝 대신 질문과 실제 지역 사진이 동시에 시작한다. 홍보편은 긴 통계 소개를 줄여 연수구의 두 생활권 가격 비교로 곧바로 이어간다.

순위편은 질문 → 다섯 지역의 도착·가격 비교 → 다른 순위 영상 안내의 구조다. 각 지역은 사진·큰 순위·지역명·거주 수를 먼저 보여주고, 가격 발화부터 두 생활권의 가격을 크게 비교한다. 상시 작은 5행 순위표는 없애고 현재 지역을 강조한다. 마지막에는 다른 편의 정확한 범위와 본편 연결을 표시한다.

## 검토한 방식과 선택

- 기존 대시보드의 색·테두리만 변경: 정보를 줄이지 못하므로 채택하지 않는다.
- 사진과 큰 가격을 중심으로 의미 단위마다 재배치: 이번 제작 방향. 채널의 Pretendard·크림·남색·파랑·금색은 계승한다.
- 새로운 전용 Jun 멘트 생성: 이번에는 기존 질문과 CTA를 그대로 재사용한다. 유료 호출·추가 크레딧은 0이며 원래 예산과 승인 자료는 보존한다.

## 구현 기준

사진을 어둡게 눌러 전 화면의 벽지로만 쓰지 않는다. 주요 가격은 대략 88~96px, 지역은 80px 이상으로 읽히게 설계하되 실제 글리프 검사로 확정한다. 제목 56px·자막 54px·핵심값 52px·조건/출처 26px 이상, `youtube_portrait_full_frame_v2`의 실제 글자 경계와 앱 UI 모사를 적용한다. 전체 화면을 작은 카드로 축소하지 않는다.

가격·표본은 기존 팩트 파일 그대로다. 금액마다 Jun 제공자 문자 정렬을 사용해 별도로 등장하고, 완성 후 읽을 시간을 확보한다. 남동구는 77개 단지의 가격 구간별 분포로 표현한다. 다른 지역의 동별 거래 중위값과 단위를 섞지 않는다.

사진 전환은 약 0.3~0.4초의 부드러운 연결을 사용한다. 현재 발화를 덮지 않으며 다음 지역의 수치가 일찍 등장하지 않게 한다. 반복 줌·과도한 흔들림·작은 순위표·긴 부정형 푸터·AI 제작 설명은 넣지 않는다. 자막 박스는 활성 큐에만 표시하고 마지막 발화 뒤 1.05초를 확보한다.

## 근거와 검수

공식 Shorts 제작 자료의 첫 순간 주제 전달·짧은 이야기·직접 편집·후속 영상 연결 원칙을 적용한다. 광범위한 유행이나 성과 보장으로 과장하지 않는다. 출처별 게시일·확인일·관찰 범위와 우리 화면에 적용한 해석은 `research/shorts-ui-v2-20261104`에 별도로 보존한다.

대표 도입·지역 진입·가격·아웃트로 화면을 먼저 검토한 뒤 세 편을 출력한다. 실제 MP4의 장면과 전환, 긴 자막, 숫자 최초 표시, 마지막 발화/유지 화면을 검사한다. 실제 청취와 연속 재생은 수행 여부를 구분한다. 새 완료 결정은 새 파일 해시에만 연결하며 기존 승인·게시 상태를 가져오지 않는다.
