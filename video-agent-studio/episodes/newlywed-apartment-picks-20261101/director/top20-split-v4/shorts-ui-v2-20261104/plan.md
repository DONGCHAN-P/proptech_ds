# 쇼츠 개선 실행 계획

> **For agentic workers:** 제작팀의 역할별 소유권과 WORKFLOW를 따른다. 이 계획의 사용자 요청 범위 안에서 기존 발화를 재편집하며 새 유료 호출과 게시를 하지 않는다.

**Goal:** 질문형 인트로와 간결한 아웃트로, 사진·큰 가격 중심 화면으로 쇼츠 세 편을 다시 제작한다.

**Architecture:** 총괄은 기존 Jun 문장을 재배치해 새 오디오·자막 타임록을 만든다. 편집 담당은 새 HyperFrames 프로젝트로 구성하고, 독립 검수 담당이 정확한 최종 MP4를 검사한다. 본편과 과거 버전은 보존한다.

**Tech Stack:** HyperFrames 0.8.181, GSAP, 기존 Pretendard·사진, Python/FFmpeg, 기존 Jun WAV·제공자 정렬.

**Spec:** `design.md`

## 실행과 확인

- [ ] 공식 2025~2026 Shorts 자료를 조사하고 실제 지침·장르 한정 사례·우리 적용안을 구분한다.
- [ ] `prepare_inputs.py`로 3편의 완결된 기존 발화 순서를 만든다. 단어 재조합·새 유료 호출 없이 원본 PCM·예산 불변을 확인한다.
- [ ] 대표 도입/지역/가격/마무리 화면을 설계한다. 기존 영상과 위계·글자 크기·시선 초점·사진 역할을 비교한다.
- [ ] 전체 글리프 경계와 안전영역, 음성별 가격 최초 표시, 큐 비활성 구간을 검사한다.
- [ ] 세 편을 렌더하고 실제 MP4의 전환·숫자·긴 자막·마지막 발화·오디오 마스터 대조·전체 디코드를 검사한다.
- [ ] 새 완료 결정과 납품 기록을 정확한 파일 해시에 연결하고 짧은 경로를 갱신한다. 본편·기존 예산·2편·게시 상태는 보존한다.

## 집중 검수

첫 프레임에 순위 기준과 범위가 읽히는가. 15위 같은 숫자가 맥락보다 먼저 말해지지 않는가. 사진과 가격의 초점이 분리되는가. 13억2,000만원 및 3억3,150만원이 잘리지 않는가. 마지막 CTA와 꼬리 발화가 완결되는가.
