도입 문구:

> ‘데이터로보는부동산’에서는 신혼부부가 매매를 검토할 만한 지역과 아파트를 데이터로 살펴봅니다. 먼저 신혼부부가 실제로 많이 사는 곳을 찾아, 앞으로 소개할 지역을 골라봤습니다. 2024년 신혼부부 통계를 보고, 지역마다 신혼부부가 몇 쌍씩 살고 있는지 비교한 거죠.

거주 쌍 수를 소개 지역 선정에 활용하며, 기존 순위·가격·집계 조건은 유지했습니다. 대본 90문장 중 47문장이 바뀌고 43문장은 그대로입니다. 원본 자료와 대조한 독립 문구 QA의 미해결 critical·required는 각각 0건입니다.

## 현재 쇼츠에 미치는 영향

현재 UI v2의 실제 locked_timing을 기준으로 대조했습니다.

- 홍보용: 바뀌는 발화 없음. 현재 영상을 유지합니다.
- 20~16위: 원미구 준공 시기 가격, 중랑구 가격·지하철 노선, 기흥구 가격 설명의 3문장.
- 15~11위: 구로구 가격·직장까지 가는 길 설명 1문장.

새 Jun 발화를 얻으면 기존 43문장과 공용 CTA 2문장은 재사용하고, 새 발화의 실제 길이로 본편·영향받는 쇼츠의 자막·전환·가격 강조 시점을 다시 맞춥니다. 단지명과 브랜드 발음, 교체 문장 앞뒤 호흡, 마지막 음절의 잘림을 실제 청취와 경계 검사로 확인합니다. 이 문서의 문구 QA는 실제 음성·최종 MP4 검수와 구분합니다. 2편·외부 Claude 전송·업로드는 이번 생성 범위에 포함하지 않습니다.
