## 바로 적용할 후보 — 모두 우리 추론

- **홍보편:** “신혼부부가 많이 사는 동네, 어디일까요?” 첫 프레임에 거주 수 TOP20·2024 기준과 검증된 대표 데이터. 영상 안에서 순위 한 가지의 답을 준 뒤 연결된 전체 영상 안내.
- **20–16위:** “신혼부부가 많이 사는 동네, 20위부터 16위입니다.” 첫 프레임에 `신혼부부 거주 수｜20→16위｜2024 기준`과 20위 지역. 5곳을 모두 공개한 다음 “여기까지 16위였습니다. 15위부터는 관련 영상에서 이어집니다.” 실제 다음 편 연결이 있을 때만 적용.
- **15–11위:** “신혼부부가 많이 사는 동네, 이번엔 15위부터 11위입니다.” 전편 설명 없이 시작하고 11위까지 마친다. 연결된 전체 영상이 있으면 “11위까지 살펴봤습니다. 전체 순위는 관련 영상에서 확인해 보세요.” 없으면 이번 범위 요약으로 끝낸다. 준비가 확인되지 않은 10–1위 편은 예고하지 않는다.
- **화면 위계:** 순위·지역명 → 핵심 수·단위 → 해석 한 줄·기준·출처. 한 번에 한 덩어리 강조. 거주 수를 추천·인기·가격 순위로 바꾸지 않는다. 기초정보도 실제 모바일에서 읽힐 크기를 유지한다.
- **공개·전환:** 기존 Jun의 의미 경계에 지역명·수치·해석을 맞춘다. 지역 교체는 같은 앵커의 컷/짧은 이동을 후보로 사용한다. 0.15–0.25초는 초기 편집 후보이며 공식 권장값이 아니다. 숫자를 읽는 동안은 화면을 안정시킨다.
- **도입·끝맺음:** 별도 로고 화면을 늘리지 않고 첫 데이터·마지막 답 위에 문구를 통합한다. CTA는 하나를 우선 후보로 삼되 실제 발화·가독성에 맞춰 총괄이 조정한다. 문구는 새 TTS 생성 요청이 아니다.

기존 영상·음성·가격 데이터는 확인하지 않았다. 수치·지역명·정확한 지표 문구와 장면ID는 총괄의 원자료/영상 검수 결과를 사용한다. 연결 CTA 조건은 [issue_SHORTS-CTA-01.json](C:/projects/realestate_reco/video-agent-studio/episodes/newlywed-apartment-picks-20261101/research/shorts-ui-v2-20261104/issue_SHORTS-CTA-01.json)에 남겼다.
