# 지도 자료 출처와 이용조건

본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다. 이번 영상용으로 지역별 그룹화·투영·색상·라벨을 가공했습니다.

- 기준 경계: ver20241001. 통계 기준일2024-11-01과 시점을 맞췄습니다.
- 원미구는2024년 복원된 구역의 실제 행정동을 사용했습니다. 기존 웹 지도에 남은 부천시 전체 경계를 원미구로 사용하지 않았습니다.
- 인천 서구는2024년 당시 범위를 유지하며 현재 서해구·검단구 이름은 별도 주석으로 연결합니다.
- 원도 GeoJSON과 라이선스 스냅샷은 research/top20-8min-v2/source에 보존했습니다.
- 지도는 위치 설명용이며 부동산 필지·측량 자료의 용도로 제작하지 않았습니다.
