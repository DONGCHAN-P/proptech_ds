# 수도권 10억 지도 · 독립 사전검토

현재 판정은 **파일럿 수집과 레이아웃 사전검토 완료, 본편 데이터·지도 통과 보류**다. 기존 annual-map-v1의 숫자가 내부적으로 맞더라도 가격 원천의 잘림·거래 중복처리와 좌표 문제 때문에 전체 가격 결론이나 전체 단지 완전성의 근거가 되지 않는다.

## 실제 확인한 증거

파일럿 원문 XML을 receipt와 독립 대조했다.

| 지역·월 | 원문 페이지별 행 | 합계 | 고유 전체 payload | 동일 payload 추가 출현 |
|---|---|---:|---:|---:|
| 11350 / 2006.03 | 1,000 + 123 | 1,123 | 1,115 | 8 |
| 11350 / 2006.09 | 1,000 + 1,000 + 49 | 2,049 | 2,028 | 21 |

페이지별 totalCount·실제 행수·receipt와 일치했다. 반복 payload는 서로 다른 거래일 수 있으므로 공식 거래 고유키 없이 삭제하지 않는 것이 적합하다. 이 두 건의 확인은 266개 월 원천 보완 전체 완료나 과거 원천의 최신 정정 내역 전수 반영을 뜻하지 않는다. 호출 실패와 재시도도 journal에 남아 있다. complete=true는 해당 파일럿 2건 범위로만 읽는다.

`analysis/billion_map_data_audit/rebuild_episode.py`를 읽었다. 교체 대상 지역·월의 기존 staged 행을 제거한 뒤 새 페이지 원문을 붙이며, 본문 행의 출현 횟수를 유지하고 단지·연도 중위값과 건수를 집계하는 구조다. 건축연도 필터·이동평균·가격 carry는 이 집계 코드에 없다. 다만 아직 실행 중인 파이프라인의 최종 산출물은 검증하지 않았다. first_valid_year 이후 미거래 표와 새 지도 packet은 후속 검수 대상이다.

6초 MP4 `outputs/map-preview-v1/style_preview_6s.mp4`를 전체 디코드했고 0·2·4·5.9초 프레임을 추출해 직접 보았다. 2006/2025/2026 부분연도 전환과 시안 표기를 확인했다. 음성이 없고 실제 앱 재생·전체 연속 시청은 하지 않았다. 프레임 표본과 기술 검사는 구분한다.

## 현재 시안에서 확인한 해석 문제

2026 실제 화면의 지도 위에는 ‘관측 6,311 / 이하 4,800’, 아래 큰 숫자는 ‘보유자료 관측 6,834 / 10억 이하 5,230’이다. 코드상 앞은 좌표 사용 가능 단지, 뒤는 좌표 제외까지 포함한 보유자료 모집단이다. 따라서 수치 계산 오류로 단정하지 않지만, 큰 숫자 5,230을 지도에서 보이는 점 수로 읽으면 맞지 않는다. ‘좌표제외 523’만으로는 이하 단지 차이 430까지 설명되지 않는다.

최종판의 큰 숫자는 지도 eligible 집합을 기준으로 하거나, ‘전체 집계(지도 제외 포함)’와 ‘지도 관측’을 명확히 구별해야 한다. 회색 미거래 점은 관측 분모에 들어가지 않으므로 ‘지도 표시 전체 점 수’라는 라벨에 관측만 쓰면 안 된다. 실제 색점 draw 호출 건수와 서로 겹친 픽셀 덩어리 개수도 같은 개념이 아니다.

시안의 안전영역은 실제 `config/vertical_video_safe_area.json`의 x156~816/y448~1160을 읽고, source bbox validation 36개 항목이 통과한 기록과 실제 추출 화면을 확인했다. 지도·연도·조건은 안전영역 안에 모여 있다. 본편 최대 숫자·최장 조건과 실제 UI 모사까지 통과했다는 뜻은 아니다.

레이아웃 제안은 한 묶음만 한다. **주 숫자를 지도와 같은 분모로 통일하고 보조 분모를 줄인 뒤, 그 여백을 지도와 ‘초과 숨김/미거래 회색’ 범례의 가독성에 쓴다.** 현재 지도는 수도권 전체를 유지하기 위해 안전영역 안에서도 실제 지형이 작고 서울 중심 점이 파란 덩어리로 겹친다. 지도 전체를 화면 끝까지 늘리거나 임의 jitter로 단지를 흩뜨리지 않는다. 고정 구도·채널 색·시안 워터마크는 유지해도 된다. 배치 취향 수정을 연속해서 추가하지 않는다.

## v2 필수 수용 기준

### 1. 원천과 교체

- 대상은 서울·경기·인천 코드 11/41/28임을 실제 입력과 결과에서 확인한다. 전국 staged가 섞였다고 가정하지도 않고 수도권만이라고 추정하지도 않는다.
- 잘린 266개 지역·월마다 모든 페이지의 actual rows=totalCount, 마지막 페이지 수량, 페이지 번호, 저장 SHA, 최종 재확인·실패/재시도 journal을 검증한다. 850 무료 요청 상한은 데이터 완전성의 대체 근거가 아니다.
- fresh 보완 월은 해당 기존 월 전체를 교체한다. 옛 1,000행에 뒤 페이지만 붙이거나 재시도 응답을 이중 합산하지 않는다. 기존 제거량 + 새 포함량 = 최종 행수로 회계한다.
- 원문 page/item index와 출처를 보존한다. 공식 거래 ID 없는 동일 날짜·층·면적·금액을 임의 단일화하지 않는다. 최고가 keep 방식이 다시 들어가지 않았는지 확인한다.
- 면적 83 포함·85 제외, 취소 표시와 취소일, 유효 계약일·양의 가격 필터의 제외 건수를 각각 남긴다. 기존 master·원본 raw는 보존한다.

### 2. 연간 가격과 상태

- 단지별 **계약연도**의 유효 실거래 중위값이다. 이동평균, 전년도 값 유지, 미래 값 역채움이 없다. 홀수·짝수 n에서 중위값을 직접 재산출한다.
- 단위는 원/만원을 명시한다. 100,000만원(정확 10억원)은 남고 그보다 큰 중위값만 숨긴다. float 반올림 후 임계값을 비교하지 않는다.
- 예시 상태열 9억→10억→10억 초과→9.9억은 표시→표시→숨김→재등장이어야 한다. 중간 무거래면 회색이고 가격하락 또는 초과로 분류하지 않는다.
- 첫 유효거래연도 전에는 점을 그리지 않는다. 건축연도와 거래연도가 다르다는 이유만으로 원문 거래를 삭제하지 않는다. 준공·분양권을 임의로 재해석하지 않는다.
- 연별 under+over=관측 단지, 관측+n0 미거래+첫관측전=분석 catalog 전체를 검산한다. annual n 합계=유효 원문행 합계도 일치해야 한다.
- 2026은 부분연도·실제 수집일·계약기간을 표시한다. 최신 계약일을 전체 수집의 빠짐없는 종료일이라고 부르지 않는다.

### 3. 단지와 좌표

- 공식 aptSeq canonical에 따라 한 단지 한 점을 유지한다. 이름·도로명 분절로 같은 단지가 여러 점이 되거나, 다른 단지가 동일 주소 proxy 한 점으로 합쳐지지 않도록 교차표를 검토한다. 공백·누락·충돌 aptSeq는 별도 기록한다.
- 기존 8,369 candidate 좌표는 unverified이며 745 제외와 함께 전수 정밀 검증된 좌표처럼 쓰지 않는다. 공식 SHP 도착 시 원본 URL·권리·CRS·식별자 매칭 근거를 먼저 확인한다.
- CRS는 실제 파일 메타데이터와 독립 lon/lat 기준점 여러 곳으로 변환 수치·위치를 대조한다. 현재 ‘강남역이 서울면 안’ 1개 확인은 로컬 파일 CRS 인증이나 단지 정밀도 검증이 아니다.
- 좌표 불가/공유/불명확은 제외 사유와 수량을 보존한다. 지도상 빈 곳을 고가 지역으로 해석하지 않는다. 지터·임의핀이 정밀도 보완이 될 수 없다.

### 4. 실제 지도와 영상

- 각 연도 packet으로 지도 대상 집합과 draw 대상을 독립 재계수한다. 파란 점/회색 점/초과 숨김/첫관측전 미표시를 구분한다. `drawn.over`처럼 실제 그리지 않은 상태를 그린 점 건수로 기록하는 필드명은 정리한다.
- 연도 라벨·분자·분모는 같은 필터/좌표 eligible 집합과 연결한다. 구 packet 숫자를 새 packet 화면에 남기지 않는다.
- 첫해·완결연도·부분연도·재등장·정확10억·처음관측·미거래의 대표 실제 인코딩 프레임을 검토한다. 각 전환 직전/직후에 해당 연도와 숫자가 동시에 바뀌는지 본다.
- 최신 세로 safe config·실제 폰트 bbox·UI 모사를 확인한다. source bbox, 기술 decode, 실제 표본 열람, 실제 앱/연속 재생은 각각 기록한다.
