# 새 원천·연간 집계 독립 검증 결과

**현재 보유 원문에 대한 가격 집계는 검토 통과, 지도·좌표는 계속 보류**다. 승인·대본·영상·공개 상태는 변경하지 않았다. API 호출·유료 실행·외부 전송도 하지 않았다.

## 독립 재계산 범위

- handoff의 11개 산출물 SHA를 실제 파일과 대조해 모두 일치했다.
- 보완 완료 266개 지역·월의 **544개 본 페이지** XML을 직접 파싱했다. totalCount, 페이지 합계, receipt, 저장 SHA, 최종 첫 페이지 재확인본을 대조했다. 원문 합계 **346,838행**과 일치했다.
- 전체 payload가 동일한 추가 출현 **8,041회**가 원문에 있다. 이를 거래 고유 ID 없이 임의 삭제하지 않았다. 84㎡ 구간 원문 **111,989행**은 source_file/item_index 기준으로 산출물과 일대일 연결하며 가격·면적·aptSeq·계약일·취소 상태까지 대조했다.
- 교체 월의 기존 staged **86,556행**이 빠지고 fresh 111,989행으로 교체됐다. 남은 staged **1,541,389행**은 원 staged의 식별자·날짜·가격·면적·층·취소·출처 위치와 정확히 일치했다. 교체 대상 월의 옛 staged 잔존은 0건이다.
- 총 **1,653,378행** 중 취소 27,086행을 제외한 **1,626,292행**이 유효 집계 대상이다. 실제 필터를 별도로 적용해 included_price_analysis와 대조했다. 수도권 11/28/41, 83≤전용<85, 계약연도 2006~2026, 유효 ID·양수 가격 범위를 확인했다.
- 유효행 전체에서 aptSeq×계약연도 중위값과 n을 다시 계산했다. **126,221개 관측 단지·연도 그룹**의 저장값과 전량 일치했다. 단지 catalog 9,172개와 21개 연도의 **192,612개 상태**를 검산했다.

## 요청 규칙 확인

| 항목 | 실제 결과 |
|---|---|
| 정확히 10억원 | 연중위값 100,000만원인 **180개 그룹 모두 under** |
| 10억원 초과 | 원값으로 엄격히 over. 가장 가까운 실제 초과 표본 100,050만원도 over |
| 짝수/홀수 중위값 | 전체 재산출 일치. n=2 표본의 두 행도 보존 |
| 재등장 | 이전 초과 뒤 이후 ≤10억으로 바뀌는 **552개 전환 사례** 확인. 무거래를 거쳐 다시 등장하는 경우도 가격을 carry하지 않음 |
| 무거래 | n=0이고 첫 유효관측 이후면 no_trade. 가격·원환산값은 결측이며 전년도 가격을 채우지 않음 |
| 첫 유효관측 전 | not_yet_observed. catalog의 첫해와 실제 유효거래 최소연도 전량 일치 |
| 건축연도 임의 필터 | 원문 계약연도가 건축연도보다 이른 **185개 유효행도 남아 있음**. 별도 원자료 오류 여부를 이번에 확정한 것은 아니며 임의 삭제하지 않은 점을 확인 |
| 분모 회계 | 매년 관측+무거래+첫관측전=9,172. 연도별 n 합계=1,626,292 |

실제 재등장 사례 `rtms:11110-2234`는 2021년 106,250만원(n2), 2022년 117,000만원(n1)으로 숨김 대상이었다가, 2023년 정확히 100,000만원(n3)으로 표시 대상이 된다. 이후 2024년 100,600만원으로 다시 숨김이다. 단지명을 임의 지리와 연결하지 않고 공식 식별자 기준 상태 검증으로만 사용했다.

## 새 수치와 구 시안의 구별

| 연도 | 새 전체 관측 | 새 10억 이하 | 새 초과 | 무거래 |
|---|---:|---:|---:|---:|
| 2025 완결연도 | 7,000 | 5,544 | 1,456 | 2,084 |
| 2026 부분연도 | 6,863 | 5,252 | 1,611 | 2,309 |

이는 **좌표 적용 전 전체 가격 catalog 기준**이다. 구 6초 시안의 2026 전체 이하 5,230·지도 이하 4,800과 바꿔 사용할 수 없다. 새 좌표 eligible 집합이 정해진 뒤 지도 분자·분모·실제 draw 대상을 다시 계산해야 한다. 회색 점은 무거래이며 가격 초과와 구별한다.

## 남는 한계와 다음 단계

1. 원천 266개 잘린 월 보완과 현재 보유 staged의 계산 일관성을 확인한 것이다. 모든 과거 신고·취소 정정을 오늘 시점으로 전수 재조회했다는 뜻은 아니다. 2026년은 부분연도이고 최대 계약일 2026-10-10은 수집 완전성 보장일이 아니다.
2. 공식 aptSeq 한 개로 묶인 catalog는 좌표·실제 단지 경계를 검증한 결과가 아니다. 다중 지역코드 사례의 부동산 경계 해석, 공식 SHP 매칭·권리·CRS와 정밀 좌표는 별도 검수다.
3. 기존 후보 좌표 8,369개와 제외 745개의 정밀도가 해결됐다고 보지 않는다. **지도 최종 통과는 false**다.
4. 이번에 새 지도나 MP4를 생성·검수하지 않았다. 새 packet으로 바뀐 지도 수와 라벨, 정확10억·재등장·미거래·첫관측전의 실제 프레임, 세로 안전영역을 다음에 확인한다.

재현 코드와 상세 SHA·전량 비교 결과: `verify_completed_source.py`, `completed_source_independent_review.json`. 검토 소유 폴더 외의 원본·집계·상태 파일은 수정하지 않았다.
