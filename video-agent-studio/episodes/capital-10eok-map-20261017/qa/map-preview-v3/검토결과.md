# v3 큰 지도 로컬 시안 독립 검토

**사용자가 요청한 큰 지도 구도를 기준으로 시안 검토를 통과했다. 새 필수·치명 오류는 발견하지 않았다.** 보수적 세로 안전영역을 전부 통과한 판이 아니며, 전체 숏폼·실기기·게시 검수 완료를 뜻하지 않는다.

## 실제 본 범위

최종 MP4에서 0·89·90·179·180·269프레임을 전역 출력 순번으로 추출하고 375px 크기와 접촉표를 직접 열람했다. 2026판은 375×667 단독 화면에서도 보았다. 270프레임 전체 디코드가 오류 없이 끝났고 1080×1920/30fps/9초/오디오 스트림 0개다. 실제 연속 시청·실기기 재생·청취는 미실시다.

MP4 SHA256: `ce1ce94cd0006ab7cddc1a206c0e608816be2cedecff4c6889237ecf0d1fe295`.

## 지도와 숫자

- 실제 본토 경계 폭은 약 904.5px, 점 분포 폭은 약 713.9px다. v2 대비 지도 선형 배율은 3.323배이며 375px에서도 도시명·중앙 점 분포가 훨씬 잘 구분된다. 전체 conservative 영역에 다시 축소하는 개선은 요구하지 않는다.
- packet SHA `6fc010df600e45b5bbebd03101fc34dc258c69d4950a9bd5ae6bf5e48a53358b`가 v2와 같다. 이미 검증한 21년 가격상태·정확10억·재등장·미거래와 8,288개 native 좌표 근거를 승계한다. 이번에 바뀌지 않은 원천을 새로 전수조사했다고 하지 않는다.
- 대표 3판의 실제 draw 건수·분모·숨김·비율을 packet과 재대조했다. 2006 4,754/4,781=99.4%, 2025 4,950/6,339=78.1%, 2026 4,649/6,180=75.2%가 맞다.
- 연도 경계 89→90 및 179→180에서 지도와 연도·숫자·비율이 함께 바뀐다. 전후 표본에서 1프레임 구판 회귀를 보지 않았다. 모든 프레임의 육안 확인을 뜻하지 않는다.
- 지도 이하 점과 범례 이하 점은 주황, 미거래는 dim 색으로 분리됐다. 수정된 범례를 실제 인코딩·375px에서 확인했다. 초과 점은 숨기며 미거래를 가격 초과와 같은 상태로 만들지 않는다.
- 지명 인출선과 큰 숫자·연도 사이에 새 겹침이나 캔버스 잘림을 관찰하지 않았다. bbox도 1080×1920 캔버스 안에 있다. 가운데 밀집점은 겹치지만 임의 지터·열지도·glow로 바꾸지 않았다.
- 비율 그래프는 당해 연중위값 이하/당해 거래관측 비율이며 70~100% 축을 표시한다. 전체 단지 수 감소나 현재 매물 비율로 해석하면 안 된다.

## 레퍼런스 확인 범위

로컬에 확보된 `reference_frame_15s.png` 1장을 직접 열람했다. 어두운 배경·밝은 주황·큰 지도·연도·추이의 계층은 새 시안에서 확인된다. 레퍼런스 프레임에는 ‘시연용 합성 데이터·실제 통계 아님’ 표시가 있어 그 수치·신고가 주장을 새 영상 근거로 승계하지 않는다. 레퍼런스 전체 재생·음악 확인은 하지 않았다.

## UI 노출 위험과 권고 1건

episode override는 지도 bleed와 큰 구도를 허용한다. 이 예외를 적용해 보수적 safe bbox 밖이라는 이유만으로 시안을 반려하지 않는다. **다만 모든 앱·기기 안전성을 통과했다고 표시할 수는 없다.**

기존 내부 모형인 상단14%·하단35%·우측64px UI 마스크를 375px 보기 위에 표시해 보았다. 이 모형에서는 제목이 상단 마스크 바로 아래에 있고, 하단 마스크가 인천·수원·지도 남부와 아래 범례·제외884·최대계약일을 가린다. 우측 지도 일부도 버튼 영역에 겹친다. 이는 실제 앱에서 반드시 그만큼 가린다는 측정값이 아니라 알려진 위험을 보수적으로 시각화한 것이다.

권고는 **큰 지도·배율은 유지하고, 최종 사용 때 필요한 주황/미거래/초과 숨김 범례 핵심만 상단 조건행 가까운 곳에 짧게 두는 방안을 고려**하는 것이다. 지금 새 디자인 수정이나 전체 축소를 요청하지 않는다. 상단에 연결8,288/제외884와 연중위 조건, 2026 부분연도는 있어 일부 조건이 아래에만 의존하지 않도록 보강됐다. 최대 계약일과 상세 범례는 여전히 하단 UI 위험이 남는다.

## 인계

`final_review.json`의 preview_review_ready=true는 이 9초 로컬 시안 범위다. conservative_safe_pass=false, actual_device_playback=false, full_video_review_ready=false를 함께 기록했다. 사용자 승인·대본·제작·전체 영상·업로드 상태는 수정하지 않았다. 새 API·유료·외부 전송·원본 미디어 변경도 없다.
