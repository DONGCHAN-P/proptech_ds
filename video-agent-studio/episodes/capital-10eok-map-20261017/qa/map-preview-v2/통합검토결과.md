# v2 지도·데이터·레이아웃 통합 시안 검토

**6초 로컬 시안 범위는 통과했다. 필수·치명 미해결 0건이다.** 전체 숏폼 제작·대본·게시 승인 또는 전 기간 실제 영상 검수를 뜻하지 않는다.

## 확인 결과

- 새 가격 원천과 지도 packet의 21개 연도×8,288개 후보 상태·중위값·n·첫 유효연도를 전량 대조해 일치했다. 정확히 10억인 지도 범위 **174개 단지·연도 그룹**이 모두 표시 상태다. 전체 가격 catalog의 180개와 분모가 다르다.
- 초과 뒤 바로 다음 해 이하가 된 전환은 **374건**, 미거래 해를 거친 경우까지 포함한 관측 재등장은 **528건**이다. 초기 validation의 374건이 전체 재등장처럼 보이는 필드명을 수정 요청했고, 분리된 두 지표와 README·handoff 수정 반영을 다시 확인했다. 상태나 영상의 오류는 아니므로 재렌더하지 않았다.
- 후보 8,288개 공식ID·PNU·x_5179/y_5179는 검증한 공식 원투영값과 정확히 같다. 공유 공식ID 없이 한 단지 한 점이다. 원도형 내부점 전량 검증은 입력 SHA가 변하지 않았음을 확인하고 앞선 좌표 검수에서 승계했다.
- renderer는 native EPSG:5179 좌표를 같은 단위의 배경에 선형 viewport로 직접 사용한다. lon/lat 역변환·정방향 재변환을 거치지 않는다. 독립 PROJ 검증을 했다고 기록하지 않는다.
- 서울(종로)·인천(부평)·수원(팔달)·고양(덕양)·성남(중원)의 라벨 앵커가 해당 실제 경계면 내부인지 독립 PIP로 확인했다. 글자 위치는 인출선으로 연결되며 해당 도시 전체의 기하학적 중심이라는 뜻이 아니다.
- 큰 숫자는 전체 가격 catalog가 아닌 지도 연결 단지의 당해 거래관측 분모다. 이전 시안의 전체·지도 분모 혼용이 해소됐다.

## 실제 인코딩·안전영역

MP4 SHA `7a0a0d7d309b10abae1031d5189e148eefbc8a8858a132b207f0e8a71f3496cc`, 1080×1920, 30fps, **180프레임/6초**, 오디오 스트림 0개다. 전체 디코드를 통해 출력 프레임 180개를 순번으로 세었고 0·59·60·119·120·179프레임을 직접 열람했다. 두 경계에서 연도와 큰 숫자가 함께 바뀌며 끝에도 다른 연도판이 끼어들지 않는다.

3개 대표판의 **48개 실제 글자 bbox**는 최신 safe config x156~816/y448~1160 내부이며 글꼴 최소 24px를 확인했다. 도시 라벨과 핵심 숫자의 잘림은 관찰되지 않았다. 18개 기하 모형 결과도 전달받았으며, 그중 393×852 cover·768×1024 cover·375×812 contain UI 모사를 직접 보아 핵심 영역이 마스크를 피하는 것을 확인했다. 이는 보수적 모델과 표본 이미지이며 실제 기기·실제 앱 재생 증거가 아니다.

추가 디자인 수정을 요구하지 않는다. 작은 모바일 표시에서 조건·출처는 본문보다 읽기 어렵고 서울 중심 점이 겹치는 특성은 남지만, 이를 임의 지터·위치 변형·안전영역 밖 확대를 추가할 근거로 보지 않는다. 최종 편집은 현재 분모·좌표 계약을 유지해야 한다.

## 남은 범위

공식 2025 공간자료의 시차와 미연결 884개, 소스 수집일 차이는 그대로다. 2026은 부분연도이며 최대 계약일 10.10이 신고 완전성 보장일은 아니다. 그 조건에서의 검증이지 수도권 모든 단지 좌표·거래의 최신 전수 완결을 뜻하지 않는다.

21개 연도 데이터는 검증했지만 실제 시안에는 2006/2025/2026 세 판만 있다. 모든 연도의 인코딩 전환·재등장·미거래 장면을 직접 봤다는 뜻은 아니다. 실제 연속 시청·실기기 재생·청취는 미실시이며 무음 파일임은 스트림으로 확인했다. 본편이 만들어지면 새 입력 SHA와 전체 연도·대표 상태·모든 경계·최장 숫자/조건을 다시 검수해야 한다.
