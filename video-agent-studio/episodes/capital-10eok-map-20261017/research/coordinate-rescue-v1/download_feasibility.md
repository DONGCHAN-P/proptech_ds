# 다운로드 실무 확인 · 2026-10-17

## VWorld GIS 건물 SHP

공식 다운로드 페이지 HTML을 `gis_download_page.html`에 보존했다. 페이지의 `listFnc.download`와 `multiDownload` 모두 로그인 여부 검사에서 비로그인이면 안내 후 종료한다. 따라서 공개파일처럼 직접 다운로드 URL을 조립해 호출하지 않았다.

단일 파일은 500MB 이하일 때 페이지가 다운로드 iframe을 만들며, 500MB 이상은 선택다운로드를 안내한다. 공식 함수상 서울129MB는 로그인 후 단일 다운로드 경로를 쓰므로 별도 솔루션 없이 받을 가능성이 있으나, 실제 수신은 확인하지 않았다. 현재 허용 범위에 신규 로그인/설치가 없으므로 해당 지점에서 멈췄다.

SHP 다운로드0, 총다운로드용량0, ZIP무결성/prj/PNU 실제파일검증 미실시. 공식 정의서와 전국/3지역 SHP 수집을 완료한 것으로 기록하지 않는다.

## 더 작은 전국 단지 SHP: 한국부동산원 (우선 취득 권고)

[공식 상품 원문](https://www.bigdata-realestate.kr/rebpp/usr/prd/prdInfoDetail.do?req_productId=1)

- 공동주택 단지 연계정보, 제공자 한국부동산원, 전국 아파트 단지 기본·이력정보 기반.
- 최신 상세상품은 **2025판 15.58MB, 2026-01-05 등록**, 무료 SHP. 2024/2023/2022판도 목록에 있다.
- 공개 컬럼: `HSMP_INNB`(단지고유번호14자), `PNU`(필지고유번호19자), `RN_MNNMB`(도로명관리번호), `SIGNGU_CD`, `LNNO_ADRES`, `RN`, 도로건물본번/부번.
- 페이지 접근권한 PUBLIC, 한국부동산원이 저작재산권 전부를 보유하는 공공저작물의 자유이용 안내. 상세상품 이용조건 무료. 실제 패키지 내 추가 안내를 확인해야 한다.
- 공개 웹 읽기 도구는 상품 설명·컬럼·버전 목록을 반환했다. 직접 requests는 HTTP404와 ‘비정상 접근’ 차단 안내를 반환했다. 요청 변조/다른 다운로드 엔드포인트 추측/브라우저 로그인은 하지 않았다.
- **정상 브라우저로 전국 파일 1개 취득** 후 geometry·prj·PNU·단지명·시기·수도권 커버리지 확인하면 건물3지역 대용량 수집보다 적합할 수 있다. 아직 좌표가 든 실제 SHP를 취득하지 않았으므로 이것만으로 복구 가능한 단지 수를 산정하지 않는다.
- 법정동+정확지번 PNU를 먼저 맞추고, 복수단지 필지는 단지명/건축연도 및 원단지 식별정보로 구분한다. RTMS aptSeq를 HSMP_INNB로 바로 간주하지 않는다.

## 범위가 부족한 보조자료

[서울시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do)는 K-apt코드·단지명·법정동주소·도로명주소·XCRD·YCRD를 공개한다. 서울에 한정되고 수도권 전체를 대체하지 못하므로 이번엔 일부만 다운로드해 전체 완료처럼 만들지 않았다.

공공데이터포털 전국 좌표파일 검색에서는 지역별 시공현황(김포11행 등), 대구 긴급자동차 출입로 좌표 같은 자료가 검색되지만 기존 수도권 전단지 좌표 대체재가 아니다. 영업·API 지오코딩 캐시를 원자료로 포장해서 사용하지 않는다.
