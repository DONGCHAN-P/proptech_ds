## 대표점과 검증 범위

폴리곤의 여러 수평 절단선 중 가장 긴 내부 구간의 중점을 선택해 point-in-polygon을 확인했다. 따라서 건물 입구·역 출입구·해당 세대 위치가 아니라 **단지 도형 내부 대표점**이다. 건물/단지 도형을 단순 bbox 중심으로 치환하지 않았다.

추가 설치 없이 표준 타원체 Transverse Mercator 역변환식을 사용했다. 별도 정방향 식으로 수도권20,058도형의 왕복변환을 검사했고 최대오차0.000019m 미만, 투영 원점도 일치했다. 이는 수학적 내부 일관성 검사다. 독립 PROJ 구현과 비교는 아직 남아 있으므로 packet의 `prototype_until_transform_review=true`를 유지했다.
