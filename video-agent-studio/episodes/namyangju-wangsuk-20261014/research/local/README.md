# 남양주 실거래 탐색 v1

원자료: 프로젝트 `master/trade_events.parquet`. 원자료 SHA-256과 파일 크기는 `local_transactions_v1.json`에 기록했다. 이번 작업은 기존 수집 자료를 읽은 분석이며 외부 API 추가 수집은 하지 않았다.

남양주시 코드 41360의 아파트 매매 자료 중 해제 표시 거래, 0 이하 가격을 제외하고 프로젝트 공통 기준인 ㎡당 50~20,000만원 범위 밖 가격을 제외했다. 가격이 없는 ㎡당 단가 필드는 공통 필터와 동일하게 제외하지 않았다.

동별·단지별 가격은 2026년 1월 1일~10월 8일 계약, 전용 83㎡ 이상 85㎡ 미만의 거래금액 중위값이다. 단위는 만원이다. 단지 후보는 기간 내 10건 이상 거래가 있는 단지다. 날짜는 계약일이며 최신 수집일이나 모든 신고가 반영됐다는 뜻이 아니다.

| 범위 | 거래 수 | 중위값 |
|---|---:|---:|
| 다산동 | 1,030 | 9.20억원 |
| 별내동 | 393 | 6.95억원 |
| 진접읍 금곡리 | 268 | 4.585억원 |

이 표는 생활권 내부 구성 차이를 포함한 탐색 집계다. 연식·역 거리·층·단지 구성·옵션을 통제하지 않았다. 왕숙 59㎡ 분양가와 비교하거나 분양가의 안전마진·수익률로 바꾸지 않는다. 원시 자료 수집 범위와 중복 여부는 이번 분석에서 별도 감사하지 않았다. 늦은 신고와 해제 갱신도 미반영될 수 있다.

대본에 쓰려면 해당 거래 수·기간·면적·중위값 및 위 제한을 함께 표시한다. 동일 면적이라는 이유만으로 기존 주택과 신축 분양을 동등한 상품으로 취급하지 않는다.
