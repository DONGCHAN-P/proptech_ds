# 남양주 Remotion 본편 v2 편집 인계

원본 v1과 승인 음성 8개는 보존했다. v2는 8장의 정지 장면을 이어 붙이는 방식 대신 승인 대본의 의미를 62개 샷으로 나눈 Remotion 프로젝트다. 실제 전편 v14의 지도·실사·개념 이미지·그래픽 구성을 참고하고 해당 영상을 198초에서 실제 프레임으로 확인했다.

소스: 저장소 `video/src/NamyangjuV2.tsx`, `video/src/namyangju-v2/project.json`, `video/public/namyangju-v2/`이다. 기존 전편 컴포넌트와 인덱스는 수정하지 않았다. 실제 샷 소재는 `visual/shot_asset_binding_v2.json`을 정확한 shot ID로 연결한다. 지리·사진·AI를 임의 순번으로 골라 사용하지 않는다.

영상 전개: 전편 발췌 3개, 자체 OSM 지역지도 6개, 원본 전체 공식 계획도 6개, 자체 의미 도식·차트 34개, AI 개념 컷 8개, 실제 사진 컷 5개다. 자체 도식 34개에는 가격·계획 규모 막대 그리기와 달력·단계·역 관계 도식이 포함된다. 획득한 실사 6종 중 문맥에 맞는 3종(PHOTO001·PHOTO002·PHOTO009)을 5개 샷에 썼다. 학교·행사 사진을 수량 채우기로 끼워 넣지 않았다.

모션: 실제 OSM 도로·하천·철도 지형 벡터에 명시된 지역명 좌표로 카메라를 이동한 뒤 라벨을 읽는 동안 유지한다. 역 출입구·산업단지 정확 좌표는 검증되지 않아 정밀 핀을 만들지 않는다. 지도는 북쪽이 위이고 경도는 cos(37.7°)로 보정한다. 그래픽 선은 약 2초에 그린 뒤 대상 단계·타입을 강조한다. 사진과 AI 배경은 자막·출처와 분리해 소폭 이동한다. 공식 계획도 2종은 공공누리 제3유형에 맞게 전체 원본 정지 fit, 무크롭·무덧그림이다.

전편의 cream #F6F4EF, ink #111111, blue #2F6FED, amber #FFE45C, Pretendard, 채널 표식, 흰 자막 띠를 유지한다. AI 컷은 화면 위에 항상 `AI 개념 이미지 · 실제 왕숙 모습 아님`을 표시한다. 실제 사진은 장소·촬영 날짜·저작자·라이선스를 별도 고정 각주로 표시한다.

음성은 audio-v1의 8개 MP3를 순차 연결한다. 복사본의 SHA256과 원본이 8개 모두 동일함을 `render_v2/input_integrity_v2.json`에 기록했다. 27,389 프레임, 30fps, 실제 영상 기준 912.9667초이며, 샷 누락·중복 프레임은 각각 0개다. 기존 소유 `Data City Ambient v1`을 내레이션 아래 낮은 고정 음량(0.035)으로 깔았다. 최종 믹스의 청취 검수는 별도로 필요하다.

자막은 기존 장면별 실제 음성 길이에 글자 비중으로 분배한 추정 시간이다. 단어별 강제 정렬이나 실제 청취 확인을 완료했다고 주장하지 않는다. 장면 경계는 `render_v1/timing_actual.json`에서 고정하고, 각 샷은 대본 cue와 해당 장면의 비율을 사용해 연결했다.

90초 내부 검토용 실제 MP4는 `editor/render_v2/storyproof_v2b.mp4`다. 전체본은 `editor/render_v2/namyangju-wangsuk_v2.mp4`로 별도 제작한다. 전자는 전체 결과물로 취급하지 않는다. 전체본은 Remotion의 H.264 1080p 30fps CRF18/AAC 마스터이며, 텔레그램 파일 제한을 이유로 화질을 낮추지 않는다. 외부 파일 전송·업로드는 하지 않았다.

재현 순서: `node editor/prepare_v2.cjs`로 소재와 정확 바인딩을 준비하고, 저장소 루트에서 `node video-agent-studio/episodes/namyangju-wangsuk-20261014/editor/render_v2_final.cjs --full`을 실행한다. 이미 존재하는 v2를 다시 수정할 때는 새 버전 파일명·출력 폴더를 정한 뒤 실행해야 한다. 신규 유료 TTS·외부 생성 API·유료 스톡 설치를 호출하지 않는다.

검수 구분: v2b의 90초 실제 영상은 독립 QA가 의미별 이미지 영역 변화와 실사/지도/AI 표시를 확인했다. 전체 v2는 완성 후 실제 62샷 중간·경계·정보 노출 프레임을 독립 검수해야 한다. source PNG 확인과 encoded MP4 확인, 정지 표본과 연속 재생, 오디오 존재와 실제 청취는 각각 구분한다.
