# v7 전반부 배치 가이드

배포 파일은 `outputs/front-review-v7/namyangju-landuse_front_v7.mp4`, 13,087프레임/30fps이다. 전체 본편에 자동 병합하지 않는다.

실제 장면과 카메라 바인딩은 `scene_camera_manifest.json`을 따른다. 기존 6장 Jun 파일·137개 자막 원문과 타이밍을 그대로 사용했다. 음성은 0.9 gain, 기존 도입 음악만 유지하며 새 마무리를 만들지 않는다.

지도 카메라와 자막·제목·출처는 분리한다. 자막 흰 바는 화면 전역에 한 번만 마운트하고 cue 공백에는 글자만 비운다. 130px 높이와 동일 좌표를 유지한다.

거시 권역도는 공식 개략도의 내부 상대 좌표다. 개별 계획 보드는 각 LH 도면의 내부 좌표다. 운영 철도는 기존 WGS84 선형이다. 서로 다른 좌표판을 정합한 것처럼 겹치거나 경로선을 연결하지 않는다.

학교·상업·주거는 해당 도형이 보이는 판 안에서만 표시한다. 미니 판의 단지명은 제목의 지구명과 조합해 A24/B17·A1/A3로 짧게 표기하고, 필요하면 인출선을 사용한다. 산업 시설 1~13 같은 밀집 번호는 표시하지 않고 실제 산업 면들을 하나의 계획 구역으로 강조한다.

M005에서 A3 남부로 45프레임 팬하는 동작은 10772프레임에 한 번만 실행한다. 12296프레임 재방문은 같은 확대 구도를 유지한다. 구간마다 광역→근접을 다시 재생하지 않는다.

우리금융그룹 공식 CI PNG는 원본을 보존하고 화면에서 흰 여백만 잘라 보여준다. 색·로고 비율은 바꾸지 않는다. 카카오 CI 이미지는 사용하지 않는다. 기업은 계획 상태이며 정확 필지 핀을 만들지 않는다.
