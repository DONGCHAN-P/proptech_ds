v10 실제 재현과 v11 수정

실제 v10 MP4의 62.75~66.25초, 164~168초, 179~184초를 초당 4프레임으로 추출하고 세 컨택을 직접 확인했다. 63.25초에는 A1 구분 자막이 유지되는 동안 광역 지도로 떠났고, 164.75~165초에는 철도 안내판 두 종류가 연속 교대했다. 182.75초에 남부 토지판으로 바뀐 뒤 183.5초에 다시 광역 위치판이 나타나 설명 대상이 사라졌다.

원인은 FocusVisuals의 Rail/Native 시간별 교대와 NativeScene의 dt<12, 12..30, 30..54 프레임 분기였다. 첫 권역 변화에도 0.4초 축소→0.6초 locator→0.8초 확대가 들어갔다. 1:04 문제는 기존 GeographicNavigation이 A1 구분 설명 중 판을 떠나는 시간 연결이었다.

v11에서는 이 컴포넌트들을 사용하지 않는다. StaticPlates는 현재 프레임을 읽지 않으며 PNG 한 장을 구간 전체에 동일 합성한다. 지도 모션·순차 노선 그리기·펄스·배경 흐리기·임시 locator 컷이 없다. 원본 자막/흰바 영역 y922 이하와 AAC 음성은 별도로 보존한다.

기존 예정역 GIS 점은 공식 정밀 좌표가 아니라 도식에서 유도한 근사점이었다. 새 판은 이 점을 폐기하고 실제 경춘선 퇴계원~사릉, 중앙선 도농~양정 선형을 계획 구간으로 표현한다. 왕숙역의 작은 배치판은 B17 공식 팸플릿 p5 원도 내부 상대배치 사실을 자체 도해로 다시 그렸으며 GIS와 별도 축척이다.
