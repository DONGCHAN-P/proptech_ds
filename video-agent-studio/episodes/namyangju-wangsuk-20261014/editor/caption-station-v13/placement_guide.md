실제 검토 파일은 outputs/caption-station-v13의 front/full MP4다. front는 0~525초, full은 26,720프레임(30fps)이다. 본편을 새로 제작한 범위는 앞부분 수정이며, full의 15,758~26,420프레임은 기존 v8 후반 내용이다.

브랜드 자막 박스 예외는 0~45프레임 무음 도입, 917~1067프레임 브랜드 인트로, 26420~26720프레임 브랜드 아웃트로다. 원본 BrandReuse/IntroVisuals를 자막 레이어 없이 렌더했다. 말하는 도입과 본문 공백의 흰 바는 유지한다. 흰색 사각형을 덮어서 지우지 않았다.

철도 설명은 4942~8190프레임에 v12 큰 지도 한 판을 유지한다. 원도 일패역과 업무시설·회색 철도시설·보이는 철도 선형을 같은 좌표계의 작은 정적 인셋으로 표시한다. 원도에서 가려진 선형은 새로 연결하지 않는다. 8프레임 구버전 판과 짧은 전체 토지판 교대를 제거했다.

시각 cue는 자막 공백 때 직전 상태를 유지하되 자막 자체는 바꾸지 않는다. active ids·요약·요약 좌표와 펄스 시작이 공백에서 리셋되지 않는다. 전체본 15750~15758의 8프레임 연결부도 현재 왕숙2 판을 유지하여 원본 후반 공급판이 잠깐 나타나지 않는다.

재현은 render_brand.cjs → render.cjs → assemble_front.py → render_bridge.cjs → assemble_full.py 순서다. 기술 검사·전 프레임 flash 검사와 QA를 별도로 기록한다. 원본 AAC를 복사하고 기존 166/275개 자막을 그대로 사용한다. 새 유료 호출·TTS·이미지 생성·업로드는 없다. 실제 청취·연속 재생은 미확인이다.
