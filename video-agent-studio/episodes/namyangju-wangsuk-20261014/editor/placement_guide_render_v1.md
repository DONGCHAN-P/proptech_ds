본편 실제 경계는 `render_v1/timing_actual.json`이다. 총괄 승인 시간표 913.3초와 0.333초 차이가 있다. 설치된 FFprobe가 읽은 MP3 길이와 승인 측 container 길이 차이에서 비롯한다. 독립 검수는 실제 경계와 말끝 보존을 확인해야 한다.

정지 카드 컷이며 전체 줌·생성 영상 모션 없음. 본문·각주와 하단 ASS 자막은 분리돼 있다. 공식 계획도는 원본 전체 등비 fit이고 원본 안에 덧그리지 않는다. OSM 지형은 실제 운행·계획 노선 판정에 사용하지 않는다. S001·S008은 일자리·철도·분양가·생활시설·생활권 공급 순서를 유지한다.

자막은 음성 장면별 실제 길이 안에서 글자 비중으로 분배한 추정 시간이다. 발화 단어·문장 강제 정렬과 실제 청취 검수는 수행하지 않았다. `render_v1/caption_estimates.json`에 구간별 근거를 남겼다. 영상 존재나 전체 decode 통과를 청취·연속 재생 완료로 해석하지 않는다.

편집 프로젝트는 `build_video_v1.py`, 실제 장면별 FFmpeg 명령은 `render_v1/S001_command.json`부터 `S008_command.json`까지다. 재현 명령은 저장소 루트에서 `tools/python311/python.exe video-agent-studio/episodes/namyangju-wangsuk-20261014/editor/build_video_v1.py --render`이다. 기존 v1을 덮어쓰므로 신규 수정에는 새 출력 버전을 지정한 뒤 실행한다. 이번 확인에서는 다시 렌더하지 않았다.

기술 검수: 기존 설치 FFmpeg로 실제 MP4 전체 영상·음성 decode를 재확인했고 종료 코드 0, 오류 출력 없음. 대표 정지 프레임 가독성 확인 외 전체 화면 연속 재생·음성 청취·모바일 축소 검수는 독립 QA 대상으로 남는다. 완성본 외부 전송·플랫폼 업로드를 하지 않았다.

추가 기술 근거: 원본 MP3 8개를 PCM16 mono 48kHz로 디코드해 바이트 수를 실측했다. 실제 음성 길이는 렌더 기준과 모두 정확히 일치했고, 각 영상 구간은 음성보다 0~26.67ms 길다. 승인 시간표와의 차이는 MP3 container padding에서 비롯한다. `render_v1/decoded_audio_duration_check.json` 참조. 이 검증은 발음·청취 확인을 대체하지 않는다.
