# 남양주 편 편집 준비 v1

최종 MP4 없음. script-v2 / scenes-v2 / visual-v2 입력. 음성 및 실제 timing lock 미확보로 최종 편집은 대기한다.

`assembly_provisional_v1.json`의 시간은 대본 글자 수 추정이다. 배포 시간으로 사용할 수 없다. 1920×1080 / 30fps 계획. 기존 `video/src/PilotV11.tsx`와 v14 조립 방식, `config/video_style.json`을 기준으로 배경 #F6F4EF, 본문 #111111, 강조 #FFE45C, 중립 회색을 유지한다.

본문 SVG를 (100,30) 1720×820 영역에 등비 fit한다. 자막은 (100,910) 1720×125 흰 상자 별도 레이어로 둔다. 원본 각주를 자막 영역으로 보내지 않는다. 출처는 본문 하단 고정 유지. 도표는 전체 줌 없이 필요한 행을 1.6–2초 안에 강조 후 hold, 전환은 8프레임 이내 crossfade 후보다. 실제 음성 길이 확정 후 조정한다.

S001 다섯 질문 소개 → S002 실제 생활권/운영 철도 → S003 왕숙1·2 구분 → S004 입주/철도 달력 → S005 일자리 단계 → S006 학교 달력 → S007 59A와84A 분리 가격 → S008 확인 범위 회수. S001과S008의 질문 순서를 일자리·철도·분양가·생활시설·생활권 공급으로 맞춘다.

S003 공식 계획도 JPG는 원본 전체 정지 표시 후보다. 공공누리 제3유형 조건에 따라 crop, 원본 위 overlay, 재색칠을 하지 않는다. 출처와 최신고시 차수 미대조 표시는 이미지 밖에 배치한다. 실제 운영 철도/지리 지도와 사진은 추가 준비가 필요하다. 자체 정보 도표와 실제 공식 자료를 구분한다.

실제 생성 파일: S001_preview_v1.png, S007_preview_v1.png, S008_preview_v1.png 및 대응 HTML. 이는 음성이 없는 정지 기술 시안이다. 배포용 파일명과 추천 삽입 시점은 timing lock 후 새 버전으로 확정한다.

재현: 저장소 루트에서 `node video-agent-studio/episodes/namyangju-wangsuk-20261014/editor/prepare-preview.cjs`. 설치된 Remotion의 Chrome Headless Shell과 기존 Pretendard 글꼴만 사용하며 신규 설치/유료 API를 호출하지 않는다.

검수: S001·S007 실제 PNG를 열어 한글, 가격 및 하단 문구가 보이고 자막과 겹치지 않는 것을 확인했다. 모바일 축소 가독성, 전체 장면, 실제 음성 청취, 연속 영상 재생, MP4 기술 검사, 지도 위치 검수는 아직 수행하지 않았다.
