# 새 음성 확정 후 편집 입력 계약

현재 상태는 **템플릿 준비**입니다. `project.json`의 `timing_locked=false`, `duration_frames=null`, `narration=[]`, `scenes=[]`를 유지합니다. 본편 조성 `NamyangjuMapLedV6`는 이 상태에서 등록되지 않습니다. 이전 취소 v4 작업을 재개하거나 이전 script-v2 음성을 새 대본에 억지로 맞추지 않습니다.

다음 입력이 필요합니다.

1. 승인된 새 대본의 정확한 `script_revision`, 장면ID, 내레이션 원문, 주장ID, 명시적인 장면별 자료 연결.
2. 같은 대본으로 생성한 Jun 음성: `scene_id`, 파일, SHA256, 실제 디코딩 PCM 길이, 샘플레이트, 생성 버전. MP3 컨테이너 길이와 실제 PCM 길이는 구분합니다.
3. 음성 기준 `from_frame`, `duration_frames`를 30fps로 잠근 시간표. 반올림·말미 패딩을 기록하고, 프레임 경계 때문에 음성 끝을 자르지 않습니다.
4. 의미 자막: `{id,start_frame,end_frame,lines:[...],protected_phrases,basis}`. 장면 상대 프레임을 사용하며 수량·단위·지구명·고유명사를 묶습니다. 명시적 줄바꿈만 렌더합니다. 문자량 추정이면 정렬·청취 완료로 쓰지 않습니다.
5. 지도 장면: `{scene_id,shot_id,kind,from_frame,duration_frames,title,message,asset_ids,claim_ids,district,block_id,focus_ids,mandatory_label}`. 모든 자료는 명시적 ID로 연결하며 숫자 나머지/임의 순환으로 선택하지 않습니다.
6. 외부 비교 표본: 지역/단지, 전용면적 범위, 거래 기간, 취소 제외, 거래 건수, 준공연도, 층 조건, 가격의 종류와 단위. 데이터가 준비되지 않으면 숫자·가격 우위를 임의로 채우지 않습니다.

본편 등록 전 필수 검사는 새 대본과 음성 버전 일치, 실제 파일 및 SHA, 장면 시간의 누락·겹침, 자막 원문 보존, 보호 표현, 자료 권리, 공간 등록 상태입니다.

음악 구간은 `{id,from_frame,duration_frames,source_offset_frames,gain,duck_gain,fade_in_frames,fade_out_frames,voice_ranges}`입니다. `voice_ranges`는 해당 음악 구간 안의 실제 내레이션 범위이며, 말할 때 낮추고 끝에서 천천히 올립니다. 64초 음악 원본에서 필요한 20~30초 도입 및 10~20초 마무리만 가져오므로 무한 루프나 새 곡 구매가 필요하지 않습니다. 정확한 길이는 새 음성 이후 결정합니다.

공식 계획도 KOGL3 원본은 전체 `contain`만 사용합니다. 크롭·핀·색칠·선 덧그림·원본 줌은 하지 않습니다. 별도의 독립 지리 지도에서 확인된 LH 안내점과 OSM 도로·하천을 다룹니다. 안내점은 블록 경계·정문·보행 동선이 아닙니다. 정밀 시설이나 경계는 대응 기준점과 권리가 확인된 자료가 추가되기 전까지 표현하지 않습니다.

기존 작은 보행자는 표현 기법만 재사용합니다. 왕숙에 별내 단지 경로를 이식하지 않습니다. 실제 왕숙 경로가 없으면 도보/버스 동선을 확정선으로 그리지 않습니다.

검토용 이미지 공백은 회색 요청 카드로 목적과 미확인 상태를 남깁니다. 새 이미지 생성은 하지 않습니다. 최종 납품에서는 검증 지도·사진으로 대체하거나 불필요한 분위기 컷을 삭제합니다.
