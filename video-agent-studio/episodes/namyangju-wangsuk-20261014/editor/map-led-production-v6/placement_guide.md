# 왕숙 지도 중심 본편 v6 배치

배포 예정 파일: `outputs/video-review-v6/namyangju-map-led_v6.mp4`.
길이: 876.4초, 1920×1080, 30fps. 기존 본편과 조각 영상은 보존한다.

실제 장면·쇼트의 프레임은 `timing_lock.json`을 기준으로 한다. 48개 쇼트는 승인 TXT의 정확한 문자 경계와 새 Jun 음성의 공급자 문자 타임스탬프로 연결했다. 문자 수 비례 추정은 사용하지 않는다.

|---|---|---|
| M000 | 도입 질문, 두 지구 전체 원본 계획도 | 1.5초 음악 리드인 뒤 음성, 원본은 contain으로 전체 표시 |
| M001 | 왕숙1·2 전체 계획도 → 자체 위치 지도 | 원본에 핀을 덧그리지 않고 별도 지도 장면으로 전환 |
| M002~M006 | 일자리·운영/예정 철도·가격·생활·공급 | 실제 안내점 카메라 이동, 지도 바깥의 조건과 시간 표시 |

| M007 | 공공분양 기본형과 조건별 기존 단지 거래 | 상품·공고시점·면적·표본 차이를 가격표에 병기 |
| M007B | 창릉·왕숙·교산 방향 비교 | 실제 주요도로·하천, 확인된 안내점만 표시. 교산 정밀 핀 없음 |

하단 자막과 출처는 지도 카메라와 분리된 고정 레이어다. 자막은 269개 의미 단위, 명시적 최대 두 줄을 사용한다. 숫자·단위·고유명사의 분할은 승인 자막 범위를 따른다.

이미지 요청 GAP-M002-01과 GAP-M005-01은 신규 생성 없이 사실 지도·일정 조건·배치 설명으로 대체했다. 최종 본편에는 회색 자산 요청 카드나 설명 없는 검은 화면을 사용하지 않는다.

음악은 기존 자체 합성 Data City Ambient v1, 도입·마무리에만 배치한다. 발화 중 gain 0.18로 낮추고, 음성은 0.9 gain이다. 정확한 구간과 페이드는 `music_plan.json`에 기록한다.

실제 청취·연속 재생 검수는 별도 상태다. 전체 디코드와 실제 인코딩 프레임 표본 검사를 청취 완료로 해석하지 않는다.
