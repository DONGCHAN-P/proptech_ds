# 시각 자료 v3 추가 확보

기존 v1/v2 보존. v3은 전체 10개 실제 자산 목록이며 지역 개요지도와 일자리 단계 카드를 추가한다.

## 실제 지역 개요지도

S002_namyangju_regional_osm_v3.png, 1920×1080. 공개 Overpass에서 경도127.03~127.40/위도37.55~37.85의 도로·하천·철도·place node 실제 지리 요소 5,615개를 조회했다. 원데이터 regional_osm_v3.json, 좌표 및 조회URL regional_meta_v3.json. 이 범위는 영상 설명용 화면 범위이며 남양주시 행정 경계가 아니다.

OSM place 노드의 실제 좌표로 화도읍·퇴계원읍·다산동·별내동·별내면·진접읍·오남읍·평내동·진건읍·일패동·이패동·호평동 12개를 표시했다. 지역 내 대략적 기준점이며 모든 주택 위치나 생활권의 중심이라고 주장하지 않는다. 경도는 cos(37.7도) 보정한 지역 등거리 원통 투영, 위도는 동일 배율로 북상향 표시했다. 왕숙1/2 법정 경계나 임의 정밀 위치를 그리지 않고 공식 DEV-001 소재지를 오른쪽 텍스트로만 설명한다.

원본 저장·지도 PNG 해상도·실제 이미지 육안 확인 완료. 지나치게 많은 통/리 place를 제외하고 label 간격을 조정했다. 편집 안전영역 적용과 모바일 축소 검수는 별도 단계다. 하단 OSM 출처는 편집 자막에 가리지 않도록 안전영역 fit 또는 별도 항상 보이는 출처 레이어 유지.

OSM ODbL 조건: © OpenStreetMap contributors 및 https://www.openstreetmap.org/copyright 표시. 원데이터·좌표 메타도 함께 보존한다. 공식 정책 https://operations.osmfoundation.org/policies/tiles/ 는 표준 타일 offline/prefetch 사용을 금지하므로 이번에는 표준타일 서버를 사용하지 않았다. OSM 공개 데이터의 복제·가공 조건은 https://www.openstreetmap.org/copyright 에서 확인했다. Overpass 공개 지리 GET 1회만 수행했고 반복 렌더는 로컬 원데이터 사용한다.

회색 철도는 실제 OSM 데이터의 지형적 선으로만 읽는다. 이번 지도는 운영/계획 상태 구별이나 역 출입구·통근시간 근거가 아니다. 운영·계획 비교는 S004 별도 카드와 검증된 facts를 사용한다.

## 일자리 단계 카드

S005_jobs_stage_v3.svg는 기존 산업단지 조성완료 / 왕숙산업단지 개발실시계획 승인 / 입주예정기업과 실제 운영 미확인 / 우리금융 건축허가와 준공목표를 분리한다. DEV-012/004/006/007. 회사 로고·사진·고용숫자 없음. 편집 담당에게 실제 래스터 검수를 요청했다.

## 사용자 알림

기존 notify.telegram.send를 사용해 짧은 진행상태 TEXT를 보냈으며 실제 결과 sent=True, notification_v3.json에 기록했다. 대본이나 파일 첨부는 보내지 않았다. 실제 사진은 확보0개이며 지도·원본 계획도·자체 정보 카드로 편집 가능하다.
