# 남양주 왕숙 시각 소스 계획 v1

입력은 승인 script-v2, scenes-v2, facts-v1, input-v1 자료집 및 continuity_notes_v2.md. 시간 미확정으로 장면ID를 유지한다. 추가 유료 생성·외부 업로드 없이 자체 SVG 5개를 준비했다.

## 제작 브리프

1920×1080, 전편 v14의 미색 #F6F4EF·진한 글자 #111111·파랑 #2F6FED·빨강 #E5484D·회색 #6E6E6E. 파랑·빨강은 강조색이며 왕숙 가격 상승이나 사업 완료를 의미하지 않는다. 자막은 별도 고정 흰 상자, 전체 화면 확대 및 텍스트 상승 금지. 하단 출처를 자막과 겹치지 않도록 편집 단계에서 배치한다. 첫/끝 장면은 같은 다섯 질문 구조를 사용한다.

## 실제 지도·사진 소스 확인 순서

1. 남양주시 https://www.nyj.go.kr/www/contents.do?key=3039 (facts DEV-001·002), 공식 지구 경계와 토지이용도. 2026-10-14 이번 접근은 web 502, 로컬 연결 실패. 이미지 경로와 개별 공공누리 유형 미확인. 기관명만으로 재사용 허용 추정 금지.
2. 토지이음 https://www.eum.go.kr/web/gs/gv/gvGosiDet.jsp?seq=629630 및 seq=628726 (DEV-003). 첨부 고시 도면의 제작일·변경차수·이미지 재사용 조건을 확인한 뒤 시 도면과 대조한다. 현재 최신 전수 대조 미완료.
3. OSM 데이터로 지역 위치 지도를 만드는 경우 ODbL 출처 및 © OpenStreetMap contributors 표기를 유지한다. https://www.openstreetmap.org/copyright 와 타일 공급자별 정책을 확인한다. 현재 좌표/경계/타일을 다운로드하거나 검증하지 않았다. OSM을 신도시 법정 경계의 유일 근거로 사용하지 않는다.
4. 운영철도는 https://www.ncuc.or.kr/jj_line/2340, /1694, /2351 및 DEV-011 운영사 자료의 역명·운영 상태를 우선한다. 실제 위치·노선 원본 및 사용 조건 확인 전 임의 노선도 제작 금지.
5. 실제 거리 사진은 촬영 위치가 특정되고 재사용 허용이 확인된 사진만 후보로 채택한다. 기존 광교·동탄 사진은 남양주 자료로 재사용하지 않는다. 현재 남양주 실사 확보 0개.

## 내부 검수 및 다음 단계

자체 SVG는 입력 값·문구·1920×1080 구조를 확인했다. 래스터 렌더·실제 프레임 가독성·음성 청취·연속 영상 재생은 하지 않았다. S001/S007 두 대표 장면을 편집용 실제 렌더로 검수한 뒤 나머지를 적용한다. timing lock 이후에만 자막 안전영역과 장면 분할을 확정한다. 지도 미확보 상태는 제작완료가 아니며 사실과 권리 확인을 충족하는 실제 소스 확보가 필요하다.
