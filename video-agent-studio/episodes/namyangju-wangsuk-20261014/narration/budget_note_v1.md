# 남양주 대본 v2 음성 예산 사전안

2026-10-14 공식 자료 확인. 유료 생성·외부 전송은 실행하지 않았다.

장면별 narration_text를 그대로 요청할 경우 공백·문장부호·내부 줄바꿈 포함 **7,419자**다. 화면 지시·제목은 제외하며 장면 사이 추가 구분자는 넣지 않는다. 1회 전체 생성에 부분 수정 20% **1,484자**를 더해 **8,903자** 상한을 제안한다. 발음 풀어쓰기·오디오 태그가 추가되면 실제 요청 문자열을 다시 계산해야 한다.

기존 승인 **Jun / eleven_v4**를 유지한다. 공식 v4 페이지는 기존 TTS와 동일 크레딧 체계라고 안내하고 가격 페이지의 기본 TTS 기준은 1자당 약 1크레딧이다. 따라서 기본 7,419크레딧, 수정 포함 8,903크레딧이다. **Jun의 커스텀 음성 배율은 미확인**이며 공식 안내에 따라 배율이 있으면 실제 비용이 늘어난다. 배율 확인 전 이 수치를 확정 과금 상한으로 쓰지 않는다.

계정 요금제·잔여 크레딧·상업 이용 라이선스는 확인하지 않았다. Starter 정상 월 $6 / 30,000크레딧을 단순 배분하면 전체 1회 $1.4838, 수정 포함 $1.7806 상당이나 이는 참고용 구독비 배분이고 이번 영상의 추가 청구액이 아니다. **추가 현금 지출 상한 $0**, 충분한 기존 포함 크레딧만 사용하며 부족하면 중단한다. 자동 충전·초과 과금·요금제 변경·갱신을 허용하는 승인이 아니다.

편집용 자체 도표·카드·로컬 렌더·권리 확인된 기존 소스로 미디어 추가 비용 $0을 제안한다. 지도는 제공자·재사용 조건 확인이 필요하다. 유료 지도·스톡·AI 이미지/영상·음악·전사는 이 예산에서 제외한다. 작성자의 709초는 추정이며 실제 음성 길이나 청취 결과가 아니다.

대본 승인은 완료됐지만 이 예산과 외부 TTS 전송/크레딧 사용은 별도 budget 결정이 필요하다. 승인 범위는 script-v2, 기존 설정, 1회 전체+최대 1,484자 부분 재생성이다. 전체 재생성 2회는 포함되지 않는다. 실제 누적 요청 문자·크레딧을 기록하고 상한 초과 전 중단한다.
