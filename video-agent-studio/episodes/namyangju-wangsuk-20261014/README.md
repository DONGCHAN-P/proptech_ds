# 남양주 소개편

2026-10-14 사용자 요청으로 착수한 별도 에피소드다. 이전 광교·동탄 본편과 원본은 보존한다.

## 방향

남양주의 기존 생활권을 먼저 지도에서 이해하고, 왕숙1·2가 어디에 어떤 변화를 더하는지 설명한다. 출퇴근·통학·생활시설의 준비 시점으로 개발계획을 읽는다. 원자료의 투자 중심 결론이나 13분 분량은 고정 조건이 아니다.

## 자료와 작업

- `inputs/`: 다운로드 원본 두 개의 보존 사본, SHA-256 기록, 엑셀 11개 시트의 셀 좌표별 추출본.
- `research/development/`: 지구계획·산업·기업·철도 검증 12개 주장.
- `research/living/`: 분양·학교·생활권 검증 12개 주장.
- `research/facts.json`: 두 리서치 결과의 통합 주장 목록. 출처·기준일·확인일·한계를 포함한다.
- `research/local/`: 기존 프로젝트 실거래 탐색. 외부 추가 수집은 하지 않았다. 분양 할인율이나 수익률 근거로 쓰지 않는다.
- `writer/`: 구성 제안, 검토용 대본과 장면 제안.
- `qa/`: 독립 원문 대조와 초안 검수. 실제 영상·음성이 없는 단계이므로 재생·청취 검수를 뜻하지 않는다.
- `state.json`, `scenes.json`, `decisions.json`: 총괄 진행 상태와 결정 기록.

## 역할

총괄이 개발·교통 리서치, 분양·생활 리서치, 구성·대본 담당을 실행했다. 리서치 종료 후 독립 검수를 추가했다. 총괄 포함 최대 4개 실행 슬롯을 지켰다. 음성·편집·최종 시각자료 담당은 해당 입력 확정 이후 단계다.

## 승인 범위

사용자의 직접 요청으로 남양주 주제와 조사·검토용 대본 작업을 진행한다. 이전 다음 영상 주제 제안 `23a3212d3ec7`은 새 요청으로 대체됐다는 기록을 남겼다. 이전 본편 공개 승인과는 별개다.

다음 결정은 대본 검토이며, 이후 유료 생성 전 예상 비용·상한을 제시한다. 완성본 전달과 최종 업로드 승인도 따로 다룬다. 유료 생성·외부 전송·업로드는 시작하지 않았다. 텔레그램 전송·수신의 실제 동작을 이번 작업에서 검사했다고 주장하지 않는다.
