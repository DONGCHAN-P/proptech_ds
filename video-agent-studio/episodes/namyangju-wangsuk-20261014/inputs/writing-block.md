# 1. 리서치 목적과 핵심 질문

## 1.1 콘텐츠 기획 배경

기존 광교·동탄 신도시 분석 영상의 후속편으로, 왕숙 신도시가 미래에 어떤 도시로 성장할 수 있는지 검증한다.

단순히 GTX, 대기업 유치, 대규모 주택 공급 등을 호재로 나열하지 않는다.

**실제로 도시가 얼마나 발전할 수 있는지, 그 가능성이 현재 분양가격에 얼마나 반영되어 있는지**를 중심으로 분석한다.

## 1.2 반드시 답해야 할 질문

1. 왕숙1과 왕숙2는 어떤 차이가 있는가?
2. 약 8만 가구의 주거 수요를 뒷받침할 일자리가 형성될 수 있는가?
3. GTX-B와 9호선은 실제 입주 시점에 이용할 수 있는가?
4. 왕숙의 분양가는 다산·별내·진접과 비교해 매력적인가?
5. 학교·병원·상업시설은 입주 시점에 얼마나 준비되는가?
6. 기업 유치와 교통 개발이 지연된다면 어떤 위험이 발생하는가?
7. 장기 투자 관점에서 어떤 조건이 충족되어야 왕숙의 가치가 높아지는가?

## 1.3 팩트체크 분류 기준

| 등급 | 의미 | 영상 표현 기준 |
|---|---|---|
| A | 공식 고시·승인·운영 사실 | 확정된 사실로 설명 가능 |
| B | 공식 사업계획·목표 일정 | '계획', '예정', '목표' 표현 필수 |
| C | 언론 전망·기업 투자협약·주민 의견 | 전망 또는 기대라는 점 명시 |
| D | 일정 불일치·근거 부족·확인 필요 | 결론에 직접 반영하지 않음 |

**핵심 원칙:** 계획 발표, 사업 승인, 착공, 준공, 운영은 서로 다른 단계다.

# 2. 왕숙 신도시 개발 개요

## 2.1 왕숙1·왕숙2 규모 비교

| 구분 | 왕숙1 | 왕숙2 |
|---|---|---|
| 위치 | 진접읍·진건읍·퇴계원읍 일원 | 일패동·이패동 일원 |
| 사업 면적 | 약 1,029만㎡ | 약 239만㎡ |
| 계획 주택 | 64,159호 | 15,955호 |
| 계획 인구 | 약 15.5만 명 | 약 4.0만 명 |
| 주요 특성 | 자족시설·산업단지·주거 복합 | 주거·문화예술·생활환경 |
| 분석 핵심 | 일자리 중심 자족도시 가능성 | 입지·분양가·생활권 경쟁력 |

합산 계획은 **80,114호, 약 19.5만 명**이다.

이 수치는 계획 수용 규모이며 실제 공급 완료 또는 입주 완료 물량이 아니다.

### 핵심 해석

- **왕숙1:** 산업단지와 철도, 일자리 창출이 장기 경쟁력의 핵심이다.
- **왕숙2:** 서울 및 기존 남양주 생활권 접근성과 주거환경, 분양가격을 중점적으로 살펴야 한다.
- 두 지구를 하나로 묶어 평균적인 입지나 가격을 설명하면 실제 투자 판단이 왜곡될 수 있다.

1. 수도권 전체 지도에서 남양주 위치 표시
2. 왕숙1·왕숙2의 사업 경계 표시
3. 두 지구의 면적·공급 규모 애니메이션
4. 산업단지와 주요 철도 예정 위치 강조

"왕숙 신도시라고 하면 하나의 도시로 생각하기 쉬운데요. 실제로는 왕숙1과 왕숙2라는 서로 다른 지구입니다. 규모부터 개발 방향까지 차이가 있기 때문에, 오늘은 이 두 지역을 구분해서 살펴보겠습니다."

# 3. 토지이용계획 분석

## 3.1 조사 목적

토지이용계획은 단순히 건물이 들어올 위치를 확인하는 데 그치지 않는다.

미래 주거 선호도와 도시의 중심지가 어디에 형성될지 분석하기 위한 기초자료다.

### 확인할 시설

| 시설 유형 | 확인 내용 | 투자 가치와의 관계 |
|---|---|---|
| 공동주택용지 | 블록별 위치·밀도 | 공급량·주거환경 |
| 상업시설용지 | 중심상업지 위치 | 생활 편의성과 중심지 형성 |
| 업무·자족시설 | 기업·업무시설 배치 | 직주근접 수요 |
| 산업시설용지 | 산업단지 경계 | 일자리·주변 환경 |
| 철도역 | 출입구와 주거지 거리 | 접근성 프리미엄 |
| 학교 | 초·중·고교 위치 | 가족 단위 주거 수요 |
| 공원·녹지 | 녹지축과 공원 규모 | 주거 쾌적성 |
| 에너지·기반시설 | 발전·물류·처리시설 위치 | 환경 및 생활 영향 |

## 3.2 반드시 수행할 공간 분석

- 왕숙역 예정 위치를 기준으로 500m·1km 생활권 표시
- 주요 공동주택 블록과 상업·자족시설 간 거리 계산
- 학교 예정지와 주거 블록 간 실제 보행 경로 분석
- 산업단지·열병합발전소와 주요 주거지역 간 거리 확인
- 왕숙1·왕숙2의 지구 내부 이동 및 연결도로 분석

**주의:** 지도상 직선거리와 실제 보행시간은 다르다. 철도역 출입구 위치가 확정되지 않은 경우 정확한 역세권 범위를 단정하지 않는다.

### 영상 활용법

**추천 장면:** 개발 개요 및 가격 분석 구간

공식 토지이용계획도를 배경으로, 공동주택용지를 회색, 업무·산업용지를 파란색, 상업지역을 주황색, 공원과 녹지를 초록색으로 구분한다.

시청자가 미래 도시의 중심지와 생활권을 직관적으로 이해할 수 있도록 제작한다.

**핵심 메시지**

"같은 왕숙 신도시라도 어느 블록에 위치하느냐에 따라 철도 접근성, 생활 편의시설, 주변 환경이 달라질 수 있습니다."

# 4. 일자리와 자족도시 경쟁력

### 주요 클러스터 구상

| 구분 | 육성 방향 |
|---|---|

클러스터 명칭과 산업 육성 방향은 미래 개발계획이다. 실제 기업 입주 및 고용 발생 현황과 구분해야 한다.

## 4.2 주요 기업 유치 계획

| 기업 | 계획 시설 | 발표 투자 규모 | 확인 단계 |
|---|---|---:|---|
| 우리금융그룹 | AI 디지털 유니버스 | 약 8,500억 원 | 건축허가 관련 보도 |
| 카카오 | 디지털 허브·데이터센터·R&D | 약 6,000억 원 | 투자협약 |
| 신한금융그룹 | AI 인피니티센터 | 약 8,500억 원 | 투자협약 |

**팩트체크 주의사항**

- 투자협약은 기업의 시설 준공이나 입주를 뜻하지 않는다.
- 투자액은 실제 투입된 자본금과 다를 수 있다.
- 데이터센터 투자액이 크더라도 상주 근로자 수는 제한적일 수 있다.
- 우리금융 투자액은 발표 시점에 따라 5,500억 원과 8,500억 원 등 서로 다른 수치가 존재한다.
- 정확한 개별 기업 필지 위치는 용지계약·건축허가 자료로 추가 확인해야 한다.

- 서울 중랑·노원·동대문구 일자리

단순 근무지까지의 직선거리가 아니라 실제 대중교통 통근시간을 비교한다.

## 5.2 핵심 리스크: 철도와 입주 시점 불일치

과거 발표자료와 후속 보도를 종합하면 GTX-B, 9호선 연장 모두 2031년을 목표 일정으로 제시한 사례가 있다.

하지만 9호선은 일부 공구의 사업자 선정·발주 지연 문제가 제기됐다.

## 투자 분석의 공통 메시지

**왕숙이 앞으로 좋아질 수 있다는 것과, 현재 투자하기 좋은 가격이라는 것은 별개의 문제다.**

결론에서는 다음을 각각 평가한다.

1. 장기 도시 성장 가능성
2. 일자리 창출의 실현 가능성
3. 교통 개선의 현실적 시점
4. 주변 시세 대비 분양가 경쟁력
5. 투자 실행 조건과 보유 리스크

투자 적합성은 단일 점수만으로 결론 내기보다 각 항목의 근거와 불확실성을 함께 설명한다.

# 13. 자료조사를 실제 영상 제작에 연결하는 방법

## STEP 1. 공식 자료를 데이터베이스로 관리

모든 출처에 다음 정보를 부여한다.

| 필드 | 내용 |

| Source_ID | 출처 고유 ID |
| Category | 개발·교통·일자리·분양·생활 |
| Title | 문서 제목 |
| Publisher | 발표 기관 |
| Published_Date | 원문 발표일 |
| Updated_Date | 최종 변경일 |
| Evidence_Level | A·B·C·D |
| Key_Fact | 영상에 활용할 사실 |
| Source_URL | 공식 원문 링크 |
| Asset_Path | 도면·PDF·이미지 위치 |
| Video_Section | 활용 시간대 |
| Verification_Status | 검증 완료·재확인 필요 |

## STEP 2. 수치와 해석을 분리

예시:

**원천 사실:** 왕숙 도시첨단산업단지 개발실시계획인가 고시.

**가능한 해석:** 산업단지 조성 절차가 진전됐다.

**아직 증명되지 않은 주장:** 기업 입주와 대규모 고용으로 왕숙의 집값이 크게 상승할 것이다.

세 문장을 구분해 기록해야 과장된 투자 콘텐츠가 되지 않는다.

## STEP 3. 정량 데이터를 추가

현재 자료의 강점은 개발계획과 공식 발표를 폭넓게 확보했다는 것이다.

남은 핵심 작업은 다음과 같다.

- 2020~2026년 다산·별내·진접 실거래가 수집
- 전용 59㎡·84㎡ 중심의 비교 단지 선정
- 왕숙 분양가와 비교 지역 시세 격차 계산
- 2027~2032년 예정 공급량 수집
- 왕숙 분양의 세금·대출·보유비용 계산
- 분양 유형별 전매·거주의무 등 법적 조건 검증

## STEP 4. 사실 검증 후 내레이션 작성

내레이션 문장마다 출처 ID를 연결한다.

예시:

`SCRIPT-023 → SOURCE-IND-004 → IMG-IND-002`

이렇게 관리하면 고시가 변경되거나 철도 일정이 달라질 때 수정해야 할 대본과 시각자료를 빠르게 찾을 수 있다.

## STEP 5. 시각자료에 근거와 날짜 표시

권장 형식:

- 화면 하단: `출처: 국토교통부, 2025.12.31`
- 그래프 하단: `단위: 억 원 / 계약일 기준 / 전용 84㎡`
- 계획 도면: `계획안이며 향후 변경 가능`
- 교통 일정: `개통 목표, 확정일 아님`

공공기관이 공개한 조감도도 무조건 자유롭게 사용할 수 있는 것은 아니다. 공공누리 이용조건, 이미지 출처, 언론사 사진의 저작권을 구분해 확인한다.

## 최종적으로 영상에서 전달할 메시지

왕숙 신도시는 대규모 주택 공급과 함께 산업단지, 기업 유치, 철도망 확충이 추진되는 도시다.

이 가운데 산업단지 개발계획과 일부 기업 유치, 철도 사업은 구체적인 행정절차로 진전됐다.

그러나 투자 가치는 이러한 계획의 존재만으로 결정되지 않는다.

**실제 일자리가 만들어지는 시점, 교통망이 작동하는 시점, 주변 공급량, 그리고 현재 분양가격이 얼마나 매력적인지를 함께 분석해야 한다.**

따라서 후속 정량 분석의 핵심 질문은 다음과 같다.

> **"왕숙의 미래 가치를 고려했을 때, 지금의 분양가격은 충분한 안전마진을 제공하는가?"**

이 질문에 실제 데이터로 답하는 것이 왕숙편의 최종 목표다.
