# 후반 v7 구성안 — 지도 분석을 후보 판단으로 연결

범위: 기존 v6의 M008·M009만 교체. 다른 내레이션 원문은 보존한다. 신혼희망타운 왕숙1 A2·A24는 대장 후보와 마무리 후보군에서 제외한다. 공고가 확인된 일반형 아파트의 입지를 비교하며 현재 매도·전매가 가능하다는 뜻으로 쓰지 않는다.

1. 오늘의 결론 회수: 분양가만으로 싼 집을 고르는 것이 아니라, 입주 시점의 출근·등교와 생활시설의 완성 시차를 가격에 함께 대입한다.
2. 왕숙1 북부: 산업단지와의 생활권 관계를 살피되 일반형 후보의 유형·공고·학교·교통을 확인한다. 근거가 약하면 대장 지정을 유보하고 선정에 필요한 조건을 말한다.
3. 왕숙1 남부: B17의 74·84형, 앞서 비교한 6억대 예산, 예정 왕숙역 환승권역을 후보 이유로 연결한다. 강남 이동은 계획 철도에 대한 의존과 개통 시차를 함께 설명하고 방음벽·도로·철도 환경과 입주·개교 시차를 판정의 반대편에 둔다.
4. 왕숙2: A3의 예정 일패역 및 복합 기능 관계와 A1의 이른 입주·낮은 기준가격을 같은 권역 안에서 비교한다. 강남 출근의 계획 교통, 실제 통학, 공원·상가 개방일을 분리한다. A3는 조건부 입지 후보, A1은 입주·예산이 우선인 가구의 경쟁 후보로 논증한다.
5. 결론: 후보의 순위가 바뀌는 조건을 제시한다. 권역 이름을 기준으로 정리하고 확정 시세 대장·미래 수익을 약속하지 않는다.

## 확인 필요표

| 판단 지점 | 필요한 근거 | 확인 전 처리 |
|---|---|---|
| 왕숙1 북부 일반형 후보 | 유형·면적·공고/계획 여부·가격·입주·주변 배치 | A2를 대체해 임의 후보를 만들지 않고 유보 |
| B17 일반형 및 거래 관련 제한 | 공고의 공공분양 유형·전매/거주/재당첨 제한 | 현재 거래 가능 표현 금지 |
| A1·A3 유형과 제한 | 지구명 포함 정확한 공고, 일반형/신희 구분 | 왕숙1 A1과 왕숙2 A1 혼동 금지 |
| 강남 출근 | 현재 연결과 계획 연결, 목표 시기 | 분 단위 도보·통근 추정 금지 |
| 학교·공원·상업 | 입주예정과 개교 목표, 실제 배정/개방 | 개교·공원·상가가 입주 때 완성된다고 단정 금지 |
| 가격 대안 | 기존 M007 동일 면적·기간·표본 비교 | 미래 수익·모든 대체지보다 저렴하다는 결론 금지 |

## 화면 원칙

작은 전체 토지계획도 locator를 고정하고 왕숙1 북부·남부·왕숙2의 현재 설명 영역만 표시한다. 큰 지도는 같은 권역 안의 주거·학교·공원·예정역 상대 관계를 안정적으로 보여준다. 입주/학교/철도는 가로 달력으로 겹쳐 비교한다. 동적 확대·축소와 플래시는 쓰지 않는다. 지리적 연결과 실제 통근시간을 혼동하지 않도록 계획 철도는 점선, 일정은 목표로 표기한다.

대본 길이는 작성 후 추정하며 실제 음성 길이로 표시하지 않는다. 새 대본 승인 전 음성 생성 없음.
