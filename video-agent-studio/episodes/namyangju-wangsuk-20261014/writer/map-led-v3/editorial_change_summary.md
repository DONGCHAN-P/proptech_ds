# 대본 v3 재구성 이유와 변경점

사용자가 실제로 들어본 뒤 지적한 문제는 영상 장식이 부족한 것에 이어, 내용이 시설·계획·숫자 목록으로 들린다는 점이다. 이번 수정은 기존 문장을 조금 짧게 읽는 작업이 아니라, 시청자가 **왕숙을 기다릴 이유와 먼저 볼 블록**을 판단하는 이야기로 순서를 바꾸는 작업이다.

## 바뀐 흐름

- 기존: 전편의 다섯 질문을 길게 소개 → 기존 남양주 지역·역 소개 → 왕숙 규모 → 기관별 계획 사실 → 가격을 읽을 때 주의 → 다섯 질문을 다시 요약.
- 새 구성: 왕숙 전체 토지이용계획도 → 공간별 일자리·교통·가격·생활·공급의 편리함과 이용 시점 → 같은 면적 기축 대안과 가격 → 지도에서 조건별 후보 블록을 좁힘.

전편 연결은 도입 한 문장과 판단 방법의 계승으로 줄였다. 별내·다산 지도를 먼저 길게 소개하지 않고 왕숙의 교통과 대체 가격을 이해하는 데 필요한 위치에서만 쓴다. 산업단지 사업비·행정 연혁 등은 생활 판단에 필요하지 않으면 음성에서 빼고 출처 패널로 옮겼다.

## 내용의 선택 기준

각 절은 ‘어디 → 무엇이 편리해지는가 → 언제 쓸 수 있는가 → 입주 때 남는 조건 → 어떤 가구에 의미가 있는가’로 쓴다. 날짜·규모를 읽은 뒤 무조건 ‘더 확인하세요’로 끝내지 않고, 실제로 달라지는 선택을 말한다.

가격은 수집된 국토부 원XML의 같은83~85㎡미만·5층이상 단지별 표본으로 다시 맞췄다. master 탐색값과 지역 전체 중위를 버렸다. 왕숙2 표시가격이 다산롯데캐슬·별내자이더스타보다 낮지만 별내푸르지오보다 낮지는 않다는 사실을 핵심 교환조건으로 삼았다. ‘새집을 기다릴 가구’와 ‘지금 이사하며 기존 시설을 쓸 가구’가 서로 다른 대안을 보도록 설명한다. 차액을 미래 이익으로 소개하지 않는다.

## 지도와 후보

전체 계획도를 처음에 보여주고 모든 절에서 위치를 회수한다. 사용자에게 호평받은 다산 상세 배치도의 주거·상업·공원 맥락과 작은 보행자 표현을 유지하되, 왕숙 설명에는 왕숙 자료를 새로 등록한다. 공식 변형금지 계획도와 자체 지도를 혼동하지 않는다.

후보는 실제 블록 위치가 확인되고 입주·가격·교통·생활 조건을 이야기할 수 있는 3~5개로 제한한다. 지구명이 다른 A1을 섞지 않는다. 각 후보는 먼저 볼 이유와 내려놓을 조건을 함께 설명하며 장래 시세의 확정 순위로 만들지 않는다.

## 유지·보존

기존 MP4·대본v2·Jun 음성·자막·지도 조각은 보존한다. 새 대본은 기존 승인 음성을 그대로 쓰기 위한 내용이 아니다. 사용자 검토 후 별도 음성·예산 단계가 필요하다. 새 이미지도 자동 생성하지 않고 부족한 장면의 목적과 자료 우선순위를 요청서로 남긴다. 의미 단위 자막 원칙은 새 대본에서도 적용하며 실제 음성 전 정밀 타이밍을 주장하지 않는다.

현재 이 파일은 구성·대본 검토 과정의 기록이다. 실제 새 음성·새 전체 영상·연속 재생·청취 완료를 의미하지 않는다.
