# 지도 장면 설계 — 검토용 v3

실제 음성·길이 확정 전의 장면 설계다. 지도 위치와 시설 단계는 리서치 주장ID에 연결한 것만 제작한다. 전체 계획도는 최초 장면과 각 절의 연결점에서 반복해 공간을 잃지 않게 한다.

| 장면 | 관객에게 줄 답 | 화면의 순서 | 정확성·등록 조건 |
|---|---|---|---|
| M001 전체 계획 | 왕숙1/2는 어디에 무엇을 만드는 도시인가 | 왕숙1·2 전체 원본 계획도 → 독립 위치 지도 서울/다산/별내 → 두 지구 주거·자족·상업·녹지 관계 | 원본은 무편집 전체 표시. 독립 지도는 도로·하천·지구 경계 등 3개 이상 확인 기준점으로 등록, 출처/기준일 유지 |
| M002 일자리 | 내 일터로 연결될 가능성, 언제인가 | 전체도 회수 → 산업 기능 위치 → 주거와 연결 → 승인/허가/준공목표 달력 | 부지 경계가 확인되지 않으면 점 핀 대신 방향·범위 수준 표시. 기업 로고를 현재 운영으로 보이게 하지 않음 |

## 변형 금지 계획도의 모션

남양주시 원본 계획도는 공공누리 제3유형이므로 크롭·색칠·핀·선 덧그리기 없이 원본 전체를 표시한다. 화면 옆 패널에서 읽을 범례·지구명을 설명한다. 원본 위치를 시각화한 별도 지도를 쓰려면 복제·변형 권한이 있는 공식 지도 또는 독립적으로 확인한 지리·시설 자료를 확보해야 한다. 독립 지도에 출처 없이 원본 도형을 그대로 베껴 ‘자체 지도’라 이름 붙이지 않는다.

## 자체 지도 등록표 필수 필드

- 지도ID, 원문 URL, 기준일, 권리, 지구, 북쪽 방향, 축척/공간 범위.
- 경계/도로/하천/실재 시설 중 기준점 3개 이상: 원문 위치와 자체 지도 좌표의 대응.
- 블록ID와 지구명, 판독한 원문 페이지, 픽셀/좌표 위치, 위치 검증상태.
- 역·학교·상업·공원별 현재 운영/계획/미확인 구분 및 확인 자료.
- 미확인 출입구·보행로는 점선 또는 질문 라벨, 실선 경로 확정 금지.

## 계승할 조각 영상

`outputs/rail-route-proof-v3/namyangju_rail-route-proof_v3.mp4`의 40.3~61초 다산 주변 배치 표현과 작은 보행자 표식을 스타일 기준으로 삼는다. 같은 영상을 왕숙 공간처럼 쓰지 않는다. 왕숙 상세 설명에는 같은 표현법을 쓰되 왕숙의 검증된 자료를 넣는다. 이동 연출은 걷기·대기·버스·하차후 걷기를 따로 재생하고 실제 소요시간으로 소개하지 않는다.

## 실제 이미지가 없는 구간

자족시설 예정지나 미래 입주 생활의 분위기 장면은 지도 설명을 대체할 수 없다. 필요성이 확인될 때만 `image_gap_requests.json`의 요청 장면을 검토한다. 검토본에는 원래 지도/현황자료를 유지하거나 회색 요청 카드에 위치·목적·미확인 정보를 보여준다. 최종 영상에 이유 없는 검은 화면은 남기지 않는다.
