# 왕숙 지도 중심 전면 재구성 — 대본 v3 구성안

상태: 리서치 진행 중인 구성안. 새 대본·음성·본편 승인 아님.

관객이 마지막에 답할 질문은 하나다. **지금 완성된 주변 아파트를 고를지, 앞으로 달라질 왕숙을 기다릴지, 기다린다면 어떤 블록을 먼저 볼지** 판단할 수 있게 한다.

왕숙을 설명한 뒤 주변 도시로 나간다. 별내·다산·진접 소개를 먼저 길게 하지 않는다. 전편 연결은 ‘완성된 도시의 거래를 봤다면, 이번에는 계획을 생활로 바꿔 읽는다’는 한 문장으로 끝낸다. 숫자는 선택이 달라지는 지점에서만 읽고, 사업비·행정 연혁은 필요한 근거 카드로 보낸다.

## 이야기 순서

1. **왕숙 전체 지도에서 시작한다.** 왕숙1·왕숙2를 같은 축척·방향으로 보고 서울·다산·별내·기존 철도와 관계를 잡는다. 주거·일자리·상업·학교·공원은 계획도 범례에 근거해 읽는다. 두 지구의 똑같은 A번호는 다른 단지라는 것을 초반에 고정한다.
2. **일자리: 출근할 곳이 가까워질 수 있는 자리인가.** 산업 기능과 주거 블록을 지도에 놓고 연결을 설명한다. 예정 기업 이름보다 어느 단계이며 어느 입주 시점에 이용 가능한지에 무게를 둔다. 투자액을 상주 인력으로 바꾸지 않는다.
3. **교통: 개통 뒤의 길과 입주 첫날의 길을 나란히 본다.** 현재 운영 노선과 계획 철도의 시각 문법을 분리한다. 별내 철도 조각은 비교·접속 설명이 필요한 짧은 구간에서만 쓴다. 걸음·대기·버스·환승을 구분하고 임의 분 단위 시간을 만들지 않는다.
4. **분양가: 같은 면적 안에서 어느 선택지인가.** 왕숙1/2·블록·59/84타입·층·선택비용을 먼저 맞춘다. 대표 가격만 읽고 나머지는 화면 표로 보낸다. 공공분양의 청약·입주 시점이 기축 매수와 다른 선택임을 설명한다.
5. **생활시설: 단지에서 학교·장보기·공원으로 실제 하루를 그린다.** 사용자가 좋아한 다산 주변 배치도 방식을 왕숙 계획 공간에 맞게 계승한다. 현재 현황과 계획을 섞지 않는다. 학교 ‘투자심사’는 배정·개교 완료와 다르다. 시설 접근성과 개장일은 각각 확인한다.
6. **주변 공급: 8만 세대를 한 해 물량으로 읽지 않는다.** 확인된 블록별 입주예정 달력을 지도와 연결한다. 전수 확보하지 못한 생활권 입주량은 빈칸으로 명시하고, 입주 집중이 상권 성장과 임대 경쟁에 각각 어떤 의미인지 조건부로 설명한다.
7. **대체 지역과 가격을 바꾸어 생각한다.** 같은 84㎡급 실제 거래 표본과 분양 표시가격을 구분해 비교한다. 차이가 있다면 그 대가가 기다리는 시간·교통 공백·신도시의 초기 불편인지 설명한다. 차액은 수익률이 아니다. 지금 이사해야 하는 가구와 입주를 기다릴 가구의 선택이 달라지게 만든다.
8. **지도로 돌아와 먼저 볼 블록을 추린다.** 지구명을 붙인 3~5개 블록을 실증 가능한 교통·학교·상업·공원·가격 조건으로 좁힌다. ‘대장 확정’ 대신 어떤 조건이 충족될 때 후보가 되는지와 탈락 조건을 말한다. 지도 위치가 확인되지 않은 블록은 순위에 넣지 않는다.
9. **결론은 선택 조건 두세 가지로 닫는다.** 지도에서 좋아 보이는 자리, 내 입주 시점에 실제 쓸 시설, 그 공백을 감수할 가격을 함께 맞추라는 문장으로 끝낸다.

## 장면마다 지킬 설명 리듬

지도에서 어디인지 → 생활에 무엇이 편리해지는지 → 언제 운영/완성 예정인지 → 입주 첫해 남는 조건 → 어떤 가구가 먼저 볼지.

매 장면에 똑같은 문구를 반복하지 않는다. 논리를 유지하면서 실제 출근길·아이 등교·장보기·이사 시점처럼 구체적인 선택으로 연결한다. 지도와 달력은 화면 안에서 서로 연결하고, 발표 연혁을 낭독하는 구성을 피한다.

## 리서치 인계가 필요한 주장 슬롯

- MAP: 공식 전체 토지계획도 기준일·변경차수·사용권·주요 범례·축척/방향. 블록 상대 위치와 철도·학교·상업·공원 접근 관계.
- TIME: 주요 시설과 철도 운영/목표/미확인 상태. 최초 입주와 공백이 겹치는지.
- PRICE: 실제 공고의 블록·면적·층별 표시가격, 확장/옵션 포함 여부와 입주 일정.
- SUPPLY: 지구/블록별 세대수·입주예정·상태를 중복 없이 연결한 연도별 표.
- ALT: 같은 면적·유사 시점 기축 단지별 취소 제외 거래 표본, n·중위·범위·준공·역 접근성.
- CANDIDATE: 최소 3개 블록의 지도 식별과 평가근거. 불명확한 가격·개통·학교를 확인된 것처럼 가정하지 않음.

## 시안과 이미지 공백

공식 변경 금지 계획도는 원본 전체를 그대로 표시한다. 원본 위 임의 색칠·크롭·그림 덧붙이기는 하지 않는다. 모션은 독립 제작한 위치 확인 지도/배치도에서 하고, 등록 기준점을 기록한다. 이미지가 부족하면 검토본에 회색 요청 장면과 필요한 정보·이유를 적고, 조율 뒤 제작한다. 임의 GPT 생성으로 빈칸을 가리지 않는다.

10~15분은 가정이며 실제 음성 길이가 아니다. 확정 전 새 유료 TTS를 호출하지 않는다. 새 대본의 의미 단위 자막은 구·절별로 따로 제안하고, 기존 대본 v2 자막을 억지로 재사용하지 않는다.
