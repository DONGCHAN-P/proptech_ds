# 새 음성 인계

확정할 입력은 `narration_input/manifest.json`과 그 안의 순서대로 나열된11개 TXT다. 각 파일은 장면 내레이션만 공백 정규화해 저장했으며 말하지 않을 제목·화면지시·근거·예산은 제외했다. 최종 QA가 확인한 script/manifest 해시와 실제 송신할 TXT 해시를 대조한다.

- 선호 음성은 기존 Jun. 모델·계정 권한·포함 크레딧·새 예산 범위는 narration/총괄이 실행 전 확인한다.
- 최초 입력6879자, 수정 입력최대1376자, 합계상한8255자. 문자수는 현재 정확한 TXT의 공백·문장부호 포함 Python len이다. 실제 서비스 크레딧 배수·가격을 뜻하지 않는다.
- 오래된 대본v2의 Jun MP3는 보존하되 새 대본에 억지로 맞추지 않는다. script-v4 입력으로 새 음성을 만든 뒤 실제 길이를 확인하고 최종 지도·편집·자막 시간을 고정한다.
- M000의 음악 리드인1~2초와 M009 마지막말 뒤 음악꼬리3~5초는 편집 구간이다. TTS 텍스트에 무음 지시나 음악 설명을 넣지 않는다.
- 실패·발음 수정 시 전편 전체를 다시 호출하지 말고 실제 필요한 해당 장면/부분만 상한 내에서 수정한다. 비용·오류 ledger를 기록하며 불명확한 결과를 중복 요청하지 않는다.

발음 후보: 왕숙1/왕숙2는 ‘왕숙 일 지구/이 지구’, A1/A2/A3는 ‘에이 일/이/삼’, A24는 ‘에이 이십사’, B17은 ‘비 십칠’, S5는 ‘에스 오’, GTX-A/B는 ‘지티엑스 에이/비’, 84 A타입은 ‘팔십사 에이 타입’. 지도 표기는 지구명과 원래 블록명을 유지한다. 발음 사전을 실제 입력 문자로 치환하면 문자수·해시·자막 대조도 다시 계산한 뒤 고정한다.

현재 writer는 유료 TTS를 호출하지 않았다. 음성 청취·실제 길이·단어별 자막 싱크는 아직 확인하지 않았다.
