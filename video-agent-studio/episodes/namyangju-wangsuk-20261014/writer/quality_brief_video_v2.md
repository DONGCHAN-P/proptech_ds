# 남양주 영상 품질 수정 브리프 v2

기준: 승인 script-v2와 실제 audio-v1 8개 파일, 순차 MP3 컨테이너 합 913.188571초. 음성·대본 재생성 없음. 추가 유료 미디어 비용 $0. 기존 v1 MP4와 자료는 보존한다. 이번 산출물은 전체 영상의 편집 지시이며 렌더·청취 완료 결과가 아니다.

## 수정해야 할 원인

실제 전편 기준은 config/current_video.json의 v14이다. PilotV11.tsx는 MediaV11 지도·실사 전환, AssetCutsV11의 소유 개념이미지, QuarterChartsV11의 빠른 차트 그리기와 해당 단지 강조, EndingV11의 동일 질문 회수를 사용한다. v14 실제 MP4의 제작기준이며, 30초 스타일 시안의 승인 여부와 별개다. 이번 사용자가 실제 전편 계승을 요구했으므로 v14를 참조한다.

이번 editor/assembly_provisional_v1.json은 'existing Remotion + PilotV11 / v14 assembly style'을 기록했지만, 실제 editor/build_video_v1.py 40~78행은 SVG와 카드를 PNG로 만들고 챕터별 `dur/len(cuts)`로 균등 배분해 concat했다. 실사·개념이미지·의미별 샷 구조와 차트·지도 내부 강조를 계승하지 않았다. 기존 프레임워크를 언급한 기록과 실제 실행 결과가 일치하지 않은 것이 확인된다. 대본의 8개 대장면을 8장의 슬라이드처럼 구현한 문제다.

## 전편에서 이어갈 것

- 컬러: paper #F6F4EF, ink #111111, blue #2F6FED, amber #FFE45C. Pretendard·흰 자막 박스·출처/기준일 표시를 사용한다.
- 지도는 실제 위치를 보여주고 지금 말하는 핀만 강조한다. 목적이 바뀔 때 확대·이동하고, 라벨을 읽는 동안 카메라는 멈춘다.
- 차트는 핵심 축과 막대를 초반에 빠르게 그린 뒤, 낭독하는 타입과 숫자만 강조하며 읽는 시간을 준다. 계속 수치가 뛰는 장식은 하지 않는다.
- 장소를 설명할 때 실사, 관계를 설명할 때 다이어그램, 가상의 상황을 생각할 때 개념 컷을 쓴다. 같은 카드에 제목과 대본을 길게 적어 읽지 않는다.
- 도입 0~4초는 소유 전편 v14의 생활권 지도 구간 03:16.8~03:20.8 후보를 음소거해 사용한다. '전편: 광교·동탄' 명시 후 남양주의 실제 지도로 이동한다. 정확 프레임은 editor가 추출·검토한다. 전편 가격배수·최고가를 새 도시 기대가격처럼 붙이지 않는다.
- BGM은 소유 Data City Ambient v1 후보를 재사용한다. 음성을 우선하고 숫자·조건 설명 중 더 낮춘다. 최종 믹스는 실제 청취해야 승인할 수 있다.

## 전체 샷 설계

writer/shot_plan_video_v2.json은 **62개 샷**으로 전체 0~913.189초를 덮는다. 전편 발췌 3, 실제지도 16, 모션다이어그램 18, 개념이미지 8, 실제사진 6, 데이터차트 11개다. 이 분포는 의미에 따른 계획이며 실사 확보 실패 시 무조건 같은 수량을 맞추는 할당량이 아니다.

각 샷에는 목적, 낭독 cue, chapter ID, claim IDs와 출처, 증거/개념 구분, 카메라 동작, 전환, 자막·BGM 의도와 미확보 대안을 지정했다. 기계적인 5초 컷 규칙은 없다. 지도·표·조건을 읽는 긴 유지에는 대상 강조가 진행되며 정지 타이틀로 채우지 않는다. 33초 공급 차트 유지 구간은 전체계획→블록 입주 달력→연도별 미확인 빈칸으로 의미를 바꾸며 전개한다.

타이밍은 실제 챕터 파일 길이에 기존 caption_estimates.json의 문자비중 앵커를 연결한 **heuristic**이다. 단어 정렬·실제 청취를 수행한 시간표가 아니다. 편집자가 decoded PCM 기준의 실제 챕터 길이를 사용하면 모든 오프셋을 일관되게 다시 계산한다. 숫자·학교명·타입별 가격 강조 시작점은 실제 음성을 들어 조정한다. 대본이나 음성을 자르지 않고 시각 전환만 맞춘다.

## 시각 담당에게 필요한 소스

visual_prepare에게 실제 요청을 전달했다. 지역 OSM 지도, 왕숙1·2 공식 원본 도면, 별내역/별내별가람역을 구분할 실사, 다산역·공원 등 기존 생활사진, 기존 산단 위치핀, 문서·표 근거가 필요하다. 담당 메시지상 별내역 실사 다운로드 일부 성공, 나머지는 후보 확인 중이며 확보 완료로 기록하지 않는다.

공식 왕숙 계획도는 공공누리3유형 변경금지 조건을 유지한다. 원본 전체를 비율 보존해서 보여주며 원본 위의 핀·하이라이트·재색칠·크롭을 피한다. 움직이는 설명은 별도 독립 실제지도·별도 도식에서 한다. 정확한 역 출입구·학교 배정·시설 위치가 미확인인 곳에는 정확 핀을 만들지 않는다.

실제 다산초 사진이 확보되더라도 왕숙의 신규 학교가 완공됐다는 증거로 쓰면 안 된다. 왕숙교 사진은 신도시 공사현장 사진이 아니다. 진접 지역전경을 왕숙2 전경으로 표기하지 않는다. 각 사진은 실제 장소명·촬영/게시일·출처·권리조건을 표시한다.

소유 asset-pack-v9의 책상·철도연결·생활권·수변·세가지조건·세시간표 이미지 후보 경로를 JSON에 넣었다. 기존 소유 개념 컷을 먼저 쓴다. **AI 개념 이미지 · 실제 왕숙 모습 아님** 라벨을 넣고 지구 위치, 준공상태, 학교·공원·역의 실제 모습에 대한 증거로 사용하지 않는다. 새로운 유료 AI 생성·스톡 구매는 이 브리프가 승인하지 않는다. 미확보 실사 대안은 같은 주제 실제지도·독립 노드 도식이다.

## 편집·검수의 수용 기준

1. 음성·대본 내용과 순서는 그대로이고 v1은 보존된다. 전체 끝까지 샷이 연결되며 대표본만 납품하지 않는다.
2. 챕터 안에서 지금 설명하는 대상이 시각적으로 바뀐다. 모든 챕터가 제목·글자 카드 하나로 머물지 않는다.
3. 실제 지도·실사·개념 이미지·동작 다이어그램·데이터표가 각각 설명 목적을 가진다. 대본 문장 전체를 큰 글자로 복제하지 않는다.
4. A1·A3는 왕숙2라는 지구명을 유지한다. 산단 승인/건축허가/준공목표/실제운영과 가격표 조건을 시각에서도 분리한다.
5. 수치·시간차·타입 강조는 음성에 맞는다. 현재 추정 자막을 정확 싱크로 보고하지 않는다.
6. 실제 연속 재생·청취 후에 자막 가독성, 장소 오인, 지루한 유지, 음악 밸런스를 확인한다. 샘플 프레임만 본 검수와 전체 재생 검수를 따로 기록한다.

이 브리프는 writer 소유 편집 제안이다. 공통 scenes/state/decisions는 총괄만 갱신한다. editor가 실제 소스 확정과 렌더·검증을 기록하고, visual은 파일·권리·정확한 장소를 연결한다.
