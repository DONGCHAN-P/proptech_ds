# 제작팀 사용하기

이 폴더에는 7개 Codex 역할 설정, 업무 순서, 공통 장면표·핸드오프·논의·검수 양식이 들어 있습니다.

현재 사용 방법: Codex에 이 폴더의 WORKFLOW.md와 agents/video_director.toml을 읽어 달라고 한 뒤 영상 작업을 요청합니다. 총괄이 필요한 역할 설정을 읽어 서브에이전트 작업 메시지에 전달합니다. 도구가 없는 환경에서는 역할을 순차 수행합니다.

사용 예:

> 이 제작팀으로 새 부동산 영상 만들어줘. 주제는 [주제], 길이는 [길이], 결과물은 [결과물]. 기존 목소리와 디자인을 유지하고, 담당자끼리 필요한 내용은 논의한 뒤 결정 기록을 남겨줘.

> 이 제작팀으로 [영상 경로]의 삽입 소스팩만 만들어줘. 이미지와 짧은 클립, 썸네일 후보, 시간 파일명, 배치 가이드, ZIP과 압축 해제 폴더를 줘.

> video_visual로 이 YAML에 맞는 썸네일 배경만 만들어줘.

자동 등록: 현재 .codex/agents 쓰기가 권한 정책에서 거절되어 설치하지 못했습니다. agents/*.toml을 프로젝트의 .codex/agents/에 배치하면 공식 custom agent 형식으로 사용할 수 있습니다. 등록/자동 실행은 아직 검증되지 않았습니다. 사용자 전역 설정은 변경하지 않았습니다.

episodes/newtown-reference는 기존 작업의 화면 기준 위치와 제한을 정리한 예시입니다. 다음 영상에는 새 episode를 만들어 사용하세요.
