# 데이터로보는부동산 쇼츠

각 편에 처음 들어온 시청자가 무엇을 비교하는지 이해하고, 한 가지 답을 얻은 뒤 다음 영상을 선택할 수 있게 만든다. 적용 출발점은 해당 편의 최신 사용자 요청과 실제 기준 파일이다.

## 시작과 연결

- 영상 작업은 `hyperframes`를 먼저 읽는다. 구조는 `hyperframes-core`, 필요한 모션은 `hyperframes-animation`, 자료·음성은 `media-use`, 실제 영상 검수는 `video-review`를 사용한다. 필요한 기능만 읽고, 설치된 스킬을 매번 다시 설치하지 않는다.
- 프로젝트의 [제작 WORKFLOW](../../video-agent-studio/WORKFLOW.md)와 [마스터 가이드](../../video-agent-studio/guides/영상제작_마스터가이드.md)를 따른다. 현재 episode의 state·최신 타임록·팩트·예산을 확인한다. 이 스킬이나 참고 편의 통과 기록은 새 비용·게시의 승인을 부여하지 않는다.
- 대본과 읽기문에는 [자연스러운 표현·발음 가이드](../../video-agent-studio/guides/대본_자연스러운표현과_발음.md)를 적용한다.

## 정보와 화면을 함께 설계

1. **처음부터 주제와 범위.** 첫 화면에 순위의 기준과 이번 범위를 표시한다. 질문이나 핵심 대비로 열고 첫 순위로 연결한다. 본편을 잘라 갑자기 “15위는…”으로 시작하거나, 로고만 기다리는 시간을 늘리지 않는다. 도입의 정확한 길이는 내용과 실제 발화로 정한다.
2. **한 번에 현재 대상.** 지역 사진·큰 지역명/순위로 도착을 알린 다음, 설명하는 값의 비교로 초점을 옮긴다. 작은 전체 순위표·제목·거주 수·가격표를 늘 상시 표시하지 않는다. 채널의 Pretendard·크림·남색·파랑·금색을 계승하되 지역마다 같은 사진을 돌려 쓰지 않는다.
3. **말에 맞춰 실제 값 공개.** 금액·단지 수별 최초 발화 앵커를 따로 둔다. 실제 값에 비례하는 막대를 사용하고 완성 후 읽을 시간을 확보한다. 거래 중위값과 가격 구간별 단지 수를 구분한다. 이전 편의 숫자·지역·비율을 템플릿 기본값으로 복사하지 않는다.
4. **끝에서 답을 마무리.** 마지막 지역의 설명을 끝낸 뒤 다음 선택 하나를 분명하게 안내한다. 다른 순위편·본편의 정확한 범위를 보여주며, 실제 준비·게시·관련 영상 연결 상태와 안내 문구가 맞아야 한다. 마지막 음절과 다음 문장의 첫소리를 구분해 자르고, 발화 뒤 화면을 읽을 여백을 둔다.

## 가독성과 소스

- 9:16 화면 전체를 활용하고 핵심 글자만 최신 [안전영역 설정](../../config/vertical_video_safe_area.json)에서 보호한다. 대상 프로필을 명시하며 완성 화면 전체를 축소해 통과시키지 않는다.
- 큰 지역명·가격이 우선이다. 2026-11-04 예시의 지역명144px·가격88px은 출발점이며 모든 콘텐츠에 고정하는 규격이 아니다. 최소 글자 크기와 실제 글리프 경계·겹침·앱 UI 모사는 현재 프로필로 검증한다.
- 실제 사진은 장소·촬영 시점·권리·출처를 기록한다. 사진과 데이터의 역할을 나누고, 제작 내부 설명·반복 부정형 푸터를 화면에 넣지 않는다.
- 자막은 의미 단위로 나누고 숫자·단위·고유명사를 보호한다. 해당 편의 자막 모양을 유지하며 브랜드·마지막 무음 화면에는 빈 박스를 남기지 않는다.

## 제작과 검수

대표 도입·지역 진입·가격·마무리를 내부 검토한 뒤 전체로 확장한다. 자연스러운 연결은 연속 경계 프레임으로 확인하고, 숫자를 읽는 동안은 안정적으로 유지한다. 세부 구현과 검수 포인트는 [검증한 제작 패턴](references/production.md)을 읽는다.

제공자 정렬·파형·전사는 실제 청취와 구분한다. 소스 검사와 실제 MP4 검사도 구분한다. 실제 출력의 첫 프레임, 모든 지역, 긴 자막, 수치 등장, 전환 직전/직후, 마지막 발화와 유지 화면을 확인한다. 파일 해시로 입력·출력·검수·승인을 연결한다.

기존 Jun의 완결된 발화 재사용과 새 음성 생성을 구분한다. 바뀐 읽기문을 기존 음성에 맞는다고 가정하지 않는다. 새 생성은 해당 입력 버전과 예산 범위를 확인한 뒤 진행하고, 수정되지 않은 음성·사진·자료·검수는 재사용한다.

## 최신 자료를 참고할 때

최근 제작 방식 조사에는 공식 출처·게시일·실제 관찰 범위를 남긴다. 제작자 조언과 도구 기능 발표, 장르 통계, 우리 편집 선택을 구분한다. 기능이 발표됐다는 사실을 계정에서 사용 가능하거나 성과가 입증된 것으로 해석하지 않는다. 다음 편의 소재·시청 흐름에 맞는 원칙만 채택한다.
