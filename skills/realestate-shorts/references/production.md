# 재사용할 제작 패턴

## 기준 예시와 적용 범위

`video-agent-studio/episodes/newlywed-apartment-picks-20261101`의 `shorts-ui-v2-20261104`는 구조·코드·검수 방법의 예시다. 그 편의 지역·가격·거주 수·2024/2026 기준일·음성 예산은 다음 편의 기본값으로 사용하지 않는다.

- 설계·실제 Jun 타임록: `director/top20-split-v4/shorts-ui-v2-20261104/`
- 원생 HyperFrames: `editor/top20-split-v4/shorts-ui-v2-20261104/`
- 실제 출력·원본 대조 이미지: `outputs/top20-split-v4/shorts-ui-v2-20261104/`
- 독립 검수와 실제 인코딩 표본: `qa/top20-split-v4/shorts-ui-v2-20261104/`
- 공식 자료8개와 적용 해석: `research/shorts-ui-v2-20261104/research_packet.md`

이 예시는 화면 표본·타이밍·소스·디코드 검토를 통과한 로컬 검토본이다. 사용자 게시 승인, 전 구간 청취나 연속 시청을 대신하는 증거로 사용하지 않는다.

## 장면 구성

질문/범위 → 지역 도착 → 비교 값 공개 → 답의 마무리/후속 선택을 한 타임라인으로 구성한다. 각 지역에서 자료 사진을 바꾸고, 비교에 들어갈 때 큰 금액·막대를 드러낸다. 표본 수와 통계 정의를 그 값 가까이에 둔다. 사진·지도·도표가 필요한 역할을 나눠 맡게 한다.

기존 예시의 0.35초 사진 연결과 막대 진입은 초기 후보값이다. 실제 내레이션의 의미 경계와 읽을 시간을 우선한다. 사진과 수치가 움직인 뒤 안정적으로 정지하며, 숫자 최초 등장 전에 다음 값을 노출하지 않는다.

## 음성 재사용

1. 승인된 원본 문장 ID와 정확한 표시문·읽기문·원본 WAV를 매칭한다.
2. 제공자 정렬에서 첫/끝 발화 위치를 얻고 인접 문장의 실제 경계와 원음 여백을 확인한다.
3. 완결된 문장이나 의미 단위만 재사용한다. 단어를 억지로 이어 새 문장을 만들지 않는다.
4. 새 타임라인에 오디오를 배치하고 자막·가격·장면 앵커를 모두 새 시각으로 옮긴다.
5. 마지막 발화의 꼬리 무음까지 포함해 유지 시간을 계산한다. 여백을 중복 가산하지 않는다.

읽기문·발음 간격이 바뀐 경우 기존 음성으로 해결됐다고 기록하지 않는다. 새 생성이나 사용자 녹음에 맞춘 실제 타이밍이 필요하다.

## 출력에서 다시 볼 지점

- 첫 프레임의 주제·범위와 첫 발화. 전편 설명 없이도 이해되는지.
- 모든 지역의 도착/중간/가격 완성, 실제 비례와 값·단위·표본.
- 가장 긴 금액과 단지명, 위아래 획과 받침, 자막 외곽선·부모 마스크.
- 모든 전환의 직전/직후 및 연속 표본. 옛 지역명이나 숫자가 겹치지 않는지.
- 마지막 5~10초와 모든 음성 편집점. 마지막 음절·다음 문장 잔여음·갑작스러운 종료.
- 앱 UI 모사와 실제 글리프 경계. 전체 디코드·해상도/프레임/오디오 길이·마스터 신호 대조.

## Studio와 버전 보존

Studio를 열면 편집기 선택을 위한 `data-hf-id`가 HTML에 추가될 수 있다. 검수용 Studio를 열기 전에 정확한 렌더 입력을 버전 보존하는 것이 편하다. 이미 추가됐다면 선택 속성만 제거한 바이트가 기존 SHA와 정확히 같음을 확인하고 원본 입력 스냅샷을 보존한다. 다른 변경까지 정규화하거나 해시를 새 값으로 덮어 통과시키지 않는다.

편집 가능한 프로젝트와 실제 출력의 버전을 구분한다. 예시의 `director/.../archive_render_source.py`는 선택 속성만 달라졌을 때 정확한 원본을 보존한 구현 참고다. 사용자 편집은 새 버전으로 기록하며 기존 렌더·자막·검수 기록을 덮어쓰지 않는다.
