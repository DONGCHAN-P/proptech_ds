## 5. secrets.json 생성 (API 키 설정)

```powershell
# config\secrets.json 생성
$secrets = @{
    data_go_kr_service_key = "본인_공공데이터포털_서비스키_입력"
    kapt_service_key       = "본인_K-apt_서비스키_입력"
    slack_webhook          = ""
    MOCK_MODE              = $false
} | ConvertTo-Json
$secrets | Out-File -FilePath "config\secrets.json" -Encoding utf8
```

또는 `config\secrets.json` 파일을 직접 열어서 아래 내용으로 저장:

```json
{
  "data_go_kr_service_key": "여기에_공공데이터포털_서비스키",
  "kapt_service_key": "여기에_K-apt_서비스키",
  "slack_webhook": "",
  "MOCK_MODE": false
}
```

> **공공데이터포털 API 키 확인 방법**
> 1. https://data.go.kr 로그인
> 2. 마이페이지 → 인증키 발급현황
> 3. `아파트매매 실거래자료` 서비스키 복사
>
> K-apt 키는 같은 포털에서 `공동주택 단지정보` 서비스키 사용

def to_pyeong_bucket(area_m2: float) -> str:
    if area_m2 < 33:   return '10P'
    if area_m2 < 50:   return '15P'
    if area_m2 < 66:   return '20P'
    if area_m2 < 83:   return '25P'

def normalize_apt_name(name) -> str:
    if name is None:
        return ''
    s = str(name).strip()
    s = re.sub(r'\([^)]*\)', '', s)
    s = re.sub(r'\[[^\]]*\]', '', s)
    s = re.sub(r'\s+', '', s)
    s = re.sub(r'(?i)apt$', '아파트', s)
    s = s.replace('아파트아파트', '아파트')
    han2num = {'일':'1','이':'2','삼':'3','사':'4','오':'5',
               '육':'6','칠':'7','팔':'8','구':'9','십':'10'}
    for han, num in han2num.items():
        s = s.replace(han + '차', num + '차')
        s = s.replace(han + '단지', num + '단지')
    return s


def make_apt_id(legal_dong_code: str, apt_name: str, road_address: str = '') -> str:
    norm = normalize_apt_name(apt_name)
    addr = (road_address or '')[:30]
    raw = f'{legal_dong_code}|{norm}|{addr}'
    return hashlib.sha256(raw.encode('utf-8')).hexdigest()[:16]

## 11. 자주 발생하는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `ModuleNotFoundError: common` | sys.path 미설정 | 노트북 상단 경로 수정 |
| `FileNotFoundError: secrets.json` | config 폴더 경로 오류 | `common.py`의 BASE 경로 확인 |
| `UnicodeDecodeError` | XML/CSV 인코딩 | 파일 열 때 `encoding='utf-8'` 또는 `'cp949'` 명시 |
| `requests.exceptions.SSLError` | 공공API SSL 인증서 문제 | `verify=False` 임시 추가 (운영에선 인증서 설치 권장) |
| API 응답 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 키 미승인 또는 오타 | 공공데이터포털에서 API 신청 승인 대기 (1~2일) |
