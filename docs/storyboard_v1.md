| 형식 | PPT 해설(보이스오버) 영상 |

## 2. 디자인 가이드 (첨부 PDF 레퍼런스 기반)

### 컬러 팔레트
| 역할 | 컬러 | 사용처 |
|---|---|---|
| Background | `#000000` ~ `#0A0F12` (우상단 청록 그라데이션 글로우) | 모든 슬라이드 배경 |
| Accent 1 (라임/네온 그린) | `#C7F11D` | 핵심 수치, 강조 단어, 액션 컬러 |
| Accent 2 (네온 시안) | `#1FE2E8` | 헤더 좌측 막대, 서브 강조, 시안 라인 |
| Primary Text | `#FFFFFF` | 본문, 헤더 |
| Secondary Text | `#9BA3A8` | 보조 설명, 캡션 |
| Card Border / Divider | `#1A2226` / `#2A3338` | 카드 테두리, 구분선 |

### 타이포그래피
- **한글**: Pretendard / SUIT (Black, Bold, Medium 3종)
- **영문**: Inter / Helvetica Now (Black, Bold)
- 슬라이드 제목: 56~72pt Bold, 흰색
- 슬라이드 부제: 24~28pt Medium, 회색
- 핵심 수치: 120~180pt Black, 라임 그린
- 본문 캡션: 16~18pt Medium, 흰색

### 레이아웃 패턴
- 비율: 16:9 (2560x1440 또는 1920x1080)
- **좌상단 헤더 룰**: 시안 세로 막대 `|` + 두꺼운 흰색 제목 (모든 콘텐츠 슬라이드 공통)
- **카드형 박스**: 둥근 모서리(radius 16~20), 어두운 카드 배경(`#0F1518`), 시안 테두리 옵션
- **큰 수치 강조 슬라이드**: 좌측 라임 거대 수치 + 우측 시안 헤드라인 + 회색 본문 2~3줄
- **타임라인**: 점-선-점, 점은 시안 글로우 (정책 사이클 슬라이드용)
- **차트**:
  - 라인: 시안 그라데이션 면 채움
  - 도넛/바: 시안+라임+그레이 조합
  - 표: 헤더만 컬러, 행 사이 1px 구분선 (`#1A2226`)
- **포토 슬라이드**: 우측 풀블리드 사진 + 좌측 검정 그라데이션 마스크 위 카피

### 슬라이드 종류 3가지 템플릿
1. **콘텐츠형**: 좌상단 헤더 + 본문 (카드 또는 차트)
2. **카피형**: 풀 검정 + 중앙 거대 카피 (라임 또는 시안 강조 단어) + 짧은 라임 밑줄
3. **포토형**: 풀블리드 이미지 + 좌측 카피 오버레이

## 3. 슬라이드 구성 (14장)

### S1. 타이틀 — 카피형
- 상단 칩: `DATA REAL ESTATE EP.01`
- 메인 카피: **THE 18-YEAR DIVIDE**
- 라임 강조 라인: **18년의 명암**
- 서브: "2008년 그날 이후, 수도권 79개 시·구에 무슨 일이 있었나"
- 채널명 워터마크 우하단

### S2. 훅(Hook) — 카피형
- 검정 + 중앙 흰 카피: "당신의 동네는 어디에 있었습니까?"
- 라임 강조: "누군가는 6배, 누군가는 1.4배."
- 라임 밑줄
- **내레이션**: "오늘은 18년치 데이터를 한 화면에 펼쳐서, 수도권 아파트값이 어떻게 갈라졌는지 끝까지 보여드리겠습니다."

### S3. 이 영상에서 다루는 것 — 콘텐츠형 (카드 3개)
- 헤더: `EP.01 분석 설계`
- 카드 1 (라이프스타일 매핑 자리): **대상** — 수도권 79개 시·구
- 카드 2 (재무 자리): **지표** — 아파트 ㎡당 매매 실거래가
- 카드 3 (미래성장 자리): **기간** — 2008.01 → 2026.04 (18년 4개월)
- 푸터 캡션: "데이터 소스: 국토교통부 실거래가 공개시스템"

### S4. 수도권 평균 시계열 — 콘텐츠형 (라인 차트)
- 헤더: `수도권 평균 ㎡당 가격 (2008~2026)`
- 풀폭 시안 라인 차트, 면 채움 그라데이션
- 좌하단 시작점·우상단 끝점 라벨에 라임 수치
- 우측 사이드 카피: "**평균 X.X배**" (실제 분석 후 채움)

### S5. 18년의 사이클 — 콘텐츠형 (타임라인)
- 헤더: `금리·정책 충격 7개 구간`
- 타임라인: 2008 금융위기 / 2014 빚내서 집사 / 2017 8·2 / 2019 분상제 / 2020 6·17 / 2022 금리 인상 / 2024~ 정상화
- 각 구간 시안 점 + 라임 라벨, 하단에 짧은 캡션 1줄씩

### S6. 격차의 시각화 — 콘텐츠형 (히스토그램 또는 박스플롯)
- 헤더: `79개 시·구의 누적 상승률 분포`
- 가로축: 18년 누적 상승배수 (1.0x ~ 7.0x)
- 세로축: 시·구 개수
- 라임 강조: "**상하위 격차 X.X배**"
- 서브 카피: "평균만 보면 놓치는, '명암'의 정체"

### S7. 누가 가장 많이 올랐나 — 콘텐츠형 (TOP 10 표)
- 헤더: `TOP 10 — 18년간 가장 많이 오른 시·구`
- 표: 순위 / 시·구 / 2008년 ㎡당 / 2026년 ㎡당 / 누적 상승배수
- 상위 3행은 라임 하이라이트, 나머지는 시안 톤
- 우하단 캡션: "다음 3개 슬라이드에서 1·2·3위만 깊게 보겠습니다."

### S8. TOP 1 심층 — 콘텐츠형 (수치 강조 + 카드 3개)
- 헤더: `1위. [구 이름]` (분석 후 확정)
- 좌측 거대 수치 (예: **6.2x**) — 라임
- 우측 시안 헤드라인 + 본문
- 하단 키 팩터 카드 3개: 재개발 / 교통 / 일자리 (각 1줄)

### S9. TOP 2 심층 — S8와 동일 템플릿

### S10. TOP 3 심층 — S8와 동일 템플릿

### S11. 누가 가장 안 올랐나 — 콘텐츠형 (BOTTOM 10 표)
- 헤더: `BOTTOM 10 — 18년간 가장 적게 오른 시·구`
- 표 구조 S7과 동일, 하위 3행은 회색 강조

### S12. BOTTOM 1·2·3 심층 — 콘텐츠형 (한 슬라이드, 카드 3개)
- 헤더: `덜 오른 데에는 이유가 있다`
- 1·2·3위를 한 슬라이드에 카드 3개로 압축 (TOP은 각 슬라이드, BOTTOM은 통합 — 무게중심 차등)
- 각 카드: 시·구명 / 누적배수 / 핵심 원인 1줄

### S13. 양극화의 의미 — 카피형
- 검정 + 중앙: "18년 동안, 수도권은 한 시장이 아니었습니다."
- 라임 강조: "**그것은 79개의 다른 시장이었습니다.**"
- 라임 밑줄
- **내레이션**: 데이터가 알려주는 것 — 거시 평균은 거짓말을 한다, 지역 단위 의사결정의 중요성

### S14. 마무리 + 다음 편 예고 — 콘텐츠형
- 헤더: `다음 EP.02 예고`
- 좌측: 채널 구독 CTA (라임)
- 우측 카드 2개:
  - "EP.02 — 강남 3구 vs 노도강, 18년 격차의 진짜 이유"
  - "EP.03 — 경기도 신도시 성적표"
- 푸터: "데이터 출처: 국토교통부 실거래가 공개시스템 / 분석: 데이터로 보는 부동산"
