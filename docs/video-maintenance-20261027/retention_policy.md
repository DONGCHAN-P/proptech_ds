# 영상 작업 저장공간 정리 기준 — 2026-10-27

사용자 요청: “앞선 작업들에서 용량 차지하는거 삭제해줘. 앞으로 참고해야할 내용들 말고는 다 지우자.”

정리 대상은 이 프로젝트의 영상 제작 산출물과 재생성 가능한 영상 빌드 캐시다. 실거래 수집 데이터·다른 업무 자료·원본 대화·계정 및 자격증명·사용자 다운로드 원본은 대상에 넣지 않는다. 영상별 원천 조사·논문·분석 표·코드·대본·승인·출처·권리·검수 기록을 보존한다.

## 남기는 자료

- `config/current_video.json`, `config/video_style.json`, `config/video_shelf.json`, episode 상태와 실제 업로드·배포 기록이 가리키는 영상·자막·대본·썸네일. 원격 유튜브 영상이나 공개 상태는 변경하지 않는다.
- 최근 매매가격 계산 재제작본, 사용자 직접 녹음용 DOCX 보존본·48문단 원문·31장면/101개 앵커 설계·계산 근거와 가이드. 기존 매매·전세·월세 Jun 본편과 쇼츠, 신도시 편의 기준본을 보존한다.
- 원천/재사용 이미지·음악·클린 브랜드·실제 지도·공고·도면·폰트·음성 원본·정렬 데이터·전사 모델·설치된 실행 의존성.
- 최신 렌더 프로젝트가 실제로 읽는 파일은 경로가 과거 버전이나 `cache` 아래여도 보존한다. 창릉 최신 프로젝트가 참조하는 과거 캐시의 PNG 입력을 별도로 식별했다.
- 대표 실패 사례·수정 전후·핵심 화면·컨택트시트 및 장면 모음. 반복적인 프레임 시퀀스는 폴더별 처음·중간·끝 대표와 이름이 명시된 진단 이미지를 남긴다.
- 모든 승인·출처·검수 기록과 과거 정리 결과. 이번 보존/삭제 목록과 실제 실행 결과도 남긴다.

## 지우는 자료

- 위 보호 대상에 포함되지 않은 이전 본편/장별 중간 렌더 MP4.
- 현재 재현 입력으로 쓰지 않는 예전 렌더 캐시의 프레임·영상·PCM과 재생성 가능한 webpack 빌드 캐시.
- 대표 증거를 남긴 뒤 중복되는 인코딩 점검용 프레임 PNG/JPG 시퀀스.
- 원래 내레이션·음악·믹스 코드가 보존된 합성 중간 WAV·float PCM·신호 점검용 중간 오디오.
- 과거 렌더 번들의 중복 이미지·폰트는 안정된 원천 경로와 SHA-256이 같은 경우에만 삭제한다. 재사용 원본 경로와 같은 해시를 삭제 목록에 함께 기록한다. 편집 소스·현재 소스 패키지·음성 원본을 이 방법으로 정리하지 않는다.
- 과거 생성 번들의 JS source map처럼 원래 소스에서 재생성할 수 있는 산출물.

모르는 파일은 이름만 보고 지우지 않는다. 현재 작업과 사용 관계를 확인하고 위 범주로 분류할 수 있는 파일을 정리한다. 보존된 오래된 코드 전체의 즉시 실행 가능성을 약속하지 않으며, 최신 재현 입력을 우선 보존한다.

## 파일별 사전 목록과 실행 보호

`file_decisions.csv`는 조사한 모든 파일의 경로·크기·보존/삭제·이유를 담는다. `delete_manifest.json`은 삭제할 정확한 파일 경로와 크기·SHA-256을 고정하고, `protected_hashes.json`은 중요 보존 파일의 실행 전 해시를 기록한다. 목록에 없는 파일은 삭제하지 않는다.

삭제는 PowerShell에서 동일 셸의 `Remove-Item -LiteralPath`로 파일별 실행한다. 모든 절대 경로가 지정된 작업 영역 안에 있는지 먼저 확인한다. 폴더 재귀 삭제·다른 셸로 경로 전달·폴더 연결 추적은 하지 않는다. 실행 직전 파일 내용이 바뀌었거나 잠겨 있으면 건너뛰고 실패 목록에 남긴다.

`영상/<편명>/작업폴더` 연결은 탐색하지 않는다. 사용자용 하드링크와 원본의 사용 관계를 보존한다. 현재 실행 환경의 파일 ID 값이 제공되지 않아 파일 크기 합계를 물리 사용량으로 단정하지 않는다. 삭제한 논리 파일 크기와 드라이브 여유 공간의 관측 차이를 따로 기록한다.

## 증거와 검수 기록의 수명

원 검수 보고서는 과거에 어떤 입력·프레임을 확인했는지에 대한 기록으로 보존한다. 일부 원시 점검 프레임/중간 MP4가 삭제되어도 과거 검수의 관측 사실을 새 검수로 바꾸지 않는다. 이번 정리 기록에 삭제 경로·해시·남은 대표 증거를 연결하고, 각 episode에 보존 안내를 추가한다. 삭제된 원시 프레임 전체가 현재도 존재하거나, 과거 폐기본을 최신 MP4에서 그대로 복구할 수 있다고 안내하지 않는다.

완료 조건은 실제 삭제 결과·실패 목록·중요 보존 파일 해시·사용자 진입점의 존재를 확인하고, 마스터 가이드와 함께 짧은 결과 보고서를 제공하는 것이다.
