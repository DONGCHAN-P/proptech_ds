# YouTube 업로드 연결 테스트

연결 채널: 데이터로보는부동산 (`UCr_mTC0x_Uobv6MrIsOkrXw`). OAuth 동의 후 mine 조회로 일치 확인.

테스트 영상: `video/out/channel-intro-v2.mp4`만 업로드. 본편은 업로드하지 않았다.

- 영상: https://youtu.be/eii0aOQm3Jo
- 편집: https://studio.youtube.com/video/eii0aOQm3Jo/edit
- 제목: [업로드 테스트] 채널 공통 인트로 v2 · 5초
- MP4 H.264 + AAC,1920×1080,30fps,5.013초, 약3.9MB.
- 파일 전체 디코드 검사 및 주요 프레임 검토 완료. 실제 청취와 유튜브 플레이어 연속 재생 검증은 별도.
- 비공개 업로드. publishAt 없음, notifySubscribers=false.
- 아동용 콘텐츠 아님 설정 반영 확인.
- AI 가상 도심이라는 설명과 containsSyntheticMedia=true를 요청 본문에 포함. 조회 응답에는 합성 콘텐츠 플래그가 반환되지 않아 Studio 표시 여부는 미검증.
- 같은 인트로2초 장면을1280×720JPEG로 추출해 썸네일 설정 성공.
- processingStatus=succeeded, uploadStatus=processed, privacyStatus=private 확인.
- 중복 방지를 위한 업로드 기록: `video/out/youtube-test-upload.json`.
- 실행 스크립트: `analysis/youtube_test_upload.py`. 이 스크립트는 승인된 테스트 영상만 처리하며 임의 본편 업로더가 아니다.

## 본편 업로드 전에 확인할 항목

1. 인트로·아웃트로 최종 합본, 수정 시간에 맞춘 SRT·챕터. 내레이션 발음과 볼륨, 첫/끝 장면, 갑작스러운 화면전환 확인.
2. 제목·썸네일·설명과 실제 내용 일치. 가격 통계의 단지/지역, 면적, 기간, 중위/최고 기준과 출처 정리. 22.25억 기사 사례와 로컬 표본의 불일치 해소.
3. 실제 자료의 이용 조건과 AI 개념 풍경 구분. 실사풍 합성 콘텐츠의 Studio 표시 확인.
4. 게시 대상 채널ID, 비공개/공개/예약 및 시간대(Asia/Seoul), 시청자 설정 확인.
5. 썸네일 실제업로드 파일 크기·가독성, 제목과 설명, 출처링크. 지금 권한은 upload+readonly이므로 별도 자막 업로드 권한은 후속 작업에서 점검.
6. YouTube Studio에서 HD 처리, 저작권/제한 검사, 실제 재생 확인. API 처리 성공만으로 저작권 검사 통과를 판단하지 않는다.
7. 엔드스크린 실제 링크·구독 요소는 Studio에서 배치. 영상 내 사각형·원은 가이드일 뿐 클릭 요소가 아니다.
8. 공개 전 최종 검토. 현재 연결 검증은 비공개 업로드까지이며 공개·예약 게시 검증은 아직 수행하지 않았다.

OAuth 클라이언트/토큰은 config의 로컬 파일에만 보관하며 gitignore 처리한다. 토큰이나 클라이언트 보안 비밀번호는 보고서·출력에 넣지 않는다.
