# 2026-10-28 영상 작업 파일 정리 기준

사용자의 “고생했고 파일정리 한번 진행하자” 지시에 따른 후속 정리다. 2026-10-27 보존 기준과 현재 마스터 가이드·피드백 이력을 적용한다.

현재 공개된 매매가격계산 본편과 쇼츠 v5 두 편, 다른 편의 최종/현재 기준 영상, 대본·자막·썸네일, 원천·재사용 이미지/음악/지도/폰트/원음/정렬, 재현 코드와 직접 입력, 승인·출처·검수·업로드·삭제 기록을 보존한다. 이전 캐시나 영상이라도 최신 제작이 참조하면 보존한다. 쇼츠 잘림의 전후 대표와 컨택트시트도 남긴다.

검수용 중복 프레임은 그룹별 대표와 명시적 before/after/contact/preview를 보존한 뒤 정리한다. 원본이 남아 있고 현재 렌더가 읽지 않는 디코드·전사·신호분석 오디오, 폐기된 중간 렌더, 재생성 가능한 빌드·바이트코드 캐시를 선별한다. 설치된 전사 모델과 실행 의존성은 보존한다.

정리 범위는 프로젝트의 영상 제작 폴더와 명시된 영상 캐시다. 실거래/예측 데이터, 다른 업무, 원본 대화, 자격증명과 계정 파일은 제외한다. 원격 YouTube 상태는 변경하지 않는다. 사용자 진입점과 원본의 하드링크 관계를 보존하고 junction을 탐색하거나 재귀 삭제하지 않는다.

파일별 보존·삭제 CSV, 삭제 대상의 크기/SHA, 중요 보존 파일 해시를 삭제 전에 고정한다. PowerShell 한 셸에서 절대 경로와 모든 부모의 재분석 지점 여부를 검증하고, 파일을 하나씩 해시 확인 후 삭제한다. 변경·잠금 파일은 건너뛰며 성공·실패를 기록한다. 논리 삭제량과 드라이브 여유 공간 변화는 별도로 보고한다.
