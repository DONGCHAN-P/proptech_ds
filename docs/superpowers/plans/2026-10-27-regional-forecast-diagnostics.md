# 지역별 집값 예측 실패 진단 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 고정 예측의 실패 지역·국면을 분해하고 시차·학습 규칙의 기여, 자료 수집 우선순위와 범위 보정 대안을 검증한다.

**Architecture:** 이전 고정본을 읽는 별도 분석 폴더를 만든다. 예측과 정답을 동일 시점·지역에 맞추고, 오차 기여도·관측 가능한 입력 상태를 진단한다. 공식 임대차·공개본 조사와 제한된 예측 범위 실험을 병행하며 기존 모델과 발행본은 보존한다.

**Tech Stack:** Python 3.11, pandas, numpy, matplotlib, 기존 evaluation/forecast helpers, 오프라인 HTML.

**Spec:** 사용자가 승인한 개선 순서: 실패 구간 분석 → 입력 시점 검증 → 지역 수급자료 보강 → 지역·국면 모델 → 예측 범위 및 신규 결과 추적.

## Global Constraints

- 분석 기준일 2026-10-27; 기존 19개 채점 원점·6개월 목표·정답 성숙 3개월·공통 지역 유지.
- 최신 수정 자료에 의한 사후 분석이며 기존 평가 구간을 새 블라인드로 지칭하지 않는다.
- 2개월 가격 시차는 역사 최초 공개값 미검증 가정. 원인 진단의 특징 비교를 인과효과로 지칭하지 않는다.
- 점예측 교체 기준(균형 MAE 5% 개선·두 수준 비악화·p90 증가 10% 이내) 유지.
- 새 유료 API·원시 거래 외부 전송·자격증명 출력·기존 원본 변경 없음.
- 연구·진단은 새 버전 디렉터리에 저장. 공개본 확보 실패 시 가정과 결손을 기록하고 진단·실험을 계속한다.

## Review Focus

1. 채점 불가 행과 모델별 누락을 숨기지 않고 공통 평가 대상을 유지한다.
2. 오차 기여 가중치 합과 균형 MAE가 일치한다. 시군구별 실제 행을 보존한다.
3. 시차와 학습 규칙의 네 조합 및 fallback 라우팅을 구분한다. 학습 규칙은 시작 연도 차이도 포함한다.
4. 미래 가격이나 미성숙 잔차가 진단용 입력 태그·실제 범위 보정에 들어가지 않는다.
5. 범위 대안은 같은 예측값을 유지하며 포함률·폭·구간점수를 함께 평가한다.
