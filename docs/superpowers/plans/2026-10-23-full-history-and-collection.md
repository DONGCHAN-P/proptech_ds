# 2006년 이후 전체 이력 분석과 추가 수집

사용자 승인 범위: 지역별 대본의 비교 기간을 2006년 이후 수집 가능한 전체 기간으로 넓히고 아파트 매매 실거래 추가 수집을 진행한다. 기존 원자료·대본 v1/v2·영상은 보존한다.

1. 기존 7개 지역의 전체 분기 경로에서 누적 변화·복리 연환산·전 기간 고점·하락/회복 에피소드를 다시 계산한다. 세종은 확인된 연속 자료인 2015년부터 표시한다. 기존 가격 지수는 매칭 표본이며 전체 유효 거래 건수와 구분한다.
2. 광주 전 기간 0건 응답은 원인부터 확인한다. 2026년 행정구역 코드 개편의 공식 원첨부를 확보하고, 현재 코드와 과거 코드로 같은 월을 소수 재조회한다. 정상 응답을 확인한 코드만 본수집에 넣는다.
3. 광주 보완 → 울산 → 충청권 순으로 200601~202609 추가 수집한다. 기존 수집기·원본 저장·페이지 건수 대조·재개 기능을 재사용하며 새 저장 폴더와 공유 일일 호출 장부를 쓴다. 알려진 호출을 포함해 하루 8,000회를 상한으로 두고, 실제 서버 한도/인증/네트워크 오류에는 중단한다. 계정 전체의 다른 호출량은 미확인이다.
4. 원본은 덮어쓰지 않고 코드 변경 증거와 파일 해시를 남긴다. 무거래 월과 잘못된 코드의 전 기간 0건을 구분한다. 완료된 지역만 후속 분석에 반영하며 수집 중 자료를 완료로 표시하지 않는다.
5. 전체 기간 결과를 대본 v3·자료화면 설계에 반영하고 짧은 경로를 갱신한다. 분석 알고리즘·표본/기간·차트와 대본을 검수한다. 유료 음성·영상 생성이나 업로드는 시작하지 않는다.

검증: 회복 에피소드의 최초 재도달·미회복 검열 테스트, 출처 해시, 수집 파일/페이지/totalCount 일치, 프로세스 실제 생존과 상태 갱신, 자격증명 비출력, 최종 대본의 현재 버전·경로 대조.
