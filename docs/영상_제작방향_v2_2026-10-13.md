작성: 2026-10-13. 사용자 피드백 반영. 기존 타임코드는 요구사항의 위치를 설명하는 참조이며 새 영상의 확정 시간표가 아니다.

## 기준
Jun / eleven_v4 및 첨부 대본의 서사를 유지한다. 기존 도입 파일럿의 문자 위주 화면을 실제 지도·사진·데이터 비교로 보강한다. 원문보다 강한 인과 주장이나 임의 수치를 만들지 않는다.
AI 개념 도시 영상은 분위기 보조에만 사용한다. 지역·아파트·기관 설명에는 실제 위치와 실제 소재를 우선한다.

## 지도 확보 결과
실제 OpenStreetMap 도로·지형 지도 12개 타일을 한 번 내려받아 로컬 캐시했다.
검수 이미지: video/out/real-map-v2.png
타일·대표 위치·출처: video/public/maps-v2/map.json 및 PNG
렌더 소스: video/src/RealMapV2.tsx
서울·광교 중심권·동탄역 일대 핀은 지역 대표 위치다. 개별 단지·출입구 위치나 도시 경계를 뜻하지 않는다. 단지 장면에서는 주소에 맞춘 상세 좌표를 별도로 확인한다.
출처 표기는 화면에 유지: © OpenStreetMap contributors / openstreetmap.org/copyright.
캐시를 사용해 같은 타일을 프레임마다 다시 요청하지 않는다. 기본 지도 확보에 추가 API 키는 필요하지 않다.
OSM 지도는 항공사진이 아니다. 호수공원 상공뷰는 별도 상세 소재로 확보한다.

## 지도 확장 순서
1. 실제 기본 지도와 출처 표시, 지역 대표 위치 핀으로 위치 설명.
2. 광교·동탄 상세 지도에 역·주거·기관·사업장·공원 레이어를 분리.
3. 공원 상공뷰: 수원시 항공·드론 공개자료의 이용조건 확인 → 기존 VWorld 설정으로 영상지도 사용 가능 여부 확인 → 부족하면 Google Maps Static API의 satellite를 검토.
4. Google Cloud TTS 활성화와 Maps 사용 설정·결제·키는 별개다. 필요한 지도가 정해지기 전에는 Maps 결제를 추가하지 않는다.
5. 카카오·Google 캡처 사용 시 각 서비스의 표시·이용조건을 확인하고 지도 제공자 로고·크레딧을 보존한다. 출처 한 줄만 적으면 모든 이미지 사용이 허용된다는 뜻은 아니다.

## 화면·모션 규칙
- 지역 설명은 지도가 주연. 범위와 위치를 먼저 보여주고 사진으로 연결한다.
- 근거 장면은 실제 소재나 비교 차트가 주연. 큰 제목만으로 화면을 채우지 않는다.
- 본문 전체를 scale하지 않는다. 제목·자막·출처는 고정 레이어.
- 확대가 필요하면 지도/사진을 별도 클리핑 컨테이너 안에서만 움직인다. 핀·라벨은 가독성을 유지.
- 아이콘 왼쪽, 요약 3줄 오른쪽. 각 줄은 짧은 제목+구체 근거.
- 광교/동탄/비교 지역 색상을 고정. 상승·하락 표시와 지역 색상을 혼동하지 않는다.
- 표본 수·기간·단위를 화면에 표시하되 작은 기술 설명으로 시청을 방해하지 않는다.
- 데이터 로딩·계산을 렌더 프레임에서 반복하지 않는다. 데이터를 JSON으로 준비한 뒤 모션 값만 계산한다.
- 이미지 반복은 연속 장면에서 피하고 지도→사진→비교 차트→요약으로 시각 리듬을 만든다.
- 1080p 기준 제목·자막·출처가 안전영역 안에 있고 모바일에서도 읽히는지 확인.
