# 나는야 투자왕 · 로컬 알파 0.1

2006-Q4부터 2026-Q3까지 80분기를 플레이하는 투자·인생 시뮬레이션의 첫 구현입니다. **시세·임금·사건·거래 수수료는 MOCK/게임용 가설이며 실제 역사 가격을 재현하지 않습니다.** 원본 기획 문서는 `docs/`에 그대로 보관했습니다.

## 실행

Node.js 24 이상에서 실행합니다. 게임 실행에는 외부 API·데이터베이스·npm 설치가 필요하지 않습니다.

```powershell
cd C:\projects\realestate_reco\investment-king
npm.cmd start
```

브라우저에서 http://127.0.0.1:3210 을 엽니다. 또는 `start-game.cmd`를 실행합니다. 포트는 `INVESTMENT_KING_PORT` 환경변수로 변경할 수 있습니다.

## 플레이

1. 시드를 입력하고 시작합니다. 20세, 현금 100만 원, 가족 동거로 시작합니다.
2. 한 분기 최대 3개 행동을 순서대로 선택합니다. 같은 행동은 2번까지 가능합니다.
3. 투자 탭에서 매수·매도를 예약합니다. 매수 한도는 수수료를 포함한 최대 지출액이며, 체결가가 한도를 넘으면 주문을 거부합니다.
4. `다음 3개월`에서 지출·예약액을 확인하고 확정합니다. 월별 수입과 생활비가 반영됩니다.
5. 80분기 뒤 엔딩·자산 그래프·이전 회차 비교·SVG 카드 저장을 사용할 수 있습니다.

월 생활비는 15만 원, 알바 1회 수입은 40만 원입니다. 알바 1회만 매번 하면 생활비보다 수입이 적습니다. 초반에는 알바·공부를 조합해 취업 경로를 준비하거나 알바 2회로 생활비를 확보할 수 있습니다. 취업 지원은 직무능력 30부터 가능하며, 합격 분기의 두 번째 달부터 급여가 발생합니다.

분기 확정 전 행동·주문 예약은 저장하지 않습니다. 확정된 회차·원장·행동 로그는 `runtime/saves/`에 저장하며, 브라우저에는 회차 ID와 응답이 불확실한 정산의 재시도 요청만 보관합니다. 재접속용 주소 `/?run=회차ID`를 보관하면 같은 PC의 저장을 이어갈 수 있습니다. 새 인생을 시작해도 기존 저장은 삭제하지 않습니다. 데이터 파일은 별도로 백업할 수 있습니다.

## 검증

```powershell
npm.cmd test
npm.cmd run simulate
# 개발 의존성 설치 후 추가 검사
npm.cmd ci
npm.cmd run typecheck
npm.cmd run test:browser
```

브라우저 테스트에는 설치된 Chrome을 사용합니다. `reports/`에 1,000시드 결과와 데스크톱·모바일 화면 캡처가 있습니다. 봇 검증은 **단일 근로·인생균형 정책**의 안정성 검사이며 전체 7개 전략 비교나 출시 밸런스 검증이 아닙니다.

## 구현 범위

- 구현: 80턴, 6개 인생 행동, 원화/수량 고정 정밀도, 현금·자산·미납 원장, 3개 가상 자산 거래, 개인 시드 사건, 기억 2~5장, 점수·엔딩, 원자적 파일 저장과 멱등 커밋, 반응형 웹 UI.
- 미구현: 실측 역사 데이터 ETL·라이선스 검증, 주식 6종과 기업행위/환율, 예적금 계약, 부동산·전월세·대출, 정식 역사 15개/개인 25개 사건·선택지, 관계·가족의 상세 상태 전이, 계정·PostgreSQL·공식 랭킹·배포.
- BTC/ETH/KRX 금은 실제 접근 시점과 데이터가 검증되지 않아 매매를 차단합니다. 등장 이전에는 공개 장터에 표시하지 않습니다.
- 서버는 127.0.0.1에만 바인딩합니다. 단일 로컬 프로세스용 파일 저장이며, 인터넷 공개·다중 서버 운영 전에는 DB 트랜잭션과 인증을 구현해야 합니다.

상세 상태와 후속 작업은 [구현 현황](docs/IMPLEMENTATION_STATUS.md)을 참고하세요.
