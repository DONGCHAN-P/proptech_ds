# 구현 현황 · 2026-10-29

## 범위와 결정

사용자가 4개 기획 문서를 제공한 뒤 별도 `investment-king/` 폴더에서 MOCK 80턴 엔진과 로컬 웹 플레이를 바로 구현하는 방식을 선택했습니다. 전체 상용 MVP 완료를 뜻하지 않습니다. 기존 부동산 서비스 코드는 수정하지 않았습니다.

기술 선택: 서버 정산은 순수 TypeScript, Node 24 기본 HTTP 서버, 원자적 JSON 파일 저장, 브라우저 HTML/CSS/JS. 외부 런타임 패키지 없이 실행할 수 있도록 첫 알파에서 Next.js/PostgreSQL을 보류했습니다. 운영판 전환 시 API/엔진 계약을 유지한 채 교체할 수 있습니다. 다운로드 원본 4개는 `docs/`에 보존했습니다.

## 실제 확인한 범위

- 엔진/API 테스트 15개 통과: 정확한 80턴 종료, 입력 불변성, 동일 시드/선택 재현, AP와 반복 제한, 원장 대차 균형, 정수 현금/고정 소수 수량, 미납/회복, 수수료/예약 한도, 무가격/무유동성 체결 차단, 시점 이전 자산 차단과 장터 비공개, 미래 시세 비공개, 상태 버전 충돌, 재접속·중복·동시 요청·특수 ID 재시도.
- TypeScript strict 타입 검사와 브라우저 JS 문법 검사 통과.
- 실제 Chrome 자동화 4개 통과: 데스크톱 1440px와 모바일 390px 각각 시작→행동 예약→매수→정산→새로고침 복원→80턴 엔딩→SVG 카드 다운로드, 느린 주문 검증 중 정산 차단. 브라우저 JS 오류 0, 검사한 대시보드 가로 넘침 없음.
- 데스크톱·모바일 대시보드 전체 캡처를 직접 열어 배치와 가독성을 확인했습니다. 캡처는 `reports/screenshots/`에 있습니다. 모든 화면/해상도/보조기술에 대한 전면 접근성 검수는 아닙니다.
- 1,000개 고정 시드 단일 균형 정책 봇: 1,000/1,000 완주, 종료 미납 0. 매 턴 음수 현금과 원장 불일치 검사. 결과는 `reports/balanced-policy-summary.json` 및 시드별 상세 파일에 기록했습니다.

## 경제·데이터의 현재 한계

봇 순자산 P10/P50/P90은 약 3.13/3.21/3.22억 원, 삶 점수는 모두 95입니다. 삶 지표가 포화되는 현상이므로 재미·전략 다양성 검증은 통과했다고 볼 수 없습니다. 원본 밸런스 JSON을 임의로 조정하지 않고 현상을 기록했습니다. 급여는 취업 시 `1,200,000 + 반올림(직무능력) × 10,000`원이라는 가상 규칙이며 이후 자동 승진·연봉 상승은 없습니다.

분기 가격은 인공 곡선, 체결일은 주말을 제외한 가상 세션입니다. 실제 거래소 휴장일·원천 데이터·당시 세제·호가 스프레드/별도 슬리피지·배당·분할·환율·CPI는 구현하지 않았습니다. 주식처럼 보이는 A/B는 실존 종목이 아니며 금도 가상 자산입니다. 개인 사건은 선물·수리·친구 연락의 3개 테스트 사건과 취업 결과이며 정식 40개 콘텐츠가 아닙니다.

가족 동거와 미혼·무자녀를 유지하는 경로가 기본이며 결혼·출산 여부는 점수 계산에 쓰지 않습니다. 관계 행동은 관계/행복 지표에 반영되지만 파트너·자녀 선택 플로우는 아직 없습니다. 주거는 가족 동거만 지원합니다. 자유 지수는 현재 구현된 유동성·미납만 반영하며 지속적 비근로소득 상품/대출은 미구현입니다. 부동산 탭과 역사 뉴스는 후속 개발 상태로 명시했습니다.
