# 나는야 투자왕 v1.0 — 개발 착수 가이드

## 파일 구성

1. `PRD_v1.0.md` — 제품 정의, 사용자 경험, P0~P2 기능 범위, 수용 기준, 분석 KPI, 데이터 리스크.
2. `GAME_SYSTEM_SPEC_v1.0.md` — 턴 엔진, 상태/경제 수식, 투자·부동산·직업·가족·이벤트, API, DB 스키마, QA 테스트.
3. `BALANCE_CONFIG_v1.0.json` — 프로토타입 초기 수치. **역사적 사실값이 아닌 게임 밸런스 가설.**

## 확정된 게임 사양

- 2006-Q4 시작, 2026-Q3 마지막 턴, 총 80턴(1턴=3개월).
- 시작 나이 20세, 현금 1,000,000원, 기본 가족 동거, 무직.
- 미래 기억 일부(`FRAGMENT`), 부와 인생의 균형을 최우선으로 평가.
- 시장 시계열은 실제 자료를 우선하고, 개인 운과 이벤트는 동일 시드에서 결정론적으로 재현.

## 구현 최우선 순서

1. 80턴 인덱스 달력과 상태머신/불변조건.
2. 원화 원장, 현금흐름, AP 3개/턴.
3. 가상의 **테스트 픽스처**로 매매·수익률·시장 상태 처리(실제 역사인 척 금지).
4. 실제 데이터 확보 및 `as_of` 누출 차단.
5. 직업·공부·건강·관계·부동산·이벤트 시스템 결합.
6. 대시보드·분기 정산·엔딩·회차 비교 UI.
7. 1,000시드 봇 검증 + 라이선스/상업 이용 점검 후 공개.

## 코딩 에이전트용 구현 시작 프롬프트

> 이 저장소의 `PRD_v1.0.md`, `GAME_SYSTEM_SPEC_v1.0.md`, `BALANCE_CONFIG_v1.0.json`을 단일 진실 원본으로 읽어라. 2006Q4~2026Q3의 80턴을 정확히 진행하는 결정론적 TypeScript headless simulator를 먼저 구현하라. 거래 수수료·현금원장·행동력·개인 시드 RNG·데이터 시점 보안을 구현하고, 80턴 완주/동일 seed 재현/중복 커밋 금지/BTC 2006 매수 금지/마이너스 현금 매수 금지의 단위 테스트를 포함하라. 시세가 확보되지 않은 구간에서는 `MOCK` 테스트 픽스처를 명시적으로 사용하고 실제 역사 데이터로 표시하지 마라. UI 작업은 headless 엔진 테스트가 통과한 다음 진행하라.

## 선결 제약

- KRX 공식 Open API가 2010년 이후 일반 시세부터 제공하므로 2006~2009년 종목 이력은 별도 검증 필요.
- 비트코인은 2009년 네트워크가 생겼다고 바로 거래 가능한 것으로 취급하면 안 됨.
- 2014-03-24 이전에는 KRX 금시장 거래 불가. 이더리움은 2015-07-30 메인넷 이전 거래 불가.
- 시세·실거래 자료별 재배포 및 상업적 이용 조건 확인 후 출시.
