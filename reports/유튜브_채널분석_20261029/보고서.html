지금 데이터가 말해 주는 것

최신 예산 본편과 매매·전세·월세편은 Analytics 처리 기간 뒤에 게시됐다. 이번 보고서의 강한 결론은 기존 지역 영상에 관한 것이며 새 주제의 성패 판정은 보류한다.

01

채널의 주력은 지역을 콕 집은 검색형 분석이다.

본편 검색 유입은 1,625회로 본편 조회수의 51.3%다. 시청시간에서는 4,479분, 75.5%를 차지한다. 검색어 상위에는 ‘창릉신도시’ 456회, ‘창릉’ 385회, ‘왕숙’ 182회가 보인다.

실행 지역명 + 시청자의 선택을 제목 앞에 둔다. 예: ‘창릉 S1·S4·S5, 내 예산으로 고르면?’ 지도·가격·입주 시점을 연결하는 기존 강점을 살린다. 검색어 표는 상위 25개 부분집합이다.

02

조회수를 만드는 쇼츠와 시간을 만드는 본편의 역할을 나눠야 한다.

쇼츠는 기간 조회수의 62.5%지만 시청시간은 10.4%다. 본편은 반대로 시청시간의 89.6%를 만든다. 창릉·왕숙 두 본편이 합쳐 전체 시청시간의 77.0%를 차지한다.

실행 쇼츠는 한 질문에 한 답을 주고, 본편은 선택 근거를 완성한다. 쇼츠 조회수 대비 본편 조회수를 전환율로 계산하지 않는다. 같은 시청자의 이동 경로는 이번 자료에서 확인되지 않는다.

03

구체적인 반문이 목록형 설명보다 강한 후보로 보인다.

‘GTX만 생기면 신도시 가격도 같아질까?’는 평균 시청비율 122.6%, ‘수도권 부동산 시장을 데이터로 시각화하면?’은 100.0%다. ‘신도시 청약 전, 이 5가지’는 22.1%, ‘왕숙 교통 시차’는 27.1%였다. 다만 GTX 쇼츠의 참여 조회수는 96회, 체크리스트는 33회다.

실행 새 쇼츠는 ‘정보 5가지’보다 ‘당연해 보이는 계산이 달라지는 이유’ 한 가지로 만든다. 100% 초과는 재시청 등이 섞인 구간/재생 비율이며 완주한 사람의 비율로 읽지 않는다. 제목 효과와 편집 효과는 아직 분리되지 않았다.

04

가장 먼저 손댈 편집 지점은 본편 시작 30초다.

약 30초에 가장 가까운 유지율 표본은 창릉 34.0초 64.2%, 왕숙 28.0초 69.5%, 교산 32.3초 68.6%, 광교·동탄 31.8초 38.1%다. 광교·동탄은 19.1초 68.0%에서 31.8초 38.1%로 내려간다.

실행 첫 3초에 질문, 10초 안에 지도나 비교 결과 일부, 30초 안에 첫 근거를 보여준다. 이탈 구간의 원인은 해당 영상의 실제 대사·화면과 대조해 후속 검증한다. 이 보고서는 유지율만으로 특정 장면을 원인이라고 단정하지 않는다.

05

같은 게시 초기 기간에서도 창릉의 시청시간이 두드러졌다.

게시일과 다음 이틀을 합친 API 보고일 3개에서 창릉 본편은 573회·1,317분, 왕숙은 134회·292분, 교산은 201회·264분, 광교·동탄은 198회·96분이다. 누적 노출 기간 차이만으로 창릉의 우위를 설명하기 어렵다.

실행 창릉의 ‘후보를 좁혀 주는 비교’ 구성을 다음 지역편의 우선 가설로 삼는다. 게시 시간·수요·유입의 차이는 남아 있다. 이 비교는 달력 보고일 기준이며 정확한 첫 72시간 비교가 아니다.

06

모바일 가독성이 우선이고, 본편은 TV 시청도 챙겨야 한다.

기기별 표에서 쇼츠 모바일 조회는 4,721회로 형식 합계 대비 89.5%다. 본편은 모바일 2,191회, TV 214회다. TV는 조회수의 6.8%이지만 시청시간의 21.1%를 만든다.

실행 쇼츠는 큰 숫자와 하나의 시선 초점을 유지한다. 본편 지도·출처는 TV에서도 읽을 크기를 확보한다. 기기 표와 형식 합계는 개인정보 보호·집계 처리 등의 영향으로 일부 불일치할 수 있어 비율의 분모를 명시했다.

07

왕숙은 구독 기여 신호가 있지만 표본은 작다.

왕숙 본편의 영상 시청 페이지에서 구독 5건이 기록됐다. 창릉 1건, 광교·동탄 1건과 대비된다. 왕숙의 참여 조회수 471회 대비 1,000회당 약 10.6건이다. 전체 채널 구독 증가는 12건이며 영상별 합계와 같을 필요가 없다.

실행 구독 CTA는 ‘다음에 무엇을 해결해 주는가’와 연결한다. 신규 채널의 5건 차이로 주제의 장기 구독 효과를 확정하지 않는다. 영상별 지표는 해당 영상 시청 페이지에서 발생한 구독만 포함한다.

08

새 예산 영상과 매매·전세·월세편의 성패는 아직 판단할 수 없다.

Analytics의 조회수만 요청한 경우와 시청 지표를 함께 요청한 경우 모두 마지막 반환일이 10월 25일이었다. 10월 26일 공개한 매매·전세·월세편과 10월 28일 공개한 예산 본편·새 쇼츠는 그 이후다. Data API 현재 누적 수치는 별도 표에서만 제공한다.

실행 두 신규 주제를 기존 지역 영상보다 약하다고 판정하지 않는다. 실제 처리된 보고일이 늘면 같은 게시 후 보고일로 다시 비교한다. 최신 영상의 CTR·유지율·유입은 빈칸을 유지한다.

  5. 평균 시청시간·비율은 API 반환값을 그대로 사용했다. 조회수×평균 시청시간으로 시청시간을 재계산하거나 단순 영상 평균으로 채널 평균을 만들지 않았다.
  6. 유지율은 elapsedVideoTimeRatio 1% 간격의 표본이다. 약 30초 비교는 실제 표본 시간을 함께 표시했다. audienceWatchRatio는 재시청을 포함해 100%를 넘을 수 있으며 개별 시청자의 생존 확률로 단정하지 않는다.
  7. 초기 성과는 게시일의 Pacific 날짜와 다음 이틀을 합친 3개 보고일이다. 각 영상의 게시 시각이 달라 정확한 72시간 길이는 같지 않다. 아직 세 보고일이 확보되지 않은 영상은 제외했다.
  8. 총 31개 확장 요청 중 왕숙 교통 시차 쇼츠(ETXkCHF4Si0)의 유지율 1개만 HTTP 500으로 수집되지 않았다. 자동 재시도는 하지 않았고 원본 오류 상태를 보존했다. 나머지 확장 요청 30개는 성공했다.
  9. 썸네일 노출수·CTR·쇼츠의 시청함/스와이프 비율은 이번 수집에서 확보하지 않았다. 카드 CTR·광고 노출수를 썸네일 지표로 대체하지 않았다. 검색 상위 25개 행은 전체 검색 유입이 아니다.
  10. 조회수와 제목의 연관은 기술 통계다. 동일 시청자의 쇼츠→본편 이동, 업로드 시간의 인과 효과, 추천 시스템의 평가 원인은 이번 데이터만으로 식별하지 않았다.
  11. 영상별 구독 증가 지표는 영상 시청 페이지 발생분만 포함한다. 기간 채널 구독 증가 12건과 현재 구독자 19명 및 영상별 증가 합계는 서로 다른 집계다.
  12. 보고서는 소유자 Analytics를 포함하므로 로컬 보관한다. Claude 협업 자료에는 공개된 제목·누적 조회수·참고 영상 관찰·새 제작안만 전달하고 비공개 Analytics 응답은 제외한다.
