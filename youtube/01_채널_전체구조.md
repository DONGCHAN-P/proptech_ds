# 부동산 데이터 분석 유튜브 — 채널 전체 구조

> 한 줄 정체성: **"감이 아니라 확률로 보는 부동산 — 예측하고, 공개하고, 틀리면 배운다"**

---

## 1. 핵심 전략: 2엔진 구조

채널은 성격이 정반대인 두 엔진으로 굴러간다. 둘을 섞지 말고 역할을 분리하는 것이 핵심이다.

| 구분 | 쇼츠 D (이상 거래 탐지) | 롱폼 C (예측 검증) |
|------|------------------------|---------------------|
| 역할 | 유입·발견 엔진 (깔때기 최상단) | 신뢰·전환 엔진 (해자) |
| 성격 | 소모형 / 속보형 | 누적형 / 서사형 |
| 후크 | "○○동 한 달 만에 3억 급등?!" | "작년 예측, 데이터로 채점합니다" |
| 제작 부담 | 낮음 (파이프라인 자동 발굴) | 높음 (모델 운영 + 추적) |
| 화제성 | 높음 | 낮음~중간 |
| 복제 난이도 | 중간 | 매우 높음 |
| 빈도 | 주 2~3편 | 주 1편 (격주 가능) |

```
[쇼츠 D: 이상거래 발굴] ──연결고리──▶ [롱폼 C: 모델 예측 + 정직한 회고]
      유입 엔진                              신뢰 엔진(해자)
         │                                       │
   "발견했다"                            "예측하고, 검증하고, 배운다"
         └──────────── 하나의 서사 ───────────────┘
```

---

## 2. 가장 중요한 성공 조건: 두 포맷을 잇는 다리

쇼츠 시청자와 롱폼 시청자는 **겹치지 않을 위험이 크다.** 쇼츠가 100만 조회가 나도 롱폼 구독 전환이 안 되는 것이 유튜브의 고질병이다. 따라서 둘을 하나의 서사로 묶는 명시적 연결 고리가 반드시 필요하다.

- **쇼츠 → 롱폼:** 쇼츠 D 마지막에 "이 단지가 왜 튀었는지, 앞으로 어떻게 될지는 이번 주 롱폼에서 모델로 분석합니다."
- **롱폼 → 쇼츠:** 롱폼 C 안에서 "지난주 쇼츠에서 발견한 그 이상 거래, 기억하시죠? 그게 이번 예측의 출발점이었습니다."
- **소재 흐름:** D에서 발굴한 이상치를 C의 예측 소재로 그대로 승계한다. 발견 → 추론 → 검증이 한 줄로 이어진다.

---

## 3. 포지셔닝: "맞히는 채널"이 아니라 "배우는 채널"

이것이 시장의 모든 부동산 유튜버와 갈리는 지점이다.

| | 맞히는 채널 (기존) | 배우는 채널 (우리) |
|--|-------------------|---------------------|
| 예측이 맞으면 | 신뢰 상승 | 신뢰 상승 |
| 예측이 틀리면 | **신뢰 붕괴, 영상 삭제** | **회고 콘텐츠로 전환, 신뢰 상승** |

틀린 예측을 "이런 변수 때문에 빗나갔고, 모델 고도화에 반영하겠다"는 공개 회고로 만든다. 일반 부동산 유튜버는 절대 못 하는 방식이며, 데이터 분석가의 실제 일하는 방식 그 자체다. 복제 불가능한 차별점이 여기서 나온다.

### 안전장치: 점추정 금지, 구간·확률로만 말한다

"변수 때문에 틀렸다"가 반복되면 "맨날 핑계 대네"로 보인다. 이를 막는 유일한 방법은 처음부터 확신을 단언하지 않는 것이다.

- ❌ "이 단지는 1년 뒤 12억 간다"
- ✅ "1년 뒤 12억 ± 1.5억, 상승 확률 65%"

확률로 말하면 틀려도 "확률 범위 안이었다" 또는 "예외 케이스를 학습했다"로 자연스럽게 수습된다. **확신을 단언하면 회고가 변명이 되고, 확률로 말하면 회고가 전문성이 된다.**

## 4. 운영 배분 (주 단위)

| 포맷 | 빈도 | 1편당 소요(목표) | 핵심 산출물 |
|------|------|------------------|-------------|
| 쇼츠 D | 주 2~3편 | 30분~1시간 (편집 위주) | 이상 거래 1건 발굴·시각화 |
| 롱폼 C | 주 1편 | 수 시간 (모델 + 대본 + 편집) | 단지/지역 예측 + 과거 예측 회고 |

쇼츠 D는 anomaly detection 파이프라인이 소재를 자동 생성하므로, "발굴된 이상치 중 가장 흥미로운 것 고르기 + 편집"만으로 완성된다. 시간 대부분은 롱폼 C에 투자한다. C가 진짜 해자이기 때문이다.

## 5. 콘텐츠 피라미드

```
        ┌─────────────────────────┐
        │  월 1회: 지역 심층 리포트   │  ← 분기 트래픽·권위 (롱폼 확장판)
        ├─────────────────────────┤
        │  주 1회: 예측 + 회고 롱폼   │  ← 신뢰·구독 전환 (C, 본진)
        ├─────────────────────────┤
        │  주 2~3회: 이상거래 쇼츠    │  ← 유입·발견 (D, 깔때기)
        └─────────────────────────┘
```

## 6. Pre-Mortem (실패 시나리오와 대응)

| 시나리오 | 발생 가능성 | 증상 | 대응 |
|----------|------------|------|------|
| 정확하지만 지루해서 망함 | **높음** | 차트만 띄우고 나레이션 → 15초 이탈 폭증 | 모든 영상에 "통념 반박" 또는 "검증 결과" 내러티브 갈고리 의무화 |
| 회고가 변명으로 보임 | 중간 | "맨날 핑계 대네" 댓글 | 점추정 폐기, 구간·확률 전면화 |
| 쇼츠·롱폼 시청자 단절 | 중간 | 쇼츠 조회수 高 / 구독 전환 低 | 두 포맷 연결 고리 강제 (섹션 2) |
| 예측 틀려서 신뢰 붕괴 | 낮음 (대응 시) | 1회 오차로 채널 신뢰 타격 | "배우는 채널" 포지셔닝 + 확률 사고 |

---

## 7. 성공 기준 (검증용)

초기 3~6개월 기준으로, 절대 구독자 수보다 아래 신호를 먼저 본다.

1. **쇼츠 → 롱폼 전환:** 쇼츠 시청자 중 롱폼 진입 비율이 측정 가능한 수준으로 잡히는가.
2. **롱폼 리텐션:** 롱폼 평균 시청 지속률 (특히 회고 구간에서 이탈하지 않는가).
3. **회고 콘텐츠 반응:** 틀린 예측 회고 영상의 댓글이 "변명"이 아니라 "신뢰"로 기우는가.
4. **소재 재생산:** D에서 발굴한 이상치가 실제로 C의 예측 소재로 이어지는 비율.
